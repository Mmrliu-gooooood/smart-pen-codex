# 智点笔 / Smart Pen

纸上出墨、笔尖近摄、板端坐标解码、BLE 与离线补传的两支工程样机项目。

**当前状态：开发中，禁止据本仓库直接投产。** 目标是可制作并经样机验证的整机，不把电路子页、概念外形或软件单元测试当作完整交付。尚无整机通过光学、功耗、热、安全、书写精度或可靠性实测的证据。制造发布须满足 [放行门槛](docs/system/RELEASE_GATES.md)。

## 已确认约束（2026-10-27）

- 单支 ≤ ¥380，两支 ≤ ¥760，包含摄像头/镜头、全部电子件、电池、刚柔 PCB、贴片焊接、外壳及笔芯；不含运费。开发工具和返工支出另列且须确认，不能静默突破上限。
- 优先级：坐标准确与安全 > 体积（目标直径 15–18 mm）> 续航。4 小时连续书写、1000 小时待机仅为优化目标，不是硬验收。
- 先黑点白纸，最终红外方案；允许重新生成密集点阵。不得假称兼容 Anoto 或现有纸张。
- 可换出墨笔芯，二值落笔检测，拿起预唤醒，短抬笔就绪，长闲置低功耗。
- 独立解码、BLE、断电安全离线坐标记录/确认补传、升级功能、USB-C 充电与烧录。
- 复用书台 Windows/网页上层功能，仅新增笔数据源。不重做评分、AI 或画画猜猜，不开发独立手机 App。
- 离线 24 小时有效书写作为估算起点，以成本和实际记录率优化，不能未经核算宣称满足。
- 每块板 < 100 × 100 mm。首轮 3D 打印，面向成人验证；儿童使用及销售须另行安全与法规评估。
- 首版样机目标不晚于 2026-11-26。用户配合采购、组装、采图、功耗与书写测试。远程工程文件不等于实体样机完成。
