# Whole-pen mechanical studies from actual RevC PCB

Read [Chinese release boundaries and results](../../docs/mechanical/整笔装配RevC_真实95mm板_20261028.md) first.

Four mutually exclusive assembly candidates; no complete-pen STL or manufacturing release.
Actual 12 x 95 x 0.8 PCB, 69 footprint positions, 67 populated shapes; frozen source SHA256 in `inputs/revC_mechanical_extract.json`. Do not silently substitute RevD or future compact packages.

Reproduce with FreeCAD Python:

```sh
/usr/bin/python3 build_assembly.py
/usr/bin/python3 scan_constraints.py
/usr/bin/python3 verify_and_export.py
```

To refresh the actual PCB extraction, explicitly provide the intended board:

```sh
/usr/bin/python3 extract_pcb.py /path/to/mainboard_revC_localroutes.kicad_pcb
```

`FPC_bend_tests_NOT_ASSEMBLY` contains 18 **alternative** quarter-bends, not 18 simultaneously installed flexes. Their failures are separate from nominal rigid-component collision results. Unknown FPC exit/connector, actual camera mount, compact contact mechanism, complete battery pack, fasteners and RF remain release blockers.

Render input meshes are temporary and can be regenerated by `verify_and_export.py`; `render_assembly.py` runs under Blender. Checked PNGs are cutaways/sections, not manufacturing split-shells.
