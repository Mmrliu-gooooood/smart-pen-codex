仅 R104/R240（RC0603FR-0710KL）、R221/R224/R233/R218/R210/R228（RC0603FR-07100KL）、R236（RC0603FR-074K7L）采用厂家最大本体 0.55 + 明示焊料/装配假设 0.15 = 0.70 mm。官方数据表链接逐项保存在合同。其余所有器件高度不变，特别四电容仍 1.3 + 0.15 = 1.45 mm；背面三个电阻也未降低。电阻 XY 未缩小。

## 固定坐标与公差

- 全板统一 X=PCB_x−7；Z=127−PCB_y。不得逐截面重新居中。未合并 RF 左扩 −1 mm。
- B 面基准 Y；F 面 Y+0.93（JLC06081H-2116 候选 finished 0.83±0.10）。旧 0.8→0.93 全部加到 F 侧，不双面各加 .065。阻焊是否计入 finished 量测仍待厂家确认。
- 功率板 X±7，Z82..127，总包络高4.15；底面 Y−5.90。保留背面器件1.45 + 名义板间0.30；相对装配损失0.20后余量0.10。
- 壳 OD19、名义壁厚1.2、壁厚±.1取最坏+0.1；径向装配/弯曲预算0.2。有效径向预算8.0；另保留0.10残余门槛，代表实体外接半径须≤7.9。OD实际制造公差未给定，不能称公差已完备。
- J109 每处 wire+solder/bend 包络1.8×2.2，高2.0 above F，三线轴向范围18.1..25.1；并未降低成铜盘宽1.4或任意矮线。沿轴线的完整线束、夹持、转弯与应力释放仍未建模。

功率板单独要求 B_Y≥2.238033315 才达到0.10径向残余；在此最低Y，C103 至少右移0.015337895、C203/C201/C205 至少右移0.065337895。因此四者在本固定变换/高度/堆叠下都必须处理，不能单靠端口内移解决。该数学下界本身无多余余裕，不是建议落板坐标。可考虑统一+.10或+.15的新预布局，由电气人员核查去耦路径/布线与DRC。几何上不需要旧方案把全部13器件搬+.35/.40。

+.15 比 +.10 多出约 .0109 mm 径向余量，仍不能宣称制造稳健；还需明确线束/支架/外壳实际公差。仅截面筛选；整机电池/NTC、接插件、RF全空间净空、手握、镜头/FPC、散热及安全不因此获批。该19mm电子堆叠不解决现有13mm摄像头/21.82耳距模组装入笔头的问题；原≥24.22必要下界与测试夹具回退仍有效。
