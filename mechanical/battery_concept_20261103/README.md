# 10440电池端部与上盖概念结构

**NOFAB：不可直接打印。** 两个STEP是独立阶段概念，不是最终笔的合并装配，也不是可制造支架。原整体结构未替换。

优先现成10440并调整笔内部；仅现成方案确实不合适时才考虑定制。10×44mm为电芯基础尺寸；完整保护包还需计保护板、绝缘、NTC和引线。原询价带线包的完整最大外形仍未知。

本研究以另一现成备用P1044C的保守本体Ø10.8×45mm进行几何计算，不能把该尺寸套给带线包，也未决定采购P1044C。

端部台阶/绝缘衬片和上盖止挡概念已做已知固定体碰撞与连续扫掠。电池轴向移出受阻，拆开上盖后+Y侧向25mm路径在已知场景中可行；上盖本体及带止挡的概念也通过有限连续运动检查。

0.3/0.4mm薄部仅空间试算，尚缺真实锁紧、倾斜逃逸、材料强度、触点、绝缘系统、线束和相机/FPC。现有检查不证明全装配或安全性。evidence为数值快照，不是完整重放环境。
