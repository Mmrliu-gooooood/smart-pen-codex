# 14×45 电源板：独立 VBUS 分流和温控裕量复核

2026-10-28 UTC。**NOFAB；JP1 保持开路，未通电、未实施充电、未修改冻结硬件。**

## 结论

1. 此前 6.821 mV/A 和新增细线 0.323 A/A 分流的条件模型，现已由独立代码重建并复现。不是短路证据，也不是载流资格化。
2. **1.167 mV 是最差条件下 20°C 冷端恢复充电许可的可用性裕量**。它不是全部温控保护的安全截止裕量。10°C 禁充、45°C 禁充、30°C 恢复分别有不同的条件裕量。
3. 不能将 VBUS 上 6.821 mV 的压降直接减去比较器的 1.167 mV。前者是电源网络压降；后者是输入对本地比较器地的差分电压，存在稳压参考、分压、器件供电抑制等传递关系。
4. 静态电路数学成立，但尚不具备消费级安全放行证据。额外泄漏、差分地偏移、NTC 贴合与自热、启动/掉电/负载瞬变、容差和真实器件资格化仍未闭环。

## 固定输入及独立方法

- PCB SHA256：`5c5764e7576c9461464c12da3531410e63ef4db32a28a67a5fa6125ef0b92014`。
- 原核心 PCB SHA256：`7a7013b4371401595b2ffcc8569bbe2b2bf0ce828f567d530ec3ab6a0b755b1f`。
- `reproduce_network.py` 自行从原生 KiCad 提取 227 段 VBUS track、16 via，构建 192 个理想结点的电阻网络；没有导入旧分析脚本或旧结果。采用同一声明条件：85°C 铜电阻率、外层31.5µm、内层18µm、实际线宽长度、pad/via 理想0Ω。逐一检查非源点 KCL 与耗散功率守恒。
- 该模型使用中心线接触分段及实际 pad HitTest，仍不是有限元铜皮扩散模型。零阻 pad/via、真实桶阻、接触与回流电阻、互感、温升、动态负载等未包含。因此分流比和电压绝非最坏公差界限。
- `reproduce_thresholds.py` 独立求解 NTC_NODE、HOT_SENSE、COLD_SENSE 的 3×3 导纳矩阵，而非调用原设计的代数公式。从实际 XML 核对 R109..R113 为10k/110k/100k/255k/100k。
- 阈值计算继承现有 Vishay material-9 多项式、±2% R25、表列曲线误差、各电阻总±0.2%、输入偏置±25/±15nA等条件；**未重新证明实购NTC/电阻符合这些条件**。每个激励范围是1024个参数角点，分别计算四种状态的裕量，不能称所有历史方案都具有相同角点数。

## VBUS 独立复算结果

- J2.1→BQ U1.13，施加1A归一化负载、其他负载0：trace压降 **6.821066020 mV/A**，新增段最大 **0.322809852 A/A**。这是线性传递敏感度，1A不是USB获准电流。
- 仅 U102.4 假设25mA：**7.046764148 mV**。25mA不是该IC已确认耗电上限。
- KCL最大残差 <4×10^-14 A；电阻耗散与源供给功率一致。与旧结果误差 <10^-8。
- 主要并联细线在前端 F.Cu，最高分流段 UUID `5861a9b2-5b80-42fc-b6e6-084cf70c7d2c`，(7.5,4.925)→(7.5,6.425)mm，宽0.15mm。相同高分流链另含 `174e62ed-1e66-4399-a9de-ab6b5cfd5a4c` 和 `df0299b4-1439-4e05-a850-1d5d052061b2`。
- 原宽主干仍连续；新增线形成并联捷径，不可全部标成“只承担温控电流”。更多精确 UUID 与条件流量见 `network_result.json`。

## 四种温度状态必须分开

现有声明激励2.34..2.53V，含上述元件/偏置/NTC角点：

|状态|最差输入裕量|含义|
|---|---:|---|
|20°C冷端恢复|1.167450 mV|冷停后能否保证重新给许可，偏小主要导致不恢复/抖动|
|30°C热端恢复|68.469973 mV|热停后重新许可|
|10°C冷端禁充|7.423240 mV|即使此前许可，冷端应撤销许可|
|45°C热端禁充|19.780735 mV|即使此前许可，热端应撤销许可|

电芯允许区间、传感器实际温度与电芯核心温度一致性另需确认。这里是输入静态电路，不是电芯安全认证。原BQ TS仍有独立NTC，不等于其所有故障/共因已验证。

只采用原预算列明的 REF DC 误差项范围2.496122269..2.503877731V时，四个裕量分别变为 **5.139787 / 100.082200 / 34.946678 / 23.558514mV**。这说明1.167mV来自较宽激励上界，但不能据此删除启动/瞬态验证：此窄范围未覆盖噪声峰、老化、焊接偏移、热滞后、电容/负载瞬变等。REF34xx的噪声、老化等典型数据不是这些误差的保证最坏界限。[TI REF34xx datasheet](https://www.ti.com/lit/ds/symlink/ref34.pdf)

TPS3700上升/下降阈值及偏置电流界限已纳入角点；5.5mV典型迟滞不是可额外赠送的保证抗干扰余量，更不应再次相加。[TI TPS3700 datasheet §6.5](https://www.ti.com/lit/ds/symlink/tps3700.pdf)

## 差分噪声/泄漏敏感度，不是故障实测

在各自最差静态角点，单独施加某一种额外误差、其他条件不变时：

- 冷恢复：额外向 INB 注入约 **16.142nA**，或 R113 底端回流比 U105.GND 高约 **1.61746mV**，可用完1.16745mV恢复裕量。前者是在已计入芯片偏置界限之外的PCB/器件附加泄漏。
- 冷禁充：额外从 INB 抽取约 **102.724nA**，或 R113 回流相对 U105.GND 低约 **10.2518mV**，可用完7.42324mV禁充裕量。
- 热禁充：额外向 INA 注入约 **372.698nA**，或 R111 回流相对 U105.GND 高约 **37.3443mV**，可用完19.7807mV禁充裕量。
- 这些值是单一误差线性敏感度。多个误差同向时必须合并，不能各自独享全额裕量。不是已测得的污染漏电、地弹或安全故障。
- 如果参考与分压/NTC整个安静网络相对比较器地一起偏移，输入也随该相对偏移；如果包括比较器地在内的全电路一起移动，则共模零点变化抵消。不能将任意供电噪声称为同等输入差分噪声。

完整带符号增益、最差角点及使裕量归零的额外误差见 `threshold_result.json`。目前没有实测或有保证的干扰上界，因此不能宣称剩余动态裕量为正；但也不能反过来宣称这些干扰必然发生。

## 最小改版建议（尚未实施）

1. 在新版本保留 J2→C1→BQ 的现有宽主干。为温控/参考支路选**唯一供电汇接点**，建议从输入去耦 C1.1 附近分出，避免与充电主电流串行共享细颈；选点也必须核查USB输入/充电布局建议。J2.1当前(7.25,1.8)，C1.1当前(7.75,4.8)mm。
2. 将独立温控支路改为一棵供电树，去掉回接J2/BQ原主干的第二、第三入口；不能只随意删除最高电流段。用全网络对每一新增段做“仅BQ注入、所有温控负载0”的检查，要求独立温控支路无BQ通流。实际器件去耦/EN/SENSE连接均保留。没有对当前冻结板作任何删线。
3. 新支路优先用≥0.30mm连续供电走廊，缩短到各IC/去耦的实际路径，避免把低功耗误当成无布局要求；0.30mm是稳健布线候选，不是已验载流标准。沿连续GND参考走线，少跨层，禁止切割必要回流平面。
4. 在 U105 周围汇集 R111/R113底端、NTC测量回流与参考低端的安静返回，避开BQ/开关电源/LED大电流路径。使用实际参考force/sense脚连接设计，不能仅同名GND即称Kelvin合格。保留独立受保护回流，不将cell负极/NTC线错误跨接保护电路。
5. 不为追求“数字更大”直接改阻值/温度窗口。先选定实物NTC、电阻总温漂、清洁度/泄漏界限、参考电容和测量方案，再分配额外误差预算；必要时降低分压阻抗或增加经验证的输入滤波。任何RC滤波必须复核延迟及开/短路故障，不能无条件增加。
6. 下一版重跑ERC/DRC/parity/实际铜连通和本复算，并实测输入电源插拔、慢升降、无线/LED脉冲、充电动态、NTC开短路与恢复。**禁止在以上闭环前闭合JP1。**
