## 总线长不是充电电流串联路径

新增 **110.4867 mm** 是 VBUS 全网络新增分支线段中心线长度**总和**。它不是单一路径，也不是全部承载充电电流。冻结报告 0.506 Ω / 假设25 mA →12.65 mV 是把所有新增线段按0.15 mm/31.5 μm串联的长度上界代用，不是实际线路压降测量。

原核心宽主干实际仍连续：仅使用原核心铜，J2.1 → BQ U1.13 中心线约 **5.4213 mm，最窄 track 0.30 mm，无 via**；到 C1.1 约 **3.2071 mm，最窄 0.50 mm**。R6 偏置路径最窄0.20 mm，不是主干。

但新增铜在原 VBUS 相邻节点之间构成了**并联通路**，不是所有新增段都严格只承担温控负载。几何最短 J2→BQ 路径会选择约1.618 mm新增0.15 mm段，整体路径5.4071 mm；这**不是最低阻路径，也不是唯一电流路径**。不能因宽主干仍在，就宣称细并联段零充电分流或零环路影响。

## 条件电阻网络（不是最短路径替代分流）

另外将**全部实际分支同时**组成线性电阻网络，按每段宽度/长度计算。假设85°C铜电阻率、外层31.5 μm、内层18 μm；pad和via桶暂理想0Ω，不包含电源、连接器、焊盘扩散、过孔桶/回流电阻或电感、皮肤效应、温升反馈。不是最坏公差，不是实测，也不是载流/USB授权。

- BQ节点施加**1 A归一化单位电流**、所有温控负载置0的传递敏感度：网络仅trace压降约 **6.821 mV/A**，最大新增0.15 mm段电流约 **0.323 A/A**。这是明确的并联分流；1 A仅数学归一化，不表示 USB100/500 模式允许1 A。实际线流依输入限制、充电/系统工作模式、各分支负载及真实阻抗而变。
- 假设仅 U102 节点有 **25 mA**、其他负载置0：trace网络压降约 **7.047 mV**，最长串行支路段电流25 mA。25 mA是筛选场景，不是该芯片或整组已确认最大耗电。与单位BQ场景可在线性模型内叠加，但真实动态电流不是这些假设。

原宽主干没被切断。新增细并联通路可能改变电流分配和环路耦合，不能自动等同安全故障，也不能因为DRC0而忽略。下一版可考虑消除不必要并联快捷铜、按真实低噪供电树优化；若做必须另开新版本并重新验证，当前冻结不悄改。NTC/参考约1.17mV静态条件裕量并未因此获得动态保证。
