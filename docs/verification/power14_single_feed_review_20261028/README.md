## 独立方法与结果

`physical_contacts.py` 独立创建物理导通图：原生track/pad形状转为最大0.5µm向内近似多边形、via外形显式减去钻孔，每一个实际填充岛独立节点。仅当同层铜多边形有正面积相交时连接；不按同名网合并岛。

- 25个多pad网全部实际连通。
- VBUS核心与温控新增铜共7组几何接触，其中3组在C1.1焊盘外。
- 全部正面积都远大于近似误差量级；该检测比旧模型“中心线端点是否相交”多覆盖环铜边缘搭接。
- 该版本的中心线电阻结果9.478628mV/A以及近零温控分流，只是**遗漏上述接触的模型结果**。不能沿用为实际板子的电流结论。本审查没有给未经实证的有限元分流新数值。

新鲜KiCad ERC=0；正确配置系统库后，新鲜DRC全部严重度/所有track错误/原理图parity/违规非零退出检查得到 **0 DRC、0未连、0parity**。首次DRC在空全局库配置下35条库缺失warning退出5，另存于 `native_drc.rpt`；正确配置官方系统fp-lib-table后结果是 `native_drc_configured.rpt`，没有屏蔽规则。两类结果明确分开。

DRC对同网接触不应报异网短路，故它通过并不反驳此问题。

## 后续最小修正方向

另开版本，将上述两个温控过孔及关联支路移出旧主干的有限铜宽邻域，再重接独立C1馈电。不要修改旧核心轨迹来掩盖设计目标，也不要只缩线或删除中心线而保留环铜接触。所有层的via环铜和填充接触均须检查。

修复后必须重跑实际形状单点接触检查，并更新电阻模型或证明仅存在一个物理汇接区域后才使用简化树模型。保留本失败候选作为回归反例。

本审查未完成EMI、地弹、动态热噪声、装配、电池、完整温控安全资格化；前一份 `power14_independent_noise` 对恢复与禁充裕量的区分仍适用。**NOFAB、充电JP1开路保持。**
