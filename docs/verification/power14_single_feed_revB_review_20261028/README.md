## 条件电阻网络复算

独立脚本从冻结原生PCB再次提取电阻网络，而不是读取作者结论。先通过实际铜单点接触检查，再使用中心线电阻近似：85°C，外铜31.5µm/内铜18µm，pad/via理想0Ω，不包含过孔桶/焊盘扩散/回流阻抗、动态与温升。

- BQ U1.13施加1A归一化，其他负载0：宽主干trace压降 **9.478628151mV/A**；温控新增段最大电流约 **6.96×10^-14A/A**，为数值零。KCL最大残差<2.2×10^-14A，功率守恒通过。
- U102.4单点假设25mA：**9.800580403mV**，较原版7.046764mV增大，说明绕行引入额外供电阻抗。25mA不是该IC实际/最大耗电，1A不是USB允许电流。
- “理想网络数值零”不等于实物任意频率完全零耦合：C1焊盘内有限电流扩散、共同源阻抗、回流和寄生耦合仍存在。
- 温控内部可能仍有有限宽度接触和并联路径，故此线性数字仍是声明近似，不是保证最坏压降；本次关闭的是**C1焊盘外额外充电主干入口**。
