# 注塑DFM准备清单（与样机打印释放分开）

本版不具备开模条件，不承诺拔模、壁厚均匀、缩水/翘曲、材料阻燃、电池安全或射频性能已验证。最终外壳需要相机、板形、电池、补充芯及鼻端力学先冻结。

1. 外径15–18mm目标下重新比较PC/ABS等材料的壁厚、筋、分型和成型能力；1.5mm仅空间研究假设，不是必须也不是量产建议。薄壁节省空间须以供应商流动/充填/跌落验证为前提，不能为容纳模块盲目削薄。
2. 沿笔轴的上下半壳、可拆鼻端、独立尾塞分别论证。避免内侧深倒扣；拆卸方向与电芯、USB、镜头支架维护路径一致。不能简单把整根空管当可注塑壳。
3. 初始拔模角一般从1–2°讨论，纹理面需更多；最终由材料、深度、纹理和模厂定义。筋厚/柱根厚避免厚肉、缩水及汇合线，不以统一比值替代仿真和样件。
4. 卡扣不能成为电池包唯一保持件；采用限位托架/机械锁定。螺钉柱、热熔螺母热源远离电池，螺钉长度防错及绝缘挡墙阻止装错穿透。
5. 天线附近壳体材料、涂装、金属装饰和紧固件冻结后再调射频；USB开口和镜头窗口做装配基准链，不能只给美容间隙。
6. 光学窗口避免反射LED杂散光；遮光壁用不透光材料、表面消光、明确遮光路径。材料黑色并不保证近红外不透光，未来850nm版本需重新测透射。
7. 公差链分离：笔芯轴向自由行程与触点预行程；镜头到纸距离/角度；电池正常/膨胀；板形和连接器；左右壳装配偏差。使用真实厂家公差和打印/成型能力数据。
8. 模具释放包还缺：带基准与公差的工程图、树脂牌号、表面/色号、分型/浇口/顶针策略、模流、尺寸检验计划、装配防错、跌落/扭转/温升/充电安全/汗液与污染/寿命验证记录。当前STEP不可作为免审开模依据。
