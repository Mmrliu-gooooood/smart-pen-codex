# 真实95mm主板下的整笔装配候选：可行取舍，不是制造放行

2026-10-28。新增目录：`mechanical/whole_pen_revC/`。所有长度单位mm。

**Ø18没有被判为全项目失败，Ø20也不是必然选择。** 本轮保留真实12×95×0.8主板及其实际摆件，给出4个互斥候选，修正了居中笔芯与8×8相机争空间的问题。电池和主板并排能减长度，但要求更严格的完整电池包直径；相机FPC仍是实质装配缺口，不能因头部放得下就宣布整机完成。

## 偏心与轴向安排

以笔尖名义点为(0,-3.8,0)，笔身长轴为+Z。D1仍是Ø2.35×67的未验证公差名义包络；不用细芯管承担所有结构载荷。

- D1轴Y=-3.8；相机光轴Y=+1.8，与笔身轴平行；两者横向相距5.6。
- 相机镜头前端Z=17.5，主示例总高H=6.5，至Z24。主板Z32..127，真实95长，没有从D1末端再串接95mm。
- PCB源Y方向反向映射到整笔Z=127−Y；PICO保留在源Y≈10，即整笔Z≈117，与后方RF研究区域相邻。变换不改变相对布局。
- 触笔机构暂给**完整Ø6×12要求包络**，Z68..80，中心随D1偏心。它不是已做出的缩型触笔总成，也不是把台架Ø14肩硬塞进笔里。芯尾与盒之间的间隙只是接口待设计区，尚无最终传力零件。
- A/B的完整电池包Z141..190，尾部电源/USB预算Z192..210；RF预留Z128..139。主板与D1本来就重叠，210并非把二者串排造成的虚假长度。
- C/D完整电池包Z82..131，与主板重叠；RF预留Z134..156；电源/USB尾区Z158..180。初步160/175设想因真实触点盒/电池端部与RF/尾区空间被修正为180，不拿早先粗估当最终图。
- 电源/USB尾区10×5×22（长方案为18长）仍是**未摆件、未完成连接器承力的聚合预算**，不是第二块已完成电路板。RF区域也不是已选天线的原厂禁布区；须实测调谐，不能凭隔开几毫米宣称射频合格。

偏心扫描见`eccentricity_contact_scan.json`：相机Y从+2.6向内移、D1更负，保持两轴间距5.6，8×8头板最远角从7.717降到7.045。故18/1.2的头板径向余量由0.083升至0.754；若壁改1.5，头板几何余量仍约0.454（非全套1.5壳重新放行）。代价是笔尖相对握持中心偏心，左右手、旋转、扭矩感和指腹遮挡必须试握。

在当前D1偏心3.8、1.2壁、要求0.3径向预算下，最终触笔总成外径上限约：18外径时7.4；19时8.4；20时9.4。台架Ø14肩完全不满足。完整小型滑套、回位簧、独立硬止挡与开关载板必须在这个边界内真实设计/试验；本文件没有把未选开关或弹簧自动缩小。

## 电池并排的真实约束

候选保护10440的电芯包边界采用Ø10.8×45保守尺寸；它已是保护电芯候选，不是允许用未保护裸电芯替代。额外NTC、引线、接触件、绝缘和保持结构必须加入。

- Ø11.4完整包意味着相对Ø10.8仅剩0.3径向加量，**未找到已证实能容纳全部附件的实物**。C因此是条件分支，不能当成现成电池方案。
- Ø12.2完整包给更多附件空间，但仍只是预算；不能宣称保护、温度传感器热耦合或跌落保持已满足。禁止螺钉穿向电池、禁止热熔胶作主固定，充电热源与电芯仍须隔开并实测。
- C/D裸板背面到完整包几何距离0.3。这个间隙不是额外留给厚托架的空间；如需支架/绝缘膜，必须包含在包络或重新加间隙，不可重复占用。

`cross_section_tradeoffs.json`用真实封装边界优化电池偏心和板位置，固定板—包间隙0.3，比较剩余径向预算：

| 外径/完整包直径/被动件高度 | 优化后的最小径向余量 | 对0.3筛选预算 |
|---|---:|---|
|18 / 10.8 / 1.0|0.124|不足；且10.8只是保护电芯边界，不是附件完整包|
|18 / 12.2 / 1.0|-0.464|出现几何冲突|
|19 / 11.4 / 1.0|0.375|条件可继续|
|19 / 11.4 / 1.6|0.120|余量不足|
|19 / 12.2 / 1.0|0.036|近乎贴边，不可按可装配发布|
|20 / 12.2 / 1.0|0.536|该截面条件可继续|
|20 / 12.2 / 1.6|0.278|仍不足0.3，真实被动件高度需冻结|

上述是整板最坏棱柱截面筛选；没有证明所有压降、散热、布线、连接器或保持件合格。今后紧凑封装/实际短板可改变取舍，不由本表推导“项目只能20mm”。优先继续18轴向与19条件分支，20作为附件容积对照；不擅自替用户改外径目标。

## 相机：总高扫描，不假装已经选型

主研究路径为AS-video AS-DGSG8A130D7/SC031GS公开8×8 PCB，与CH2035AB候选镜头。几何使用镜头Ø6×3.67、6.5方形座占位、8方形PCB；总安装高H逐点扫4.5/6/6.5/7.5/9/10.5，**整个H范围都是参数实验，不是卖方确认总高**。每个高度保留相机与D1、内腔和主板起始位置的检查，见`camera_height_scan.json`。当前最小相机板—D1距离0.425；按公差/安装支架后未必够。

[AS-video模块页面](https://www.as-video.com/product/sc031gs-vga-global-exposure-subminiature-structure-180fps-mini-dvp-camera-module.html)与[CH2035AB厂家图纸](https://www.opticslens.com/uploads/CH2035AB.pdf)属于不同供应来源；镜头螺纹、座、传感器位置和近焦需共同核实，不是买来必定互装。

另一路[YXF SC035HGS页面](https://www.yxfcamera.com/products/DVP-Camera-Module/0.3mp-esp32-cam-global-shutter-hdr-sc035hgs-dvp-camera-module.html)公开8×49.69×3.7与650nm IR-cut。**49.69包含柔性尾部，不是49.69硬头；3.7是否覆盖最终镜头/调焦座/装配公差缺证据。** 本轮没有把3.7替换成已确认镜头总高，也没臆造8mm头长和其余FPC长度拆分。它保留为待拿完整图纸的独立候选，不与SC031GS叠装，也不宣称现有驱动或近焦已经兼容。

两路650nm IR-cut不能直接叫未来850nm红外方案。零件价格、完整两只报价未闭环，不能仅凭几何宣称单支≤380、两支≤760元（不含运费）。

## FPC是实际阻塞，不藏在壳外

`FPC_bend_tests_NOT_ASSEMBLY.FCStd`中的18个形体是**互斥的独立试弯**，不是同时装入的18根线。厚0.15、宽3/5/8、弯曲半径3/5皆为诊断参数，不是供应商已批准的半径/线宽。

- 从8mm相机板向-Y（笔芯方向）转弯，8宽/R3与D1相交约0.834mm³。
- 向+Y（外侧）转弯，8宽/R3在18/19/20外径的内腔都超界。
- 向+X转弯，8宽/R3仍分别超界约0.730/0.330/0.071mm³；不能因20只少量超界就磨壳压线。
- 3宽/R3侧向试弯在18几乎贴边而无公差；19/20有名义空间，但**没有证据真实模组会提供3mm窄尾**。5宽亦需实际余量核对。

这些只验证四分之一弯，未接到真实未冻结连接器，不能算全长连接完成。必须获取真实FPC出线方向、每段宽度、板后禁布区、静态/动态最小弯曲半径和连接器高度，再做完整带应力释放路径。可以研究窄颈柔板、不同出线方向、移动接口或不同镜头支架；未经厂家允许不得锐折、剪耳/剪尾或默认拧成扭带。

## 纸面、遮挡与工作距离

相机不必看见笔尖，可观察旁边点阵再通过标定外推。当前光轴平行笔身，两轴偏移5.6；镜头前端Z17.5。对纸面法线夹角30/45/60、roll=0：

| 法线夹角 | 沿光轴的镜头前端→纸交点距离 | 图像中心到笔尖的纸面距离 |
|---|---:|---:|
|30°|14.267|6.466|
|45°|11.900|7.920|
|60°|7.801|11.200|

这些距离以**镜头前端**为基准；厂家最近物距5mm的基准未明，不能直接作等价通过判据，更不能用无穷远FOV推算近焦像质。不同握持旋转也会变距离，例如roll180°时60°情景约27.2。需要实拍验证景深、清晰度、曝光、纸面定位及倾斜畸变，不能只验证单一握笔方向。

近端壳通过围绕偏心笔尖的锥形避让，几何上针对法线夹角≤60°、各roll留1mm纸面间距；60组抽样检查中壳纸最小约1.000、镜头/相机实体纸面最小约1.303。以镜头中心发出至纸面6×6测试ROI的5条射线，所测角度未被壳/笔芯截断。**这只是针孔式几何检查，不是已证实的有效FOV、成像质量、整镜头孔径光束或手指遮挡。** 真实LED、遮光隔板、窗口材料和左右手指腹仍未加入，必须继续验证。

笔芯轴向移动仍会改变固定相机到笔尖的偏移。此整笔图没有沿用台架0.65作为最终行程。最终须缩短记录状态内余程，或可靠标定笔轴与纸平面交点补偿；二值触点不能直接测位移。`optical_geometry.json`中Δs=0.1只是敏感性示例，不是已达到的机构余程；对应30/45/60°约0.050/0.071/0.087mm投影误差。原始图像、实际行程和真值轨迹需一起测。

## 装配/维护仍待闭环的真实项目

现有壳是连通空间边界，不是可直接下单的分件外壳。下一步要选择分壳/可拆鼻端和尾塞，落实定位筋、紧固件、装配顺序以及USB插拔载荷路径；不允许为了照片漂亮就把接头和螺钉删掉后叫最终版。

初步顺序只能是先装光学头及FPC、再定位主板与独立触笔盒、再装完整电池托架/温感/线束、最后尾电源板和已选天线；每个步骤必须有可到达的插接与拧紧路径。长管端部可进入不等于有足够手工装配空间；短并排方案尤其需要可拆结构。换芯应从鼻端释放，不拆电池；整个抽芯路径、实际尖头肩部和夹持方式还须与新的小型触笔盒一起重做。

缺口逐项列明：①原厂相机总高/出线与近焦；②完整FPC/连接器；③真实小型触笔机构与行程光学校准；④完整保护电池+双温感/绝缘/保持件；⑤主板路由完成及真实尾板/天线；⑥壳体紧固、LED遮光、热/射频/跌落/握持测试。完成前不制造放行，也不停止与这些缺口无关的真实布局优化。

## 文件与回归

- 4套具名FCStd/STEP互斥，不能把A的电池和C的主板偏心随意混用；2个DNP、保护电芯与其完整包预算、服务扫掠和RF区域都有明确性质。
- `assembly_validation.json`保留名义实体碰撞、壳碰撞、径向余量；保护电芯被完整包包含是有意关系，未当作冲突。FPC未混入“零干涉”的主装配结论，独立失败结果见专门扫描。
- `reopen_validation.json`独立重开全部4个FCStd、回读STEP；零干涉不能替代所有真实未知件。
- `extract_pcb.py [实际PCB路径]`生成冻结输入；`build_assembly.py`→`scan_constraints.py`→`verify_and_export.py`回归。FreeCAD可编辑每个具名实体，尺寸参数在生成器；它不是全约束原生Sketcher特征树。禁止手改输入把真实PCB/器件缩小来“过检”。
- `*_cutaway.png`是剖去近侧半壳的显示视图，不是分壳制造图；`*_section95.png`是Z95截面。绿色为真实板、金色为实际封装保守棱柱、蓝色为**完整电池包预算**、紫色为未选型光学/尾电路预算、橙色为待工程化触笔盒。图片已目视检查，不据外观宣称最终物料完成。

## 下一轮保持18mm的具体降长目标（不替换本轮真实板）

续航是可取舍目标，因此不应只在“210长”与“增径”之间二选一。若接口、前端/FPC、RF和尾区不增加长度，轴向方案的长度敏感性约为：`L≈210+(真实主板长−95)+(完整电池包长−49)`。例如：

| 后续真实板长 / 完整包长 | 对应长度研究目标 | 尚须建立的证据 |
|---|---:|---|
|82 / 49|约197|实际短板布线/板形/接口通过，而不是裁掉未连部分|
|95 / 35|约196|存在安全合格、带保护/温感/保持件的短包，实际容量与峰值电流可接受|
|82 / 35|约183|上述两项均成立且FPC/天线/尾区不反向增大|

这里的82/35仅给电子与电池筛选明确几何目标，不表示已经完成82mm板或找到35mm完整包；不把10180等外形相似裸电芯直接代换。真实封装精简、短完整电池与实测功耗应并行评估，优先安全/精度，再看体积和续航。

19mm薄完整包分支可能引入定制保持/温感成本，不应为缩径盲目改买高价镜头或电池。仍按数量2的完整报价比较成本与装配风险；本轮不认定20更便宜，也不宣称19已满足单支380元。
