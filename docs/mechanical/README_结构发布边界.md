# 结构交付：先验证光学，不伪装整笔已能装配

**2026-10-27。Ø18 mm 是目标，不是完成配合保证。只有独立光学台架及笔芯导向试片提供 STL。完整笔没有制造放行。210mm纯轴向方案仅作对照，170mm错层重叠方案是另一个尚未布板的候选，不推荐锁定210mm长笔。**

## 已得到的结果
- 新建 FreeCAD 可编辑模型、STEP、8 个独立闭合 STL；FreeCAD 1.0 重开及 STEP 回读有效。
- 台架打印件之间、所建 M4 螺栓/头部/螺母包络与打印件之间无体积干涉。滑台两个极限位置检查无碰撞；中间运动为直线且障碍恒定。
- 旧版 `handheld_pen_20261018/mechanical/refined/build_refined.py` 已检查：镜头支架预算外伸、压力载荷堆叠未工程化；旧模型未作为本次装配证据。
- MINI 分支：16×3.2 mm 横截面最小外接圆16.317 mm，采用本研究1.5 mm壁时外径至少19.317 mm（仍未含公差）。因此 **MINI 不用于冻结Ø18设计**；不等于Ø18对所有方案不可能。替代PICO 12×4 mm整板预算横截面可落入Ø15，但布局、射频、散热和连接器尚未验证。
- 假设8×8×8 mm相机近笔尖侧置时超出Ø15内腔约215.84 mm³；高度8是未确认假设，不能据此选择镜头或缩壳。13×8 mm假设电池膨胀预算也超出内腔约3.72 mm³。缺口保留在检查JSON，而不是隐藏。

## 台架打印与装配
单位mm。Base 100×90×6；Upright 80×28×106；Carrier 76×50×24；Adapter_SC035HGS_candidate 40×35×3；Nose_guide_coupon Ø18×12。
- 建议PETG或韧性工程材料，0.2mm层、至少4壁。打印工艺、公差、材料收缩必须以孔径试片确认；禁止由模型推断机械寿命。
- Base底面平放；底部M4头沉孔需打印后清理。Upright可背面平放；Carrier背板平放并按切片结果支撑悬臂，不可默认无支撑。Adapter平放。鼻端试片大法兰平放。
- Base/Upright：4×M4×16低头螺栓（头径≤7、头高≤3；非任意标准圆柱头均可）、4×M4螺母；沉孔Ø7.4×3.2。孔Ø4.6。后排螺母在y=41，避开立板。底部头部不能突出桌面。实际螺母/垫片尺寸再次核对。
- Carrier：2×M4×20低头螺栓、2×M4螺母/手拧螺母（本模型只检查Ø9×3包络；更大手柄须另查）。拧紧前两侧同高，调整后确认不滑动；禁止带电调整裸露线束。
- Adapter：4×M3通孔Ø3.4，孔距30×25，用4×M3×12螺栓和M3螺母（包络已查）。根据已目视核对的`MMSYDZ-ESP32-S3-HDSF035V1.0(1).pdf`，现有SC035HGS镜头Ø10±0.1、耳孔中心距18±0.1、孔Ø1.8±0.1。转接板开口Ø11、孔中心±9、槽宽1.9/中心延长0.6，另留9mm宽FPC出口缺口。候选M1.6螺钉配合最小1.7mm耳孔；实际耳厚、支承面高度和可用螺钉长须测量，不能直接把参考硬件长度当采购规格。薄软绝缘垫保护钢补强/电路，严禁压镜筒/FPC；不得擅自剪掉安装耳。载台光窗24×24以避开M1.6螺母。镜头若需更换，使用原厂支架，不打印精细镜头螺纹。
- 滑块螺栓中心z24..94，对应平台z12..82；基板纸面z6。实际镜头距纸由镜头安装方向及下伸量决定：**不得把平台高度当工作距离**。可将镜头装在板下，经中央光窗观察，目标3..15mm距离逐点实测。若镜头头部不能安全下伸则增加纸面刚性垫板，垫板实际厚度计入标定。
- 本交付用30/45/60°刚性纸面楔块获得稳定相对角度，不靠松动相机螺钉制造倾角。角度定义为相机光轴与纸面法线的夹角，需与用户“握笔角”约定转换。它不能模拟笔尖遮挡和手握旋转的完整真实场景。
- 鼻端导向试片：假定D1 Ø2.35，孔Ø2.8，单独验证滑动、回位、笔尖可见和磨损。**不是完整可替换鼻端总成**，没有防脱/弹簧/开关/防水接口；不能安装进整笔后交给用户书写。

## 30天样机结构冻结门槛
必须实测：相机含镜头/支架/FPC出口全包络、最近焦距与清晰平面、左右手遮挡及倾角；两支实际D1补充芯的尾端/笔尖肩部尺寸；选定NO开关预行程/过行程/力；弹簧外径/自由长/压并长/刚度；电池完整保护/NTC/引线/绝缘/膨胀规格；USB连接器和FPC弯曲规范。
测量后才完成：鼻端旋卸或两螺钉可拆结构、内芯防转、笔芯前抽路径、硬机械止挡、相机固定与可调近焦螺纹锁定、LED遮光隔板、壳体分件/承力筋/紧固柱、PCB/FPC接插件压紧与应力释放、电池独立托架/软垫/无尖角接触、USB插拔载荷路径。

## 二值触笔机制约束（待工程化）
目标架构：笔芯轴向滑动→带肩滑套→回位压簧→独立常开触点；硬止挡承受超压，不能让传感器或PCB焊点承载全部书写力。初始试验目标触发0.3mm、止挡0.6mm，仅参数起点，不是选定开关规格。电气触点释放必须在最不利公差/倾斜/污染条件下可靠；回位力需兼顾低笔压不漏触和横向摩擦不挂住。细长D1芯不能未经支承当结构导柱。量产前做至少1万次验证样机循环及落笔/抬笔误触计数，寿命目标另定。

## 安全/维护与走线
- 电池禁止热熔胶作为主固定、禁止穿透电池区的螺钉/尖肋；不挤压软包膨胀面。可拆托架、柔软绝缘垫和引线应力释放是必需后续件。保护10440候选Ø10.8×45只是电芯预算，接触片、套管、NTC和引线另加。
- 充电热源与电池隔开；NTC与电芯可靠热耦合但不可刺破/损伤包膜。壳体表温/电芯温度/最坏充电热试验完成前不无人值守充电。
- FPC模型只是路径占位，不是可下单柔板；R≥3mm可作试验起点但需遵守供应商最小动态/静态弯曲半径。禁折痕、禁转角处螺钉夹持；装配须保留插拔余长和端部夹持区。连接主板不能因插拔USB牵拉相机。
- 尾部USB-C应支持充电及程序下载，不依赖反复拆电池；防止金属外壳/电池/线束进入实际天线禁布区。当前天线块仅占位，不能当射频已验证。
- 左右手均需测试相机视场/LED遮挡、笔尖可见度、握持旋转、指腹热感。不能以一只手的照片替代人机验证。

## 现有相机与采购约束
现有SC035HGS相机13±0.2方形主体、耳宽21.82±0.2、轴向9.44±0.2，不能按8×8候选放进Ø18笔。当前整笔CAD的8×8相机是**未选型替代方案**，并非现有模块。首轮台架优先利用已有模块，不新增购买相机；在3/5/7/10/15mm记录原始图像、清晰率、曝光和笔尖遮挡后，再决定是否采购。完整两支笔单支≤CNY380（不含运费）的成本需要与电子/电池/组装共同闭环；本机械台架不代表整笔已达预算。

## 短笔错层候选（170mm，非制造放行）
`pen18_compact170_NOT_FOR_PRINT.FCStd/.step`：Ø18×170；PICO等薄器件位于补充芯相机反侧，主板包络11.5×60×2.4（含0.8mm板，封装+焊料允许1.6mm，禁止默认背面装件）位于z7..67、y=-4.4..-2；较高电源器件另在12×20×4mm岛z80..100，电池仅电芯z110..155，USB预算z160..170。
该薄板几何上与Ø3.3补充芯抽出通道距离0.35mm、与1.5mm壁壳约0.260mm。**这些很小的距离尚未加入装配轨/绝缘膜/印刷件公差；不等于可装配。** 短方案需要真实布局布线、元件最大高度、壳体材料及定位方案共同优化。电源岛12×20不保证能同时放全部充电/升降压/接口，不能以盒子当电路已完成。实际相机/NTC/托架仍有相同缺口，现有相机不能直接装此笔。机械检查无实体预算互碰，但相机仍超出内腔；见compact170_validation.json。

## 稳定斜纸近焦试片
新增Paper_wedge_30/45/60独立STL：底面20×8，低端高3，另一端高3+8tanθ，最大16.856mm。楔块平底打印，顶面是刚性角基准。用薄可移胶带固定在Base上，胶带不铺到成像区；将已打印点阵裁成小纸片贴平顶面，顶面实际面积20×(8/cosθ)，不能拱起。未把楔块装配到FCStd默认位置，使用时移到光轴下并测纸面高度。
先选0°平纸，再30/45/60°；每个角度测镜头正下方实际纸面到镜头前端3/5/7/10/15mm，近焦从远到近调整。楔块高边、螺钉、镜头、光窗与纸不能接触；纸片必须位于镜头开口内，若接近时周边先碰撞立即停止，不以力压纸或相机获取更短距离。真实镜头下伸量尚未实测，所以每个角/距离组合可能不可达，须记录不可达而不是填写成功。角度倾斜不代表笔尖实际视线；真实纸笔轨迹/左右手测试在下一阶段进行。

## 先利用已有支架，不强制打印整套
用户已有较大OV5640支架/可能已打印支架，优先确认能否安全夹持现有SC035HGS模组及稳固纸面；先做最简单近焦原图试验，**不要求先打印8件才知道镜头能否近焦**。现有稳定夹具可用则仅打印必要转接板或角度试片，甚至暂不打印。需要手动保持时只握绝缘支架、不握裸带电PCB或FPC，不让金属尺/夹具短路。新台架是可复用的**可选测试工具**，不是每支笔的必需零件，也不应重复计入两支笔的单支BOM；打印成本单列并先询价。
