## J103：已有拾笔块的完整合同

源 `smart_pen_rebuild_20261028/hardware/pickup_contact` 已有真实小板，不能说功能不存在；当前问题是物理归属和整合。其 J1 与主板 J103 各pin1..6网络一致，检查已在接口包 `check_system_boundaries.py` 中读取双方真实XML证明。

- 只允许3V3_AON和保护后系统GND，不接USB5V/裸电池。保持LIS2DW12的供电/host I/O协同，断电输入不得反灌。
- AON_I2C_SCL/SDA仅复用该板一组10k上拉；不可因主板添端口再安装第二组或误并相机TCA9517总线。
- 默认先100kHz；既有文档按100pF估算847ns上升时间，不代表实际线束合格。常驻线束接插件/并行走线寄生必须加入。
- NIB_CONTACT_N由该板的100k/1k/1nF与外置干触点形成，不能在主板为压噪又加不明大电容而损失落笔时间。机械触点载荷/导电笔芯对人体耦合/ESD尚待核对。
- 外接只读/调试治具不得向这些AON引脚独立供电；内部接口无热插拔/用户ESD资格。

## J104：共享UART必须把状态变为装配/操作条件

J104.1是MCU侧TX(CAM_RESET_UART_TX)，应接adapter的RX；J104.2是MCU侧RX(CAM_PWDN_UART_RX)，应接adapter的TX；J104.3为共同GND。这不是1→TX/2→RX同名直连。接线逻辑不替代实际U101复用配置。

1. 相机电源关闭且确认放电，IO/SCCB隔离；默认DNP的JP201/JP202不因调试而桥接。
2. 外部adapter不得向DUT提供电源，也不得把5V串口接入。没有硬件powered-off保护器，外部TX在DUT未供电时必须高阻且无不允许注入；普通“3.3V串口”标签不足以证明这点。
3. 使用带限位的壳外服务治具，先接地后信号、先断信号后地；三探点没有“任意用户插接”许可。尚无选定带掉电隔离的adapter，因此RX驱动测试仍有资格关卡。
4. 退出调试后移除治具、停止UART日志和输入驱动，再按相机初始化序列重配复位/TRIG/时钟并使能。不能用软件提示代替装配隔离。

## J105：连接到现有安全前端，不把ADC候选能力扩大

现有 `battery_adc_candidate` 包含真实分压+TMUX1511隔离+输出泄放；主板本身GPIO4不具备直接电池输入许可。J105.1对接该前端J2.1 BATTERY_ADC，J105.2对接J2.2保护后GND；它不是前端J1 PROTECTED_VBAT。

- JP1输出与JP2使能仍开路；硬件PG正常/棕断时序和实际注入未资格化时，禁止连接MCU。
- 该前端ON时名义比例1/3而不是1/2；初始滤波节点存储电压与稳态不同，不能用稳态1.43V证明启动瞬态安全。
- C1在隔离之前，不能为“图上更像标准ADC”把电容搬到掉电GPIO侧。线束和MCU采样负载会改变原分析，需要重新测量。
- 默认开路使主板ADC端没有自动电量信号；固件应禁用未资格化采样/避免把浮动值用于欠压决策。这个端口不是唯一欠压保护或充电终止依据。
- 模拟线与GND成对短走，避开时钟与大电流返回；PCB连续参考地比机械“共用一根细地线”更可控。实际走线与前端安放后再重新做噪声/采样检查。

## 保持的默认隔离，不新增隐式许可

- AXC /OE默认上拉禁用；CAM_IO_EN经DNP commissioning门控，不短接使能。
- SCCB默认禁用，JP202不开；真实下拉和上拉归属不变。
- 相机门控TPS22918默认OFF且输出JP1开路；它不是限流、反灌或裸芯片多电源时序控制器。
- ADC两桥默认开；相机/充电/ADC的commissioning是三个不同门槛，不得因接口DRC通过一并授权。
- 旧30Pin模组未知映射/电压依然不兼容新24Pin合同。每个旧逻辑网已明确迁往新脚，不能再按旧数字直连。

## 路由前后停止条件

先取得精确机械通路与门控归属，再新建路由分支。每完成一个功能组，重跑native DRC/parity、实际铜和填充地的连接图、现有RF/USB/电源保持、各组真实长度/层/参考面；不可只下降未连计数。未解决的物理装配/时序/模拟/供电边界继续公开，不把任意内层细线或长散线当成品通路。
