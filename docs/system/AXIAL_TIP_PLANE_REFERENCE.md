# 轴向活动笔尖与纸面的交点：仅几何参考

`tools/calibration_geometry.py::axis_contact_on_paper` 是一个独立的 Python 参考函数。
原有 `nib_on_paper` 固定笔尖偏置 API 不变；新函数没有接入实时固件、图像解码或产品坐标输出。
它不求解相机位姿、不验证真实标定、不测量压力，也不把接触开关当作位移传感器。

## 为什么需要独立模型

D1 是试验夹具，不是量产合格结构。若总轴向行程为 0.65 mm，在名义闭合点后
还有 0.30 mm 的相对轴向移动，固定偏置造成的纸面内横向变化为 `0.30 sin(theta)`。
笔轴与纸面法线夹角为 30°、45°、60° 时，分别约为 0.150、0.212、0.260 mm。
这些是理想刚体几何量，不是真实夹具测量值，也不是精度承诺。

## 输入与符号（全部长度为 mm）

- 位姿必须由外部已验证的求解/测量流程提供：`X_camera = R @ X_paper + t`。
  纸面坐标系的纸面为 `z=0`，相机 `+z` 向前。
- `axis_origin_camera` 是**零行程时的标定笔尖点**，不能随便拿笔身原点替代。
- `axis_direction_camera` 必须是单位向量，正方向由调用方明确约定。
- `X_camera(s) = origin + s * direction`；`s` 是沿此向量的有符号 mm 位移。
  改变方向必须同时改变有符号行程区间。
- `travel_interval_mm=(low, high)` 必填、有限且有序，端点包含在内。
  区间必须相对于上述零点独立标定；0.65 mm 只是夹具总行程背景，函数不会默认
  把 `[0,0.65]` 当作每支笔的有效接触范围。触发阈值和剩余行程不能混为一谈。
- `paper_plane_camera=(nx,ny,nz,d)` 满足 `n·X_camera+d=0`，法线必须归一化。
  与位姿推出的平面交叉检查（法线容差 1e-8、偏置容差 1e-6 mm），允许整体反号。
  从同一个位姿计算该平面只是一致性检查，不是独立验证证据。
- 必须明确传 `units='mm'` 和 `contact=True`。单位标签无法发现调用者误标的米数值；
  上游仍须负责真实单位转换。接触必须来自经过验证的接触判定，不可由交点存在推断。

令 `n=R[:,2]`，交点位移为 `s = -n·(origin-t)/(n·direction)`。
返回 `((paper_x_mm, paper_y_mm, 0.0), s_mm)`；`s` 是以上述前提成立为条件的几何推断，
不是开关读数，也不是新增加了轴向位移实测能力。

## 拒绝条件及边界

无接触、缺参数、非有限/非数值、无效形状、反射/非正交旋转、非单位轴/法线、
错误单位标签、倒置区间、位姿/平面不一致、非正向深度、数值不稳定或越界位移均拒绝。
平行或 `abs(n·direction)<min_abs_axis_normal` 时拒绝，默认阈值 0.1；
阈值需按实测误差预算选择，不能为提高成功率而任意降低。
不将越界结果裁剪回行程，也不把不一致输入强行投影成有效笔迹。
零宽区间可表达理想固定位置，但浮点端点严格比较，无额外放宽容差。

该一自由度模型不能补偿导向间隙、侧向摆动、笔芯弯曲、弹簧侧载、相机支架柔性、
滚珠/圆头接触点变化、纸面不平、镜头畸变、滚动快门或位姿误差。
在这些误差没有测量和限制之前，不能宣称真实笔尖定位精度达标。
仍需实物刚度/回差测试、轴线与相机外参标定、接触阈值与迟滞标定、
不同角度/力/方向的独立真值对比及完整系统验收。NOFAB 和硬件发布门禁不因此解除。
