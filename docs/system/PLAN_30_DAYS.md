# 首版样机计划

起点：2026-10-27；最迟目标：2026-11-26。此为依赖驱动计划，非已经完成或已保障交期。

- 10月27日–30日：核对书台当前源码，局部码/页定位与姿态可观测性；建立协议测试；确认镜头、模组和电池可采购性与两件成本。并行准备光学夹具与原理图基础。
- 10月31日–11月4日：用户采集不同速度/倾角的近摄实图；验证密集点阵印刷、笔尖偏移标定、曝光与补光。未通过不得冻结笔头/相机板。
- 11月5日–10日：依据 G1/G2 结果冻结器件/空间/引脚；完成 PCB/FPC、结构公差、BOM 与跨域审查；试印关键接口。
- 11月11日–19日：用户批准后下单并组装；按电源、主控、相机、接触、BLE、离线顺序带电验证。交期以厂商承诺为准。
- 11月20日–26日：笔迹、蓝牙中断、低电量、充电温升与续航等样机测试；修复及记录首版遗留项。

如果光学报价、实际数据或制造交期威胁目标，立即报告影响和可选方案；不能通过跳过安全验证来维持日期。

## 下一次需要用户配合的输入

只有在光学候选和测试方法清晰后，给出一份合并清单：现有可用相机/镜头的具体型号与图纸、可采集图像方式、点阵打印条件、所需少量试件。已有资料可先复用，不能默认要求重新购买整套工具。
