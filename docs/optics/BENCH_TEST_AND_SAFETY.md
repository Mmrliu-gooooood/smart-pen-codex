# 下一项实体试验：先证明看得清，再做两支笔

**建议的具体动作（尚未执行/购买）：**直接用用户已有MMSYDZ-ESP32-S3-HDSF035V1.0 RevA SC035HGS模组（13mm主体、18mm安装孔距、21.82mm含耳宽）夹在可调台架。使用已有可工作的采集板，在电子负责人确认输入和电平后外部限流供电；可见光下扫镜头前端到纸面3–15mm，先固定原镜头不拆胶，采集原始静态点阵图。没有清晰近场图再确认能否调焦；无法近焦才启动新镜头/相机询价。**首轮不需要买新摄像头、不带电池、不先开未知功率IR，也不投生产PCB。**可用现有尺、纸、刚性夹具降低台架成本；需新增适配件的费用仍应列账。已有模块通过不能替换后续不同镜头验收。

## 用户需提供

1. 现有摄像头正反面和FPC照片、标签、购买链接、供应商引脚表及驱动（若没有则保持不上电）；使用的主控型号和可用相机接口。
2. 纸张/点阵PDF原文件、真实打印机型号、打印设置、墨粉/墨水型号、纸批次及带尺的显微照片；不要只给手机截图或JPEG压缩图。
3. 笔芯型号/批次/颜色、实际总长/外径/笔尖尺寸，以及允许的最小笔径；30–60°是相对纸面还是法线、常见书写最高速度、目标精度（RMS/95分位/最大值）及可接受丢点率。
4. 台架原始RAW/无损灰度图、完整时间戳、曝光/增益/帧率/LED电流寄存器及实测电源波形。没有原始数据不能替用户宣布通过。

## IR照明/材料的边界

[Vishay眼安全应用说明](https://www.vishay.com/docs/81935/eyesafe.pdf)强调应评估最终产品的光学、机械和驱动条件，不能直接从LED器件推断整机安全。这里只提出设计控制，不出具IEC62471合格或法律保证。也不把其示例测量距离/辐射限值直接套到笔尖近眼情境。

- 在未选定LED、发光面积/角度、波长、限流和最终镜窗前，没有可辩护的“安全电流”数值。采用硬件限流、默认关闭、看门狗超时关灯，尽可能仅在可信纸面接近/笔触条件下开启；纸面检测不是唯一保护。
- 短曝光需要强光时不能任意加峰值电流。数据表脉冲电流额定值有脉宽、温度及占空比条件；故障常亮也要受限。占空比D=f×t（每帧单脉冲）：180fps×60µs约1.08%，但低平均功率不自动证明脉冲眼安全。LED需要覆盖真正全局曝光窗，而非凭VSYNC任意打光。
- 应评估正常使用、抬笔、笔尖朝眼、反光表面、固件卡死/灯常亮、儿童可接触等可预见状态；由有能力人员按目标市场适用标准确认测试方案后才人体手持试写未知IR样机。不要让用户直视或用放大镜检查亮灯。
- [Anoto打印要求](https://support.anoto.com/article/1492-general-printer-requirements)说明其系统通过黑色碳墨的红外特性读取点阵，打印质量及CMY→K转换会影响识别。该事实**不能证明自定义点阵、任意黑色打印、某支蓝/黑笔芯兼容**，也不授予Anoto专利/码制许可。
- 要分别测：点阵在选定波长的吸收、纸的反射/荧光、正文印刷、笔芯墨迹。笔芯最好在目标IR下不遮挡点阵，但这必须来自实际墨迹图像/透过或反射测试；不能凭品牌、油性/中性或肉眼颜色作保证。

**此台架的停止条件：**找到一套可重复满足G0–G4的明确SKU/镜头/照明/打印/笔芯组合才进入笔壳和电池冻结；若短曝光SNR、斜视景深或预算失败，给出数据后修改目标或器件，不在缺数据时继续堆壳体。
