# SC035HGS 资料结论与模组验证边界

记录日期：2026-10-28。基于用户提供的 SC035HGS V0.3 数据手册、DVP V1.0 应用指南、MMSYDZ 模组尺寸图及厂家初始化文件重新整理。厂家原件标有保密信息，不在此仓库分发 PDF、图纸截图或完整寄存器表；下文为针对本项目的独立工程结论。

## 已确认与仍未知的边界

- 用户确认实物传感器为 **SC035HGS**。初始化文件中的 SC031GS 名称是沿用模板，不再作为型号疑点。
- 芯片 I/O 工作在 1.8 V 域；不能将 ESP32 的 3.3 V 推挽输出或 3.3 V 上拉直接接入。模组标注 3.3 V 电源输入不等于所有信号具有 3.3 V 容限，也不能证明内部稳压和电平转换电路。
- 芯片硬件关断为低有效，但模组 FPC 上的 RESET、PWDN 名称不能自动映射到芯片脚。必须获得模组映射确认，不能套用 OV 摄像头极性。
- 资料对 DVP 数据标签和部分方向列存在不一致。按模组 D0–D7 名称接线后，仍需用测试图/位权和波形验证，不凭标签猜测换线或对收到的字节右移。
- 初始化文件的地址表示需区分 8 位写地址与 7 位 API 地址。0x30 是待 ACK 验证的 7 位初始候选，不是已经点亮的证据。
- 工厂出图仅证明其测试链路可以成像，不能证明用户的 ESP32-S3 已点亮、能在所需近焦距离解码，或能捕捉快速书写。

## 曝光与时钟：条件计算，不是测量

厂家文件名标示 72 MHz 像素时钟，配置的总行长为 878、总帧长为 1366，曝光字段对应 328 行。仅在实际像素时钟确为 72 MHz 且该配置有效时：

- 帧率约 60.03 fps；每行约 12.19 μs。
- 曝光约 4.00 ms，而不是已经达到 1–2 ms。
- 纸面相对速度为 0.5 m/s 时，4 ms 对应约 2 mm 的曝光期间位移。

因此，静态网格清楚不足以证明动态码点清楚。必须读取曝光/增益状态并测量实际时钟或曝光信号，再取得短曝光的真实码纸原始图。

单纯增大帧长可以降低帧率，但不会自动降低瞬时 PCLK。也不能在 PLL 配置不变的情况下任意减小输入时钟并假定仍符合芯片约束。若 ESP32-S3 无法接收厂家现有时序，应索取经厂家验证的低 PCLK RAW8 配置，而不是盲改 PLL。

## 最小闭环清单

1. 模组电源内部连接、功耗、FPC 所有输入的电平容限和 RESET/PWDN 映射。
2. 八条数据的位权、同步极性、采样沿、真实 PCLK 及首帧测试图。
3. 原始灰度图及对应的点阵间距、镜头前端到纸面的距离、曝光与增益。
4. 镜头近焦范围和滤镜透过信息。芯片具有近红外响应不代表整套镜头没有 IR-cut。
5. 先验证现有相机的光学可行性，再锁定最终小型模组、笔壳和主 PCB。
