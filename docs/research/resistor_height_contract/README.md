# 精确电阻高度候选合同（未放行制造）

只覆盖 `contract.json` 明列的 9 个电阻；原板、原理图、冻结机械报告均未改。

- R104、R240：YAGEO RC0603FR-0710KL，10 kΩ，1%。
- R221、R224、R233、R218、R210、R228：RC0603FR-07100KL，100 kΩ，1%。
- R236：RC0603FR-074K7L，4.7 kΩ，1%；保留 RESET_CANDIDATE，不能因选定电阻就宣称未知相机复位兼容。

三个精确料号的官方规格均为 0603 / 1608、0.1 W（70 °C）、75 V 连续上限、±100 ppm/°C、−55 至 +155 °C。实际工作电压还受 sqrt(P×R) 和温度降额限制。仅作为保守电阻承压筛查，假设两端 5.5 V、阻值 −1%，功率分别约 3.056 / 0.306 / 6.501 mW；这不是 GPIO 允许承受 5.5 V 的声明，也不是整个系统热验证。原阻值、精度及网络未更改。R240 的 100 kHz 初始上拉仍需实测上升沿。

官方精确料号尺寸为 1.6±0.1 × 0.8±0.1 × 0.45±0.1 mm。仅这 9 refs 可在独立机械比较中使用 **0.55 mm 本体上限 + 0.15 mm 明示焊料/装配假设 = 0.70 mm 铜面外高度**。0.15 mm 不是厂家保证，需装配确认。四个电容 C103/C203/C201/C205、其他器件和线束不得连带降低。XY 仍保持当前保守原生实体/焊盘外框，不能只缩 Z 后偷偷缩 XY。

## 焊盘兼容边界

已目视核对 [YAGEO Mounting V.10](https://yageogroup.com/content/Resource%20Library/Product%20Guide-Catalog/yageo_PYu-R_Mount_10_19050818_343.pdf) 第 4 页图 4 / 表 1：0603 回流推荐总长 A=2.6、内隙 B=0.8、单盘长 C=0.9、宽 D=0.8 mm。

所有官方精确料号规格链接、采购目录链接、逐 ref 原值/网络/焊盘/源哈希均在 JSON。采购链接只证明目录可检索，不承诺库存或价格。此合同允许有条件比较空间，不代表最终 BOM 采购批准或功能验证完成。
