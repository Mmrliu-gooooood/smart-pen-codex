## 八、固定400的剩余额公式与最小报价门

设：`F`＝最终实际PCB装配固定项（工程/钢网/多款去重）；`K=111.96`＝上述5项两支装机成本样本；`M`＝两颗真正可买PICO及所需备料；`Q`＝BQ两颗等**其余全部电子**及采购MOQ/损耗；`O`＝两套相机/镜头按明确历史/新增口径；`B`＝两只合格电池；`P`＝所有PCB/FPC实付MOQ订单；`S`＝结构/笔芯/线束；`A`＝尚未包含的上料/贴点/检查/夹具/人工/校准/返工/税。

```
两支总成本 = F + K + M + Q + O + B + P + S + A  ≤ 760
若仅假定 F = 400：M + Q + O + B + P + S + A ≤ 248.04
若再仅参考缺货PICO 62×2：Q + O + B + P + S + A ≤ 124.04
若参考原厂样品37×2（非现货承诺）：余项 ≤ 174.04
```

没有把未知填0，亦无合理依据给这些余项随意分配5/10/20元。PICO缺货价格是可比情景，不是可以购买。即使400实现，还要以上全部余项报价闭合才可判通过；按现有数据**尚不能证明容纳相机/MCU/电池**，也不能证明所有国内渠道必不容纳。

建议次序（研究路线，不是已批准≤760路线）：

1. 不改电路，先锁完整候选MPN、两支净用量与SMT余料；先解决PICO/BQ/稀少TPS3899国内小量可售性，再补其他高值件和相机/电池；新旧持有物分账。
2. 用本报告真实面别列表比“仅隐焊点+必要0402代贴，其余有价人工”与整面标准SMT；列足全部板族和检验范围。必须有可履约价格，不能把未报价当通过。
3. 若部件/光机费用仍有余量，再让lead评审同栈工程统一是否值得。先取得“多款合拼按几面/几款收费、层数厚度可做、实际板MOQ”的条件报价输入；本次不提交设计。不为纸面节省先改四层为六层。
4. 如果现行电源保护实现的器件/两面装配持续成为主要成本，可继续**保持安全功能**的架构研究，而不是批准删电路：见 `docs/research/power_architecture_tradeoff/README.md`、`docs/research/high_beta_ntc_followup_20261028/README.md`。BQ25170+TDK B57371V2103H060是值得验证的高βNTC候选，静态角点热断[36,44]°C、冷断[2,9]°C/恢复保证窗12–33°C，不是0–45全域能充。仅适合0–45类电池边界研究，不适合10–45电池；BQ25170无SYS powerpath，需要默认安全的**硬件充电停写/负载隔离**、正确终止、USB防反灌、NTC开短路/贴附/延迟热裕度及电芯保护验证。不得从当前50实体方案贵推导“安全无解”。
