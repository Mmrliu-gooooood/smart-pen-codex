# 首样计量目标勘误（独立增补，不修改已冻 RevB / RevC）

**“≤0.005 mm”是为自定窄触发窗选择的研究计量目标，不是 ALPS 原厂要求，也不是首样必须购买 5µm 量具的结论。** 成本表不得据此锁定该项采购。普通卡尺同样不能仅凭显示分辨率被当作达标仪器。

原 RevB 采用自定真实 ON 行程窗 [0.08,0.12] mm，总宽 .04 mm。若测量结果 m 的可信误差界为 ±U，要保证真实值在 [a,b]，必须使用保护带后的接受条件：

`a + U ≤ m ≤ b − U`，可用接受窗宽 `b−a−2U`。

- U=.005 → 测得 ON 只接受 [.085,.115]，宽 .030 mm；
- U=.010 → [.090,.110]，宽 .020 mm；
- U=.020 → [.100,.100]，零宽，现实重复测量无稳健接受范围；
- U>.020 → 该原窗口下无可行接受区。

因此 5µm **不是唯一必要值**；它是原窄窗口的自定裕量选择，不是由最大/最小安全行程唯一反推。U 是本测量方法的能力输入，须包含仪器实际误差、校准、分辨率、夹具柔度/零位、方向、重复性、读数与温度等，不能把“0.01mm 分辨率”直接代入 U=.01。若使用扩展不确定度而非有界误差，上式只能按声明的覆盖概率提供保证，不能说成绝对保证。

下一版应先取得实际可用仪器与测法能力，再选择有足够宽度的触发/止挡验收窗口；可研究更宽 ON 窗口和可替换止挡，避免为纸面小窗口要求不现实工艺。**.25mm 总行程降为待测小行程候选；.35mm 也仅是待比较实验值，本勘误未批准它、未改 CAD、未保证其书写精度。** 不得用降低计量要求冒充原窗口已满足。

逐件至少记录：无载电气断开、加载 ON 位移、卸载 OFF 位移、回差、硬止挡位移、重复性、仪器/校准/不确定度、装配和笔芯身份。OFF 的真值下界也必须留 U 保护带。原厂未知保证回差意味着某些开关可能无法同时满足无载断开、可靠触发、可靠释放和止挡安全；**不得要求所有公差开关必收，不得用软件屏蔽常闭**。SPVE 最小50µA@3V/50k次目录寿命以及 AON 和前端条件门保持不变。

共同支架“每轴 .01mm”同样只是拟测目标，不是已证明的固定后允许位移、线材允许应变或制造精度。短直线没有服务余量；没有线材/焊点疲劳允许值，就不得因夹具读数小而宣布寿命通过。

## 不能遗漏的笔尖平面误差

设机械轴向相对行程为 d，笔轴相对纸面法线夹角为 θ，则未补偿行程的纸面投影量为 `d sin θ`。本增补的30/45/60°均从纸面法线量起；不是从纸面量起。若关心触发后继续压缩，应以实际 `d=硬止挡位置−ON位置` 及其误差界计算，而不是只看名义总行程。

| 轴向行程 |30°|45°|60°|
|---|---:|---:|---:|
|.25mm（对照）|.1250|.1768|.2165|
|.35mm（未批准实验值）|.1750|.2475|.3031|

这是几何误差预算项，不是已经完成补偿后的误差。真实笔芯轴线、实际笔尖面、纸面姿态、机构压缩与光学外参尚未联合标定；不能只改善装配就称准确性无损，二值接触信号本身不测连续压缩量。
