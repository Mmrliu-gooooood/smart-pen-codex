## 已实际查到的候选

在[官方当前阻抗计算器](https://jlcpcb.com/pcb-impedance-calculator)输入 Rigid / 6层 / 0.8mm / 外1oz / 内0.5oz / L1对L2 / 50Ω。选中带 recommend 的 **JLC06081H-2116，Standard/Finished thickness0.83±0.10mm**，不是首个未标推荐的结果。保存两张实际页面截图和最终DOM观察。计算器模型返回：

| 模型（非“without solder mask”） | 线宽mm | 同层地间隙mm |
|---|---:|---:|
| Single Ended (Non coplanar) | 0.1814 | 不适用 |
| Coplanar Single Ended | 0.1707 | 输入0.2，输出0.1999 |

以上为**官方计算器输出**，不是本地独立场求解或本板测量。UI的0.5%为计算容差，不能替代工厂标准±10%受控阻抗规格。不要直接拿微带宽度用于两侧紧贴地的CPWG，也不要改变阻焊/参考层后继续沿用数值。0.1707只是保留原始结果精度，不暗示加工精度；实际Gerber线宽舍入应重新核算并由工厂确认。

合计0.8264mm，与显示0.83近似相符。**不得再把铜厚加一次。** 页面未明确说明“finished”厚度量测是否含阻焊；机械合同保留这一未知项。按显示上界先做0.93mm条件包络，比原CAD0.80增0.13。不能把总厚公差平均分给每层介质，亦没有查得各层独立公差保证。RF场分布/损耗仍受材料批次、铜蚀刻、阻焊和实际布线影响。

## 同名不同表的问题

公开模板查询端点由当前官方页面JS给出，使用无账户、无设计上传的模板查询，响应正常。`public_template_extract.json`保留读取时间、请求参数、选择字段和原始响应SHA，不保留网页脚本或订单数据。

- 同名 JLC06081H-2116 的“No requirement”记录中央介质0.2028；显式模板记录却为0.2104。
- 实际计算器推荐结果明确0.2028，与“No requirement”记录一致。**仅凭模板名字不够锁定结构**；本候选以截图、完整11项物理表和型号一起锁定，生产前必须核对工厂工程文件。
- [旧cart静态页](https://cart.jlcpcb.com/client/template/placeOrder/impedance.html)六层只显示1.2/1.6/2.0mm，并使用旧介电参数。不得用它否认当前0.8可用，也不得把旧Dk混入新计算。
- 查询同时确认 JLC06081H-1080B、JLC06081H-7628A 等名义0.8六层结构存在。不同后缀可能属Special；没有批准成本/交期等价替换。

- JLC04081H-7628（四层名义0.8）：外介质0.2104、中心core0.25mm，同铜配置。
- JLC06101H-3313（六层名义1.0）：外介质0.0994、两core各0.25、中心prepreg0.2104mm，同铜配置。

这些是查询记录，不是已经选定或已运行相应50Ω计算。四层减少工艺层数但不能解决目前已观察到的TRIG通道切断AON问题；需要重新放置/布线才能公平比较。六层方案可采用F信号/In1地/In2电源/In3信号/In4地/B信号，但平面是否连续、换层回流与铜净空仍须逐板检查。层数增加本身不保证EMI或SI。

## 公共制造边界与本板含义

[官方制造能力](https://jlcpcb.com/capabilities/pcb-capabilities)给出多层1oz线路0.09/0.09mm、优选via钻孔0.2mm；钻0.2/0.25且盘径小于0.45会增费。因此目前0.45/0.2通孔和0.127/0.127线路在公开能力内，不等于本板DFM批准。Via环宽0.125mm不可与普通元件PTH环宽规则混为一谈。孔到异网铜、钻孔位置公差、内层避空仍要检查。普通线宽公差±20%不代表已开启阻抗控制。

铣边普通尺寸公差±0.2mm；高精度±0.1有尺寸/工装条件，12mm窄板不能自动假设可单板满足。六层无HASL选项；通孔填塞/封盖的实际工艺要明确，不能因宣传“free via-in-pad”就把任何裸孔当安全焊盘孔。12×101.5纵横比约8.46，需考虑长窄板装夹、翘曲、拼板连接与去板应力。[尺寸说明](https://jlcpcb.com/help/article/pcb-dimensions)明确大纵横比需制造审核。

## 380元预算不能从裸板广告推出

[当前官方促销页](https://jlcpcb.com/ads/pcb-prototype)六至八层$2起价对应5片50×50mm促销尺寸。12×101.5不是50×50，甚至长度超过四层100×100促销框；不得因面积小就套同价。是否重新拼板仍需算尺寸、层数、设计种数和工艺边。

[官方贴装能力](https://jlcpcb.com/capabilities/pcb-assembly-capabilities)经济贴装仅单面且仅标准叠层；标准支持双面，最小单板/拼板为70×70mm。当前主板和电源板有背面器件，不能直接按经济贴装报价。页面概览称经济支持2/4/6层、0.8–1.6，但具体组合表有限制；未通过实际订单组合核验，**不保证0.8六层可走经济贴装**。

[官方价格表](https://jlcpcb.com/help/article/pcb-assembly-price)当前标准双面setup$51.12、stencil$16.42，两项合计$67.54/订单（两片均摊$33.77/片），尚不含裸板、元件、上料、X-ray、夹具、拼板等。不是本项目报价，也未换汇或把该美元价当国内嘉立创报价。同一板族的两面与不同层数板族不能随意合并省去setup。

可在后续成本评估中比较单面机器贴装+少量背面人工、学校装配或国内服务报价；每条路线仍需合格焊接/检测，PICO等焊盘不可仅靠“愿意手焊”消除质量要求。本次未改变板层、装配路线或预算。
