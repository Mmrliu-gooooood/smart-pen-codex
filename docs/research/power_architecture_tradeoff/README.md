# 点阵笔电源架构复杂度复盘（独立研究，2026-10-28）

**结论：可以重新研究更简单的电源架构，但目前没有一款经本次验证可以直接删去现有温控链的替代。不能为缩体积，先删除安全功能再补证明。保持冻结源、JP1 开路与 NOFAB。**

本次只写研究文件，不修改原理图、PCB、BOM 选定状态，不采购、不上传。源码推论、数据表边界与实物验证分开。

## 1. 哪些是用户要求，哪些是工程选择

明确要求：准确与安全优先，之后体积；单支380元、两支样机；有电池保护和充电管理；续航可取舍。用户没有明确要求双独立NTC、6颗独立温控IC、20–30°C恢复窗口或“所有任意单故障均安全”认证。

现架构采用第二NTC、精密基准、双监督及串联模拟开关，是为已选 BQ24074 与候选电池温区不相合等问题建立保守许可链的工程选择。不能把这个选择误记为用户不可更改要求；同样不能因为它不是用户逐项指定，就任意削弱保护。必须先锁定具体电芯允许温区、全部误差、所需故障覆盖和产品验证计划，再比较替代。

当前10–45°C目标覆盖Jauch候选；Keeppower记录为0–45°C。不能在还没有选定电池时，用前者温区锁死所有架构，也不能用后者放宽已选电池的要求。后者厂家网页本轮读取失败，温区仅沿用已有源记录，必须采购前再次核验。

## 3. 原生TS能否替代独立链

[BQ24074 Rev N，§8.5/9.3.6](https://www.ti.com/lit/ds/symlink/bq24074.pdf)规定TS电流和阈值；其103AT-2示例窗口约0–50°C，所示被动串并补偿只扩宽，不能收窄。原生TS、芯片过温、包保护是不同功能，不能互相代替。

本次用当前 Vishay NTCLE100E3103GB0 的材料9多项式、R25±2%及B误差表，独立枚举TS电流/阈值角点，不使用简单B指数外推。详见 screen_ts.py 与 ts_screen.json；插值是数学筛选，尚未加入贴合、自热、污染、线束或响应延迟。

| 充电器与同一NTC直连 | 冷停止范围/°C | 热停止范围/°C | 0°C冷端裕量 | 45°C热端裕量 |
|---|---:|---:|---:|---:|
| BQ24074 | 0.67…5.30 | 43.14…51.82 | +75.94mV | −80.01mV |
| BQ25170 | 1.13…5.76 | 38.70…45.18 | +63.77mV | −1.25mV |
| BQ25185 | 1.74…6.44 | 50.61…59.02 | +96.27mV | −72.25mV |

因此三者“直接换芯片/直接接现有NTC”均不能保证45°C已禁充；对10°C下限也均不满足。**BQ25170的0.18°C越界不能靠四舍五入或典型参数消掉。** 当前比较只否定这些特定组合，不证明所有充电器/NTC都不可能。

[BQ25170 Rev A](https://www.ti.com/lit/ds/symlink/bq25170.pdf)是2×2mm、无独立SYS电源路径的充电器，标称0–45°C不等于全误差边界。它可以作为“充电期间硬件停写”的简化研究，但要先选择完整R/T有保证的NTC/网络，再解决负载影响终止与USB寄生供电。

[BQ25185 Rev B（2026-08）](https://www.ti.com/lit/ds/symlink/bq25185.pdf)保留电源路径、2.2×2.0mm，按电阻设定；其当前热阈值不是45°C硬停。产品检索标签中出现JEITA不能替代芯片数据表。不得用小封装理由直接省去外链。此前BQ25186研究的复位温窗/默认输入电流风险仍有效，本次不重复批准它。

[Vishay NTCLE100E3 Rev 2025-05](https://www.vishay.com/docs/29049/ntcle100.pdf)给出本次曲线与误差。该引线件不是已经合格的笔内薄型传感器；其涂层无规定绝缘特性，也不意味着任意灌封/胶粘工艺合格。新薄型NTC必须重新算曲线与误差，不能继承上述数字。

## 4. 比较选项与真正的取舍

A. **继续现有集成链**：50封装、630mm²已有实际路由和检查，近期返工较少；代价是空间、调试和故障组合增多。最新单点温控供电候选另有独立审查，本文不替它放行。1.167mV是冷端恢复可用性余量，不是整个安全链的唯一安全余量。

B. **换更适合电池温区的充电器+合格单NTC**：理想可移除上述27件温控增量，保留TPS63802；但这只是相对于现图的候选删除集合，尚无替代原理图和布局，实际批准节省为0。BQ25185/25186没有解决当前要求；不要暗换。

C. **BQ25170充电时硬件关闭写字负载**：电源路径需求下降，有机会只保留充电器、TPS63802和少量负载禁用器件。实际对照表仍是当前23/50封装，不能凭应用图声称新板17件或20件即完成。必须补：合格温窗、独立于固件的负载关闭、USB数据/外设反灌、失电及默认状态、充满终止与计时、输入总限流、插拔恢复。需要用户接受充电不能写；当前没有此授权选定。

D. **首版可拆电池外充/大头台架**：可以把光学与坐标风险先验证，但改变成品充电体验和成本归属。专用外充器也必须计价与验证，不能悄悄把充电安全/成本移到“免费外设”。本次不建议直接选定，仅保留首样风险分拆选项。

推荐：在推进当前安全候选的同时，把B/C作为有边界的另线研究；先定实际可采购电池允许温区与峰值，再做一张完整的替代原理图和故障矩阵，满足后才切换。不要因18mm困难直接扩大笔壳，也不要为了18mm直接删安全链。

## 5. 单故障边界（当前复杂度也不等于认证）

- NTC开路/短路：原生TS健康时可形成超窗口禁止；必须实际验证偏置顺应电压、泄漏、上电与温度响应。电气未断但传感器脱落仍可能读正常空气温度。
- 单NTC/单芯片故障：独立性减弱，不能继承双链论证；是否可接受需产品风险分析，不能用“用户没要求双NTC”代替分析。
- 双NTC共用胶粘、地、供电、充电器：存在共因。当前CE硬短到地或内部充电器失效可绕过外链；原BQ窗口又未覆盖严格45°C。故不能宣称现有复杂链已满足任意单故障安全。
- 包PCM负责其已定义的过充/过放/过流/短路功能；没有温感证据不能宣称它提供电池温控。保护阈值与延迟仍要和电芯协调。
- 充电芯片内部热调节针对结温，不等于握持表面或电池温度安全；所有方案均需封闭壳温升与异常测试。
- 本地CE默认禁用、commissioning桥、USB预授权电流与反接/保险/线束保持都不可因架构简化自动删除。
