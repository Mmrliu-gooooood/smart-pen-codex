# SC035专用接口隔离原理图草案

独立草案，未合并主板，不能制造或上电。打开sc035_adapter_draft.kicad_pro。

32元件，ERC0违规。30针模块2/28为3V3输入；主板参考J202.23为1.8V，不可直接相接。模块电源评估复用主板J301受控3V3候选，而非自动再堆叠开关。TPS22918不保证反向阻断/限流。

TMUX1511RWBR为SCCB隔离候选。实际主板上拉不因缓冲器EN低而物理断开；需要模块电源资格信号，而该信号尚未证实。U1、链接及READY入口保持DNP，READY未分配。RESET/PWDN实际映射不明，保持隔离。SC031独立维护，不视为可互换。

本图使用逻辑研究符号，实际连接器/封装/电源/去耦与全部失电路径尚未定型。`verify.py`检查随附网表与4项负例，不能证明硬件安全。
