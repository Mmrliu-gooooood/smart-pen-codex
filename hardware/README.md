## 制造放行前仍需完成

- 光学近焦、点阵尺寸、倾角、短曝光与原始图像验证，确定镜头和板型。
- 模组真实引脚、电平、复位/关断映射及采样时序核对。
- 主板布局布线、回流路径、USB/RF/高速 DVP、电池和机械公差联合审核。
- 电池数据表、保护阈值、NTC 接触与断短路安全、USB 取电模式和温升验证。
- 实际落笔、拿起唤醒、离线补传、无线、升级、低功耗和故障恢复测试。
- 两支样机完整报价核算，不能把目标预算当作已获得的报价。

参见 [整体放行门槛](../docs/system/RELEASE_GATES.md) 和 [摄像头资料结论](../docs/optics/SC035HGS_DOCUMENT_REVIEW.md)。

## 重建版的使用限制

MCU 引脚分配以新提交的 `mcu_usb/gpio_assignment.json` 为准，不保证与遗失工作副本或旧程序相同。既有合成 BLE 测试固件不是本硬件的完整驱动，摄像头固件、隔离控制、上电时序尚未联调，不可直接套用旧引脚表。

本次三模块独立审阅见 [检查报告](../docs/verification/ELECTRICAL_REVIEW_20261028.md)。跨模块名称核对不等于物理集成，见 [接口约束](../docs/electronics/integration_contract.md)。
