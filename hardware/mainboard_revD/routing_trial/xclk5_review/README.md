2. 为避开B面VIO阻挡，**仅 VIO 两既有via(8.85,43.15)↔(8.85,53.15)间供电段**从B改In2绕行。旧10段10.497056mm，新5段11.118377mm，保持.15mm宽，不增VIO孔。新路径：(8.85,43.15)→(9.5,43.8)→(9.5,47.75)→(10.2,48.45)→(10.2,51.8)→(8.85,53.15)。直接按旧坐标迁层会撞SDA，已拒绝。

4. 新增XCLK标准.6/.3孔仅2只：(10.25,9.025)、(1.95,49.05)。**XCLK本身仅F/B，没有使用In2短桥**，也未扩7个小孔白名单。

## 真实连接、供电与返回门槛
- 写盘重载逐新UUID断言新增XCLK仍是XCLK、VIO仍是VIO；不靠DRC低数推断网络。与VIO迁层板相比所有原铜保持，新增只有XCLK。
- 51个多pad信号网逐实际铜图检查匹配native DRC；8数据主路未断，剩D7只是偏置支路。27 AON（含PICO六供电脚）、75 GND、11 VIO均逐端实际连通。In1一连通区，In2仍3区桥连。
- 输入长In2路径仍有约0.2mm级局部狭颈；新板25µm腐蚀筛查与前版相同：半径.10mm仍通、.125mm断。不是整59.45mm轴距均为细线，也不是已证不安全；完整实际电流/铜厚/孔/压降/瞬态未批准。
- VIO迁层保持线宽**不等于保持电阻/PI**：内外铜厚未定；实际负载/上电/边沿未测。此约11mm供电拓扑调整不是原1–2mm短clock桥许可，已有独立授权并单列。
- 新XCLK沿线按实际In1填充polygon做每≤.05mm中心/±半宽采样，178/4044样点下方缺直接地。不是精确面积比例，也不是回流/阻抗认证。新两孔最近GND via分别2.799665/2.128967mm，仅几何距离。
- **B面最近参考层是In2电源，不可仅凭In1整体连续就称B时钟回流连续**。实际叠层、In2岛/边缘、电源去耦耦合、边沿/串扰/阻抗须专门审查；本长时钟路径不能承诺24MHz或72MHz性能通过。

## 已拒失败与生成器护栏
拟在y43放1.1mm In2 clock桥的两个标准孔落入U202.16 VIO焊盘。KiCad把孤立新铜自动归VIO，低DRC数字失去XCLK含义；逐UUID期望网检查已捕获并STOP。失败板在兄弟研究目录，不是本板来源。后续生成器必须在写盘重载后核字面预期net，不从错误读回值生成“合同”。
