# USB4105 定位孔—地焊盘 DFM 评估（2026-10-28）

## 实测几何，不是四个独立物理问题
Rev A J101 旋转 180°、位置(6,3.675) mm：

|NPTH 中心/mm|孔径/mm|相邻地 pad 中心/mm|同位 pad 编号|
|---|---|---|---|
|(8.890,6.280)|0.650|(9.200,7.355)|A1、B12|
|(3.110,6.280)|0.650|(2.800,7.355)|A12、B1|

地铜尺寸 0.60×1.15、圆角 R0.15。两个逻辑编号共位的铜实际重叠，不是应分离的不同网络；然而 NPTH 无铜孔的加工净距与是否同网无关。

最近距离为圆孔到圆角边，而不是中心距减半宽：
`hypot(0.31-(0.30-0.15), 1.075-(0.575-0.15)) - 0.15 - 0.325 = 0.1944027 mm`（以脚本精确值为准）。
若当尖角矩形，距离为 `hypot(0.01,0.50)-0.325≈0.1751 mm`，不能拿矩形距离或四舍五入0.2冒充真实当前铜形状通过。

GCT B4 推荐图：地 pad 横向中心跨距6.40、两定位孔跨距5.78；推荐 pad 0.60×1.15；定位孔 Ø0.65；纵向中心差由图基准得1.075。图标推荐布局公差±0.05。当前 KiCad 采用圆角而原图未给圆角半径，这是库的工艺化表达；不能把库铜形状等同原厂逐点批准。

## 0.25 的含义和真实厂能力
A 的 0.25 mm 是工程初始保守规则，并非已选定板厂合同硬限。可是 [嘉立创中文官方能力](https://www.jlc.com/portal/vtechnology.html) 明确 NPTH 到铜 ≥0.20，包含线路、焊盘、铜皮；[JLCPCB 英文能力](https://jlcpcb.com/capabilities/pcb-capabilities/) 的 NPTH-to-track 0.20 不构成 pad 豁免。A 比0.20少约0.00560 mm，名义上未达该公开常规能力，不宣称板一定做不出来，也不能把差值当数值误差忽略。

孔径、位置、蚀刻有公差；孔径增加0.05会单独吞掉0.025径向净距，孔偏心还会减少净距。不能用 GCT ±0.05 当成许可让制造孔径缩小或位置随意偏移；不应重复从板厂已经定义的设计规则扣除不明公差再称成品绝对值。需工艺审核实际工具孔径、位置和铜蚀刻预算。

另有明确较紧工艺：[Precoplat 官方技术条款](https://www.precoplat.de/en/technical-delivery-terms-tlb-recommendations-and-design-rules-for-printed-circuit-boards/)，2026-05-12 导出、p18，NPTH 外层孔切线到导体 Standard0.20 / Special0.15 / Technical0.05 mm；内层分别0.25/0.20/0.10。它说明0.1944并非普遍不可制造。**未选择该厂、未获本板焊盘适用确认或报价，不证明¥380预算可承受**。没有凭这个表修改 A 全局规则。尝试独立条件规则研究并未作为交付可用工艺配置；不存在隐藏违规的量产profile。

## 可执行的低成本几何路径
独立 `../usb_tail_revB` 已实际生成：仅两块地铜靠孔端缩0.08（四逻辑 pad 一致），远端不动。净距0.272329，全局仍0.25，真实 DRC/ERC/parity 均0，非靠改规则。但 GCT 图缺少足够的最坏焊接接触尺寸链，故这是**装配待核候选**，不是已批准原厂替代。图给的16×0.20尾脚宽可核横向覆盖，不能独自证明纵向 heel 覆盖。候选仍保留0.60宽，长度1.07；矩形面积减少6.96%、实际圆角铜面积减少约7.16%。

因此闭环结论分两层：电子/几何上已提供无需特殊板厂且保留原规则的可编辑候选并新检查；生产放行仍需这一项明确装配尺寸/焊接DFM。若其不通过，则选择有明确0.1944孔铜距承诺的工艺或更换连接器，并重新检查。不能把改焊盘本身称工艺资格已闭环。
