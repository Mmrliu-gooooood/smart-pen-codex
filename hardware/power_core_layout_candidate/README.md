# 电源核心 LAYOUT-P0 — 已布线候选，NO FAB

2026-10-28 独立新版本，不覆盖冻结核心。**不是电池/充电或生产放行。JP1 必须保持物理开路。**

## 真实完成范围

- 原生 KiCad 原理图、23 个真实带网络封装/71 个 pad shape，12×35×0.8 mm 四层 PCB；既有 BQ24074 + TPS63802 电路的电源回路、反馈、NTC、慢控均已实际布线。
- 新 ERC 0；新 native DRC **0 违规、0 未连、0 原理图一致性错误**。无豁免，无规则降级：0.15 mm 间距、0.5 mm 铜到板边、0.6/0.3 mm 过孔。
- `verify_design.py` 从源 XML 与实际 PCB 做280项断言，独立核16个多端点网络的轨迹/过孔/焊盘接触/实际填铜连接，而非读取绘图脚本或只看ratsnest。全部源值保留，仅电感从TBD定为具体候选，JP1地端改为外部许可端，新增十个外部端点。
- In1 GND 与 In2 SYS 均为真实填充单连通区；25 µm栅格及0.10–0.25 mm腐蚀筛查仍单主区。SYS两供电端之间最大瓶颈路径宽度筛查约0.7 mm，**不是电流/温升认证**。

## 安全接口变更

旧 `CHARGE_DISABLE→JP1→GND` 的直接接地旁路已移除。本版是 `CHARGE_DISABLE→JP1(OPEN/DNP)→CE_PERMISSION_EXTERNAL`，到J5.3，不能随意接地。R6 10k仍在本板，负责独立默认禁用；与新的硬件温控许可链整合时必须按合同去重CE上拉和commissioning门，不能照抄并联旧旁路。外部安全链、NTC/电池未资格化，当前不能闭合JP1。

| 接口 | 实际 pad 顺序 |
|---|---|
| J1 | 1=PACK_NTC，2=保护后GND |
| J2 | 1=VBUS_5V，2=GND |
| J3 | 1=3V3_AON，2=GND |
| J4 | 1=PACK_PLUS_PROTECTED，2=保护后GND |
| J5 | 1=USB_EN1，2=USB_EN2，3=CE_PERMISSION_EXTERNAL，4=GND |

全部接口是自定义焊线铜地，不冒充已选连接器；线径、拉力释放、反插/反接、焊接工艺、完整封装后的三维空间仍未批准。禁止接裸CELL_MINUS绕过保护。J2外部需要已核USB-C/ESD；它不是任意输入电源接口。

## 原厂封装与物料边界

- **BQ24074RGTR：RGT0016B**。Rev N正文第7页明确B，但当前PDF附录第53页只有C。另一个TI官方产品PDF中的同编号B图证明其铜尺寸：外围0.6×0.25 mm/0.5 mm pitch、EP1.6 mm；不能据此证明实际采购批次一定是B。B/C不能混用；订购实物封装版本必须确认。B的EP焊膏刻意未生成，4个0.6/0.3热过孔为自有工程选择，填孔/钢网/焊接必须DFM。
- **TPS63802DLAR：DLA0010A**。已按原厂非对称10pad创建：左5个0.6×0.25，右4个0.9×0.25，pin8为1.3×0.25；不是普通DFN，也没有虚构第11/EP脚。IC最大高1.0 mm。
- **XFL4015-471MEC** 是本布局具体电感候选。按原厂0.98×3.4/pitch2.37 mm矩形焊盘；体4.0±0.3 mm，最大高1.60 mm。小型Murata替代尚未资格化。本候选并非全部器件最小尺寸方案。
- 8颗电阻采用0603几何，6颗MLCC采用0805几何，**精确可采购MPN未冻结**。电压/温度/容差/DC-bias下有效电容必须验证：TPS输入≥4µF、3.3V输出≥7µF。不能凭10µF、2×22µF印字放行。

## 实际电源回路与计算筛选

`preview/assembly_diagnostic.svg` 按实际PCB显示橙色SW、蓝色FB、参考号和pin1；不是生产装配图。SW在转换器上侧，FB在下侧，AGND在IC附近与功率GND连接。SW外部轮廓用器件内部直线闭合估计约6.006 mm²，仅用于布局比较，非真实电磁环路面积/EMI证明。

主功率轨迹最窄颈部0.3 mm；DLA原厂pad本身宽0.25 mm。SYS的0.15 mm段仅供EN高阻分支，VBUS的0.2 mm段仅供CE上拉。按**假设**外铜最小31.5µm、85°C，0.3 mm宽/10 mm长约22.9mΩ；1A时约22.9mV/22.9mW。实际铜厚、过孔镀厚和温升没有验收，不能把此电阻算例当载流量规格。

`power_screen.json` 的0.75A@3.3V、2.8V输入、80%效率是假设筛选，不是测得系统负载；对应平均输入约1.105A。开关频率只有特定条件典型值，脚本扫0.5–2.1MHz不是最坏保证。电感25°C 20%下降点5.4A低于转换器boost限流最大5.75A；正常包络与故障/全温饱和必须分别测，不称限流保护已自动协调。

## 不可省略的系统门槛

1. USB_EN默认LOW/LOW为USB100模式。**CE禁充不意味着PICO可任意取500mA**。未批准电池接入时，PICO启动/枚举能否在100mA输入限流下稳定必须实测；不能用枚举之后500mA授权反证枚举之前可启动。实验室台源与合规USB接口分开验证，不能靠擅加大输入电容掩盖。
2. R1=8.66k±1%对应约91.12–113.73mA，不是保证100mA；R2=3.24k±1%可到536.23mA，不是500mA硬上限。USB500授权应使用正确硬件模式，CE支路与其他VBUS负载仍计总电流。
3. 电芯充电电压/最大电流/温区、双NTC贴合及故障、实际外部许可链动态、低压停机与存储掉电行为未通过。正常低压运行能力不是电池放电截止保护。
4. BQ热耗散、封闭笔壳/皮肤温度、完整线束、整笔装配和预算尚未验收；该12×35板不是已经装进18mm笔的证明。
