# V4 投影解码：未采纳的离线实验

**有真实增益，但不能替换V3，也不具备30–60°可靠性资格。** 新代码未接入相机/app，未push，未改任何冻结V3文件。

## 已确认结果

- 原8张理想针孔图：V3为2正确/6拒绝；新实验为**6正确/2拒绝**。0/30/45°各两张正确，60°两张仍拒绝；成功图最大网格误差约0.103px。
- 独立120例保留测试：**37正确接受、0观察错误接受**；姿态29/48、采样2/24、噪声/模糊6/18；30个负例全部拒绝。姿态60°仅1/8通过，不能说可靠60°。
- 旧API原44 cold及12个可用warm逐字节一致；完整旧host85 tests无skip通过；V3原394文件及副本哈希不变。
- 新API最终原340+68回归发现**3个原must_reject负例被接受**：fov5/6/7的edge_stroke位于原96框边界、新80框之外。坐标本身正确仍属合同失败；因此本实验**未采纳、不集成**。340例中224正确、3合同违规接受、113拒绝；旧253接受例损失37例，新增11接受中8正确/3违规。68 adversarial为1正确、67拒绝（包括镜像/歧义）。数据见`regression_summary.json`。
- 四个旋转例的保守墨点外包方形越界，解析圆周极值却证明真实圆点仍有约0.497px余量；在结果中区分square/circle，不把不存在的方形角误说成错码。
- ASan/UBSan安全检查通过，包含参数/stride640/canary/随机噪声/容量溢出；seedcap=1故障注入证明overflow failclosed。LSan受运行器ptrace限制，未通过、未冒充通过。

## 改了什么

独立版本化9系数homography API；原像素80×80ROI；允许细长小连通域进入网格验证；中心36点获取，再渐进扩到全点做有界单应拟合。最终码位残差门限不放宽，不丢全框内outlier，不从正确答案拟合。

工作区36480B；32879粗候选；≤256种子×25迭代；≤128质心；无heap/RANSAC。详细确定性运算界和坐标合同见[DESIGN.zh-CN.md](DESIGN.zh-CN.md)，不是ESP32 FPS。没有SDK/物理相机性能结论。

## 采样不是缩放魔法

200原像素=6mm只对应同倍率全640px=19.2mm，**不等于全VGA=6mm**。如果全640px=6mm，内部80像素仅.75mm，装不下六个中心1.5mm/墨点支持约1.7mm。所有测试明确倍率，不悄悄resize。SC035仍未支持，SC031 provider仍OFF/未资格化；相机轴倾角不是握笔角，网格坐标不是笔尖坐标。

## 复现/证据

`./reproduce.sh`顺序执行冻结源校验、原8诊断、独立保留、原例回归、旧44、sanitizer和完整旧host。需要已有numpy/C编译器、同级冻结资料及完整host依赖；只写本目录/临时库，不需网络或私有厂商资料。**原回归负例门失败会返回非零，这是实验真实结果，不应删除断言让它变绿。**

- `component_diagnostics.json` / `model_diagnostics.json`：检测/ROI与拟合根因分离。
- `candidate_eight_oracle.json`：独立6成功图坐标/符号/完整支持/方向核验。
- `HELDOUT.zh-CN.md` / `heldout_results.json`：120例独立渲染器。
- `regression_results.json` / `regression_summary.json`：原340+68，新API安全/可用性边界。
- `final_host.log` / `legacy44_results.json`：旧路径回归。
- `safety_v4.log` / `seedcap_v4.log`：内存安全与容量拒绝。

冻结一套实现后停止调参。后续独立候选应先定义更完整的ROI证据/墨线拒绝合同，例如区分拟合ROI与更大验证ROI，并按已投影网格验证外围组件；不能把裁掉墨线当作安全拒绝。此轮不继续临时调参，也不把本实验包装成产品支持。
