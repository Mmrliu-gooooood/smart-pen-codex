# 独立照明驱动新增电路 — 2026-10-28 / NO FAB

已实际绘制原生KiCad电路，不是占位功能框：**330Ω串联硬限流 + PMV30UN2低边开关 + 栅极限流/下拉 + 物理DNP开放使能跳线**。不是恒流源，也不是光学安全认证。没有PCB、Gerber或整机投板批准。

## 接口和默认状态
- J1内部语义端口：1=3V3_AON（只限3.0–3.6V稳压电源）、2=GND、3=ILLUM_STROBE（现有MCU GPIO48，3.3V控制）。不增加GPIO；不可接电池或USB5V。
- J2只接受**一颗无内置驱动的独立LED**，1=阳极LED_A，2=阴极LED_K。只在这两端之间接负载，不接地，不接相机模组自带LED驱动，不接未知30pin的25/26脚。实际LED料号、波长、极性外观与连接器尚未批准。
- JP1物理开路且BOM DNP；未完成光源额定、短曝光亮度及光安全审查前，禁止安装/短接。不是固件可打开的开关。
- JP1开路时LED供电断开。人工commission后，ILLUM_STROBE高使Q1导通，低使其关断；控制断开/高阻由R3=100k下拉。关断有器件泄漏，不能承诺理想零光通量；上电、GPIO模式转换、快速供电边沿造成的米勒耦合和脉宽仍需示波器验证。
- SC035HGS芯片LEDSTROBE是1.8V输出；本页没有把它与GPIO48并联。以后若使用芯片同步触发，必须经明确选路/隔离审查替换信号源，不能直接两输出相连。

## 本次硬限流计算和限制
R1=330Ω±1%，要求额定功率≥0.1W且实装温度下满足降额；不依赖MOS导通电阻限流。3V3_AON最大3.6V、LED短路/压降按0V的保守计算：
- Rmin=326.7Ω（按初始±1%计算；全温保证还须把实际MPN的TCR、老化与降额纳入，以下上限以实装电阻不低于此值为条件）；LED支路电流≤11.0193mA；R1耗散≤39.6695mW。
- 正常电流约`(Vrail−Vf−VDS)/R1`，会随LED、温度和电源变化，并非恒流。3.3V/Vf2.0V示例约3.94mA，仅示例不是选定光源规格。
- 控制高时R3另耗约33µA；R2=1k限制栅充放电脉冲，理想3.6V阶跃峰值≤3.6mA。MOS栅电容不是固定量，不能直接据典型电容保证最短曝光脉冲。
- Q1漏源短路仍由R1限流；LED短路也受上述上限约束。**R1本身短路或接线绕过它不在此保护范围内**，不是单故障安全认证。
- 低电流可能不足以满足短曝光准确度；不得为了亮度擅自减小电阻或提高电源，改变后必须重新做电流、功耗、光学和眼安全审查。可见/近红外LED都不能仅凭电流推断安全。
