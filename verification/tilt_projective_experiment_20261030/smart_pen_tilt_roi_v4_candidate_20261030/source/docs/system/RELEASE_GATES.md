## 原则

1. 单元测试、仿真和 DRC 不替代实物；不把未执行项目写为通过。
2. 不跨长时间、不同页、落笔边界或低置信丢码强行补线。预测点应标识，与测量点分开；保留原始坐标与质量信息。
3. 电池无完整保护/温度/充电规格，不进行最终装机放行。小电池的充电电流按电芯规格，而非任意套用 1 A 充电板。
4. 光学模组的 FPC 针序、I/O 电压、复位/休眠有效电平未确认，不冻结相机 PCB。
5. 不以“已购认证模组”宣称整机合规；法规按销售市场、供电附件、年龄群体和产品分类重新确认。原型也不豁免基本安全。
6. 不公开密钥、个人资料、供应商保密图纸或无分发许可的数据手册；引用原厂链接并保留代码来源及许可。
7. 本仓库的新建/推送不等于采购、生产、部署或批量销售授权。
