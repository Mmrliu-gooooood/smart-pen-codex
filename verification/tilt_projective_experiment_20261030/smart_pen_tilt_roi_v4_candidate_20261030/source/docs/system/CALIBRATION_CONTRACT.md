# 笔尖标定接口：不能用固定像素偏移替代

## 坐标定义

纸面 W：z=0 为纸平面，x/y 方向与注册页码清单绑定；相机 C：z 为光轴向前，镜头模型与畸变参数独立保存。定义 Xc = Rcw Xw + tcw。笔尖在相机坐标系中的三维点 qc 由固定机构和标定确定，故接触纸面时 qw = Rcw^T (qc - tcw)。

`tools/calibration_geometry.py` 只验证这个刚体变换。它不估算相机姿态、不检测点阵、不提供相机内参，更不能用零假值冒充校准。它检查旋转正交/正行列式、前向深度、真实接触及笔尖到平面的残差；不把错误高度强行投影到纸上。0.2mm 默认残差只是测试用工程参数，需按实物误差预算确定。

## 必需标定数据

- 固定对焦后相机内参和畸变。每次改变对焦、镜头座、传感器或滤片后需重检。
- 正确的局部点阵绝对位置、朝向、页号、点间距与打印比例；不能由任意手动页标签隐藏局部解码歧义。
- 相机到实际触发状态笔尖的三维变换。轴向弹簧压缩、可换笔芯的长度偏差会改变它。
- 多个非退化倾角与旋转下的已知触点，留出未参与拟合的验证触点。只在一个角度“点几下”不足以证明任意姿态一致性。
- 每个校准版本绑定硬件、镜头、笔芯、固件、页清单版本和温度/焦距设置。数据有校验和，写入应断电安全。

## 运行门槛

平面姿态求解可能存在歧义，需检查正深度、多点重投影、邻帧一致性及解码置信度。标定未知、笔芯未就位、反光/墨迹污染、纸面起伏或姿态退化时输出无效/GAP，不得给出看似平滑的虚构轨迹。

用于拿起唤醒的三轴加速度计不是六轴陀螺仪，不提供可靠航向或高速位姿，更不能单靠惯性积分恢复纸面位置。本版优先依靠点阵视觉几何求纸面位姿；是否增加陀螺仪由数据证明必要性，而非先扩大功耗和成本。

固定“笔尖前移2像素”不适用于移动近摄笔。未经标定的图像中心、解码窗口原点和真实出墨笔尖是三种不同坐标。
