# 现有定制 SC035HGS 模组：线序证据与验证边界

日期：2026-10-28。本说明为独立分析，不是接线批准或生产发布。只保留必要结论，不公开原始保密 PDF、截图、照片、完整寄存器表或长段原文。

## 先给结论

**不能把 AI 建议的订购线序当成厂家实际做出的线路，也不能按最新口述直接重命名现有模组。**

- 定制模组图纸标注：**25 = LED_STROBE，26 = NC**。
- 用户此前给厂家的要求：**25 = LED_EN，26 = STROBE（可选）**。
- RevD 接口图沿用了前一种定义：J1 的25为 CAM_STROBE、26为 NC。

图纸与 RevD一致不是两份独立实物证明。现有模组保留为**台架研究对象**，下一版采用带版本号、供应商确认的接口或完整独立验证的自有设计；不要求现厂家补充不存在的资料。

[思特威官方产品列表](https://www.smartsenstech.com/products_list)可确认 SC035HGS支持DVP，但官方产品页、通用驱动和其他模组电路不能证明这个定制30针内部连接。第三方转载保密资料也不构成公开转存原件的理由。

## 图纸针号清单：仅为设计意图，不是接线许可

- GND：1、3、5、7、10、15、20、27、30。
- 3V3：2、28。
- 时钟/同步：4 XCLK；6 PCLK；8 VSYNC；9 HSYNC。
- 数据：11 D0；12 D1；13 D2；14 D3；16 D4；17 D5；18 D6；19 D7。
- 串行/控制：21 SCL；22 SDA；23 RESET；24 PWDN。
- 待确认或未用：25 LED_STROBE；26 NC；29 ID/NC。

29的 ID/NC不明确，保持悬空。不要猜测交换25/26。下一版按真实电路区分 CAM_SHUTDOWN_N、CAM_TRIG、CAM_STROBE和主控侧 LED_DRIVER_EN；名字不能替代连线证据。

**方向：**镜头正面朝向观察者、软排线向下，图纸1在左、30在右；背面视图30在左、1在右。这不直接确定座子上/下接触点、主板焊盘或转接板是否反转，须断电逐线核对。

### RevD 的两个额外陷阱

1. **J2不是开发板物理脚序，而是主控逻辑线束。J2的26为 BUS_EN，不等于摄像头 J1的26。** 不能用同号直通线束把二者接起来；J1还需要外部 FPC 转接，必须逐线检查方向。
2. 接口板上的外部1.8V转换器电源，不证明摄像头内部 DOVDD 已建立、与之同步，或允许摄像头断电时被接口信号反向供电。RESET/PWDN 可选路径不能因为接口图画出来就提前装通。

## 新增厂家答复：单列为声明，不冒充实测

用户转述厂家确认：模组内部处理3.3V到2.8/1.8/1.5V电源；外部应供DC-DC转换后的3.3V。这是内部电源架构的**厂家声明**；三轨及上电时序尚未实测。

厂家同时说“都是3.3V MCU兼容电平”，在另一项涉及控制/初始化的问题下只答“1.8V”。后者究竟指电源、I/O或其他条件并不清楚，不能替厂家强行解释。兼容声明不等于逐脚3.3V直连许可；容限、控制映射及极性仍未闭环。

厂家称镜头无 IR-cut（白玻）、850/940nm可透过，未点胶可自行微调，8/10/12/14mm物距可满足。尚未实测透过率、近焦解析力及动态码纸效果。

用户新增手册截图说明曝光期间 LEDSTROBE可输出高电平，仍是**传感器逻辑输出**，不是 LED功率驱动，也未证明已接到 FPC25。按厂家所提 MCU GPIO控制独立 LED板推进补光：GPIO只控制合适的限流驱动，不直接带功率灯；现阶段不依赖摄像头25/26，不混用 LED_EN 与传感器闪光输出。保密截图不随仓库发布。

## 无需新增厂家资料的有限验证路线

以下供有低压电路经验和适当仪器的人员执行，不是未知线路的直接上电说明。

1. **断电确认方向。** 拔掉电池、USB、下载器、主控及所有供电。私下记录版本、排线正反面、触点面和器件标记。在不接模组时先检查转接板1号位置及逐线对应；不刮封装寻找芯片焊球。
2. **低能量无源检查。** 使用测试电压/电流已知且适合该电路的电阻档，检查已识别的地、供电与可达走线。不要使用参数未知的蜂鸣/二极管档试信号脚。记录阻值及方向；电容、ESD结构和并联支路可能误导。检查2/28关系、地线组和可见稳压器；测不到导通不等于 NC，探针易跨接相邻脚时停止。
3. **上电门槛。** 物理针号、供电极性及供电路径须由检查证据或已验证工厂线束支持；否则停在无源检查。通过后只用单一稳压、限流台式电源和绝缘夹具，按确认条件供稳定3.3V；限流依据已识别电路或正常基线，不虚构通用数字。**不用裸锂电池、不接5V、不热插拔、不先接主控驱动。** 异常温升、限流或电压异常立即断电，不靠提高限流试启动。
4. **先观察，不试短接。** 断电时固定探头及已确认的地线，再用高阻探头观察可达电源点和23/24/25/26。地夹不能接信号。静态高低电平不能单独判定功能。**禁止带电短接试极性，禁止3.3V上拉/推挽直连未验证摄像头 I/O，禁止闪光脚直接带 LED。** 控制映射未确认前不随机拉高/拉低23/24。
5. **有条件的功能验证。** 电压安全的时钟/串行路径及必要控制映射建立后才主动配置。已有可靠工厂出图环境可用于被动观察曝光变化与候选闪光波形，但相关性不证明带载能力。独立补光先不接摄像头候选闪光脚。用已知测试图核对位权，记录 PCLK、同步和数据有效窗，最后建立带版本/仪器/接法/未解决项的实测表。关键控制仍不明时保持台架状态，不将猜测写进下一版 PCB。
