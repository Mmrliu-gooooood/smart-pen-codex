# SC035HGS 已有 PDF 的设计答案页码索引

2026-10-28 重新核读。下列页码均为 **PDF 从封面计数、从 1 开始的物理页码**；这两份文件的正文印刷页码与之相同。简称“手册”指《SC035HGS 数据手册 V0.3》（44 页），“指南”指《SC035HGS 设计应用指南 V1.0 for-DVP》（13 页）。原件保密；这里只作原创归纳，不转载原图、原表或整段寄存器清单。

## 已经有答案，不应继续列为“厂家待提供”

- **电源与电平**：手册 p2、p11、p38；指南 p7、p10–11。芯片使用模拟 2.8V、数字 1.5V、I/O 1.8V 三路电源。手册 p38 给出工作范围和输入输出电平条件；不能据此把芯片 I/O 当作 3.3V 接口。指南 p10–11 已有 DVP 参考电路、逐电源脚去耦、参考电压脚电容、肖特基保护和供电树设计依据。
- **上下电顺序**：手册 p13–14；指南 p5–6。上电图依次安排 DOVDD、DVDD、AVDD，然后释放 XSHUTDN；图中前三段最小间隔允许为零，初始化前的 T4 不小于 4ms。特别注意：T4 的图示起点是 EXTCLK 有效开始，而不是仅凭 XSHUTDN 上升沿计时。下电图也已给出待机、时钟/关断控制及电源撤除顺序与间隔；不要把串行接口 lane 示意直接套作 DVP 波形。
- **XSHUTDN**：手册 p10–11、p14；指南 p7–8、p11。DVP 封装球位 B7，低电平有效，内置上拉。手册区分硬件关断与软件睡眠：拉低时不能访问寄存器；软件睡眠仍允许寄存器访问。不是“极性未知”。
- **TRIG**：手册 p10–11、p24–25；指南 p7–8。DVP 球位 A6，是外部曝光触发输入。p24–25 已写明上升沿触发、曝光由寄存器控制、触发模式使能及活动/消隐行控制。上升沿之后还有复位前导行时间，不能把它与实际感光曝光起点无条件等同。MIPI 管脚定义不同，不可混用。
- **LEDSTROBE**：手册 p10–11、p24 §2.1；指南 p7–8、p10。球位 B1，是输出；曝光期间输出高电平，且已有使能字段定义。用户给出的 LED STROBE 截图对应这份手册已有小节，不是新增资料。它与 TRIG 输入是不同信号。工程上将其用作外部补光驱动级的控制信号；该小节不等于给出了直接驱动功率 LED 的电流额定值。
- **配置总线格式**：手册 p15–16。已经明确标准 I²C、7 位设备地址、16 位寄存器地址和 8 位数据，且有读写事务及接口时序。p15 的 SID 地址选择表明确限定 MIPI 封装；不要把该表当作 DVP 上存在 SID 引脚的证据，也不要混淆 7 位地址与含读写位的总线字节。
- **DVP 时序和可调项**：手册 p17 已给出 FSYNC/LREF/PCLK 时序、同步极性、同步宽度、PAD 驱动及 PCLK 延迟的控制入口；p36 给出输出窗口、行长、帧长和帧率关系；p28 有曝光量纲与生效时序。这些都是能直接用于设计和调试的已有资料。
- **外部时钟**：手册 p23、p39；指南 p11。EXTCLK 允许范围为 6–27MHz，p39 进一步给出占空比与高低脉宽要求。指南明确可以使用有源时钟源或系统提供时钟。

## 应准确区分“已有内容”“版本冲突”和“尚未由这两份 PDF 建立的结论”

1. **八位数据的名称有原文冲突，而不是没有管脚资料。** 手册 p10–11、指南 p7–8 将八个 DVP 数据球位标作 D0–D7；指南 p10 的参考电路在对应球位上标作 D4–D11；手册 p17 又使用 12-bit DVP 的概括描述，p2 列出多种位宽能力。应保留球位对照与实物连线验证，不能无说明地选一套名称当作全部一致。
2. **引脚方向栏存在明显不一致。** 手册 p11、指南 p7 把 PCLK/FSYNC/LREF 标成输入，并把 SCL 类型写成地线；手册 p17 的 DVP 功能说明则明确输出数据时钟及同步用途。设计时应结合接口功能、参考图与实际信号方向解释，不能机械照抄有疑点的类型栏。
3. **PLL 已有章节，不应称为“没有时钟资料”。** 手册 p23 有锁相环结构及输入/VCO 范围，p20、p22 有相关接口的时钟选择控制。但这两份 PDF 未给出可完整计算并编码所有 PLL 前分频、反馈倍频、后分频的寄存器字段表，也未附一份完整低 PCLK DVP 初始化序列。p17 的 PCLK 延迟控制不是分频器；p36 的行/帧长度调节也不能单独证明 PCLK 降频。现有初始化文件应作为另一份证据单独核对，不能据 PDF 的帧率公式虚构一个已验证低 PCLK 模式。
4. **芯片球位不等于定制模组的 30-pin 连接器序号。** 上述 PDF 已回答芯片侧设计问题；项目连接器映射应从已有模组图纸/连线资料交叉核对，不应因此重复索取已经给出的芯片资料。
