# 相机电源门控：新设计 NO FAB

2026-10-28 新电路，非历史原件恢复；未采购或批准投板。此模块不修改电池充电核心，电芯/NTC 未批准时仍禁止启充。

## 已实现的硬件

原生可编辑 `hardware/power_safety/power_safety_NOFAB.kicad_sch`，附独立符号库、生成器、网表和检查脚本。U1 为 TPS22918DBVR 候选；所有封装尚未赋值，不能把符号当成已核验 PCB。DBV 六脚封装需再核对实际焊盘、装配方向与供应型号。

- `3V3_AON` → U1 → `CAM_3V3_PRELINK` → **JP1 实体开路调试桥（DNP）** → `CAM_3V3_SW` → J1.1；J1.2 为 GND。
- J1 是实际下游两线供电接口的候选，连接器型号、极性防错结构和物理引脚尚未确定。绝不解释为已确认摄像头 FPC。
- `CAM_PWR_EN` 为层级输入，现提案 MCU GPIO41。TP1 是使能电平测量点，供复位/掉电验证；不是隐藏 ERC 排除项。
- R2=1k 串入 ON，R1=100k 下拉；MCU 复位高阻且无外部上拉时默认 OFF。若 MCU 保持高电平，不能声称必然关断。集成时 MCU 端重复 100k 可合并，须重算漏电预算。
- C1=10µF 输入，C2=1µF 输出；C3=1nF/25V C0G 控制斜率；R3=100Ω 连接输出与 QOD。实际电容容差、直流偏置、负载电容和功耗仍需定料与实测。

## 原厂核对依据

[TI TPS22918 Rev C 官方数据表](https://www.ti.com/lit/ds/symlink/tps22918.pdf)，本次重新下载并记录 SHA256。第5节：1 VIN、2 GND、3 ON、4 CT、5 QOD、6 VOUT；第6节规定输出不得高于输入，ON 高/低门限分别为1V/0.5V。第8.3节提供 CT 斜率和电阻串联 QOD 的用法；CT 对地选25V，不能错接至输出。表2的1nF/3.3V典型上升时间为1.68ms；公式估算1.914ms，两者都不是最坏保证。第6.5节中3.3V关断电流典型0.5µA、最高3.5µA（指定测试条件）。这些数据不含外部负载和倒灌。

## 安全边界与接线门槛

**这不是限流器、保险丝、OVP或反灌保护器。2A器件额定值不是本系统允许的相机电流。**

`CAM_3V3_SW` 只能给已证实兼容的3.3V模块，或已设计的下游稳压输入；不能接裸传感器所有电源，也不能作为1.8V VIO。独立相机接口电路负责 I/O 隔离，未验证前不得桥接 JP1。

桥接 JP1 的必要条件（全部满足，人工签核）：
1. 明确传感器/模块、电源范围、每个电源域及上下电时序、连接器极性；记录实际引脚资料。
2. 证明 MCU 的 XCLK、SCCB、复位、DVP 等信号不会给断电域反向供电；所有上拉归属和双电源翻译器掉电行为已验证。
3. 下游没有并接 USB、调试器电源或其他源；掉电全过程测得 VOUT 不被外部抬高。单靠输入电容大于输出电容不能作全工况保证。
4. 在限流实验电源上完成空载、真实负载、最大电容、重复启停、输入突然断电测试；上游3V3不复位，浪涌/热/放电均符合系统预算。
5. 根据输入/输出真实电容与负载确认R3功耗及QOD热边界；不得让外部电源持续驱动已关断的输出。

## 控制顺序（接口约束，不是已写成固件）

上电：隔离总线并禁止输出时钟 → 保持传感器复位（其电平必须符合掉电规范）→ 使能电源 → 等待实测稳定及各域时序 → 允许隔离器 → 释放复位/启动时钟。

关电：停止采集与时钟 → 按传感器要求进入复位/待机 → 禁止隔离器并处理上拉 → 拉低 CAM_PWR_EN → 等待实测放电。无电压监测/PG，本图不能靠固定2ms延迟保证供电稳定。必须覆盖 MCU 看门狗复位、深睡和棕断，而不只是正常软件关机。

R1 单独在3.3V使能时约33µA，计入工作电流。检查器的 ON 漏电估算仅含开关规定漏电，不含 GPIO、污染、TP1探头等；不据此声称所有故障安全。
