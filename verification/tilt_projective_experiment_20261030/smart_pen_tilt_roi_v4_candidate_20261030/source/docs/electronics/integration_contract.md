# 2026-10-28重建：跨模块合同 / NO FAB

这是3套独立KiCad工程，不是已经合并和完成物理连接的整机。`hardware/verify_integration.py`读取各自实际导出XML，检查11项接口名称及非空节点；电源页采用局部根标签，XML前缀 `/NAME`仅去掉单一根斜杠进行名称比较，不忽略任意子层级。首次未归一化的检查失败是该前缀差异，不能把不同工程同名网络当作已物理连接。

|模块对|合同网络|
|---|---|
|MCU–power|VBUS_5V、3V3_AON、GND、USB_EN1、USB_EN2|
|MCU–pickup|3V3_AON、GND、AON_I2C_SCL、AON_I2C_SDA、PICKUP_INT_N、NIB_CONTACT_N|

`integration_checks.json`包含新的运行时间、节点计数和三个输入XML的SHA。它仅验证命名对应，不能替代整机合并后ERC、线束端子映射、通断、供电顺序、ESD和掉电反灌验证。

- GND必须是保护电池负端PACK_MINUS/系统回流，不能接裸CELL_MINUS绕过保护MOS。原始电芯与保护电路/NTC资格尚未确定；此包不是充电许可。
- 3V3_AON由电源模块稳压供给MCU和拾笔，电源旗标只是该事实的电气检查声明，不是另一个电源。带电I/O不得接未供电设备。
- USB_EN1=GPIO18/PICO24，USB_EN2=GPIO21/PICO27，复位100k下拉在电源模块；固件必须在合法电源授权后切换，不能按USB-C机械插入就提高电流。
- 拾笔板只有一对10k I²C上拉，初始100kHz并测量线束上升时间。RTC唤醒需要固件配置低有效锁存、清除历史事件并确认线恢复非有效。50Hz低功耗模式1是候选，20ms只是采样周期不是完整预唤醒上限；1.6Hz的625ms周期不适合承诺快速拾笔。
- 摄像头模块的1.8V IO、实际FPC接法、时序/电源隔离与72MHz配置适用性均未落实，不能直接插J2逻辑接口。没有光学准确度或坐标准确度实测。

## 常开稳压器的待机预算
TPS63802的典型静态电流不是整笔输入电流。511k/91k反馈分压在约3.308V时约5.49µA输出负载，另有MCU、PSRAM、拾笔和所有泄漏；不能把活动时的效率用于微安待机。应在整个电池电压/温度范围以足够长窗口覆盖PFM周期测量电池端电流，包括触点一直按下、USB插拔、总线卡低和摄像头反灌。用实测效率曲线时避免重复计入同一静态项。1000h待机是软目标，未验证。
