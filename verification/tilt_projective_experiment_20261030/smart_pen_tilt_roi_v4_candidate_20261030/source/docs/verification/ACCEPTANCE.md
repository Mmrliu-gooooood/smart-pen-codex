# 样机实测与证据要求

尚无本笔实测数据。下列数字是首轮工程目标，非已达成性能或用户硬性承诺；根据仪器精度与实拍可调整，但调整必须记录原因，不能为掩盖失败追改门槛。

## 先确定测量定义
- 笔轴对纸面夹角 α、相机光轴对纸面法线夹角 θ 分开记录；左/右手、纸张/墨水/打印机/比例、模组/镜头/滤片/LED 电流/占空比/曝光/帧率/ROI 均入记录。
- 参考坐标误差需显著小于被测门槛。手画直线不构成亚毫米真实轨迹，优先用刻度夹具/已知点击位置/独立追踪；不要以旧书台输出自动作为绝对真值。
- 无同步时钟不得直接相减宣称端到端延迟；记录时钟拟合误差或用共同时基/高速录像观测笔尖接触到显示。
- 图像原始帧与坐标序列均保留；允许插值的可视化副本不能覆盖测量原始数据。

## 首轮条件覆盖

静态九点：中心、四角、四边；每点至少 30 次重新落笔，至少三种笔轴角及左右旋转。近边缘、墨迹遮挡、强/弱环境光、普通纸/目标纸、不同握持至少分别记录。动态测试使用实际测得速度，建议从 0.05、0.2、0.5 m/s 分档，不用“正常/快速”代替数值。

初始目标：静态位置误差 p95 ≤ 0.3 mm，动态 p95 ≤ 0.5 mm，端到端延迟 p95 ≤ 100 ms。任一工况缺数据均为未验证，不能用总体平均掩盖极端工况。速度/倾角范围须与最终规格共同报告。

失码必须统计：有效落笔时间中无坐标比例、每笔断段次数、最长失码时长、错误跨页/跳点数量。最后一项目标为零；宁可标识缺口也不要伪造墨迹。不得把采样缺失比例称为笔画断笔率。

接触检测记录首次接触到第一有效坐标的时间与距离，抬笔多画的尾部，轻压漏检及机械回弹。二值开关无法输出真实压力，评分不能使用虚构提按信息。

## 故障与寿命

- 在写入、提交、发送、ACK、页切换、升级各阶段切断电源/断开链路，并验证不丢已确认数据、不覆盖未确认记录、不重复绘制；随机重复至少覆盖每种切断窗口。
- 存储满、坏 CRC、异常长度/版本、重复序号冲突、计时回绕、未知页、升级失败、低电量、接触抖动必须显式可观测。
- BLE 多终端策略与配对授权需明确；未授权设备不得删笔迹、修改校准或升级。OTA 需要签名/版本与回滚策略，但不可未经审批烧安全熔丝。
- 充电输入、正常充电、NTC 开短路、满电、低电量、LED 最大允许工况测试；异常电池测试交由合适实验条件，不让用户自行短路/穿刺电芯。
- 热与续航需在整机握持条件、实际亮度/采样/无线负载下测量；记录环境温度、外壳热点、芯片/电池温度。未指定安全界限时依器件与电芯原厂额定值，不臆造“安全温度”。

## 数据工具

复制 `verification/measurement_template.csv`，仅填实际测量。运行 `python tools/evaluate_measurements.py measurements.csv --output report.json`。工具拒绝非有限值和倒退时间；缺失坐标不能当作零误差。输出只作诊断，不自动批准生产。
