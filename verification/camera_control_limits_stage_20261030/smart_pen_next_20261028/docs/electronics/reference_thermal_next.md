# NEW-REF-P0：2.5V参考激励温控候选（NOFAB）

## 已解决常态可用性，不再停在26–27°C

本轮真实原生图在 `hardware/reference_thermal_next/reference_safety_NOFAB.kicad_sch`：REF3425IDBVR供第二独立NTC双阈网络；两监督器均改监视**REF_EXC本身**，不再监上游AON。温控与双SPST已连接，唯一JP1仍OPEN/DNP。旧INT-P0未改。本候选不包含完整BQ/TPS电源核心，也不批准任何pack。

新的10–45°C目标网络：NTC上拉10k，热侧110k/100k，冷侧255k/100k；NTC仍NTCLE100E3103GB0。五电阻的模型是**总误差±0.2%**（含初值/温漂/允许老化等），不是把标注±0.1%当终身全温保证。

1024个独立参数角点、4096行阈值结果重新计算，且新增**恢复许可**而非仅看故障阈根：

| 已算条件：REF_EXC=2.34–2.53V | 最坏余量 |
|---|---:|
| 电芯10°C，冷侧必须禁止 | 7.423mV |
| 电芯45°C，热侧必须禁止 | 19.781mV |
| 电芯20°C，冷侧即使先前故障也必须恢复许可（按最小下降阈0.387V） | 1.167mV |
| 电芯30°C，热侧即使先前故障也必须恢复许可（按最大上升阈0.404V） | 68.470mV |

**输入偏流条件必须保留**：TPS3700 INA的±25nA仅在VI=6.5V测试，INB的±15nA仅在VI=0.1V测试；本应用阈值附近约0.4V，并非相同测试点。因此以下20–30°C结论是采用该偏流包络的条件模型，不是原厂对所有输入电压的偏流保证。NTC自热、PCB漏电和实际热耦合尚未纳入该四项电压余量预算。

NTC单调且节点电压随温度单调下降，故两恢复端点给出20–30°C全段许可的静态电气证明，包含规定R/B/电阻/输入偏流/比较器阈值角点。20°C冷侧余量仍有限，不能覆盖未预算热耦合误差；不得宣传整笔真实电芯在20–30全条件一定可充。温度根仅估计，许可证明使用20/30°C原厂表格误差点，不靠B误差插值。

## 参考电气预算与未有界项

U6选真实订货名 **REF3425IDBVR**，不是缺少I的名称，也不是引脚不同的REF3425T。官方六脚：1 GND_F、2 GND_S、3 EN、4 IN、5 OUT_S、6 OUT_F；EN与IN同VBUS，OUT_S/OUT_F同REF_EXC，地sense/force同保护后GND，布局需Kelvin回路。

正常USB评估输入4.5–5.5V。采用10mA测试点的500mV最大dropout而不是零负载100mV：低输入仍远高于2.504+0.5V。NTC短路作为参考负载上界，加两个监督分压与偏流，合计不超过约0.562mA，低于±10mA能力。低于正常USB范围的brownout不靠该精度保证，改由REF监视和试验处理。

保守相加的有规格DC项：初始500ppm；温漂按box法全−40..125跨度6×165=990ppm；line按2.55..5.5V跨度44.25ppm；source load约16.84ppm。结果 **2.496122–2.503878V**。这不是统计RSS。

未给出可据以证明长期上界的项目单独留下：噪声峰值、长期漂移、热回差、焊接漂移、启动、供电/负载瞬态，以及实际电容/PCB。原厂2.5ms启动仅典型，完全没有当作最大启动保证。2.53V静态分析上界提供约26mV余量，但不是这些未定误差天然受限于26mV的证明；须用规定寿命/温湿度及实测约束。REF高失效也不是现UV监督器能检测的全部故障。

C6=100nF；C7=4.7µF候选，**实际有效电容要保持原厂0.1–10µF稳定范围**，直流偏压/温度/容差/ESR未选型。精度表测试COUT=10µF，4.7µF应用必须验证启动/动态/稳定性，不假称已复刻所有测试条件。

## 监视参考输出的真实阈值

- U1改 **TPS3808G25DBVR**（固定2.33V阈，不能用G01替代），SENSE200Ω/10k，总电阻误差±0.2%。以固定版本±1.5%阈、0..2.5%回差、保守±1.7µA输入模型计算：下降2.340428–2.412779V，最坏释放2.473090V。CT开路仍有12–28ms释放延迟。下降最小略高2.34V，释放最大比已预算参考下限低23.03mV。
- U2仍 **TPS3899DL01DSER**，改34k/10k监REF；下降2.158070–2.286307V、最坏释放2.469076V，低于参考下限27.05mV。CTS/CTR开路，原厂规定条件的50µs最大检测规格保留。
- 上述偏流最大值的表格测试点与本应用电压不同，模型按保守双向包络使用，仍需针对真实SENSE电压验证；不声称厂商原表在每个中间电压都单列该保证。
- 参考未升到有效阈时U1拉低；阈后再计至少12ms。这样不需要猜参考的启动最大时间。参考若达不到阈就保持禁止，而不是超时后强制允许。
- **快速棕断仍有未闭合动态区间**：U1静态边界2.34V，但其下降时延只有典型；U2有条件最大时延却在更低阈动作。因此不得声称REF一跌破2.34V就零延迟关断。新的低温5°C慢升反例许可约1.248–2.020V，只有完整门控时序测试才能验证不会在这段误充；试验优先关注2.34→2.02V的最快跌落与50µs/实测撤销裕量。

## 精密电阻与两颗NTC不是零体积

原厂[Vishay TNPW/TNPU表](https://www.vishay.com/docs/28758/tnpw_e3.pdf)列TNPU0805的5ppm/K、0.05%档及100Ω–332kΩ范围，可作为200Ω、10k、34k、100k、110k、255k这组低漂移电阻的现实候选范围。**本轮没有伪造完整订货号或库存**；最终各数值可订性、焊接/长期变化及±0.2%总预算仍须实料资格确认。初值0.05%+从25°C到125°C的5ppm/K项0.05%只占0.10%，其余0.10%不能在无寿命条件下无限宣称可用。图上0.1%是最高允许初值要求，绝非选完MPN。

[Vishay NTCLE100E3 Rev2025-05-07](https://www.vishay.com/docs/29049/ntcle100.pdf) 的10kΩ引线型适用330Ω–470kΩ尺寸行：B=3.3±0.5mm（最大3.8mm）、T最大3.0mm、H1=1..3mm、H2最大6mm、引线长24±1.5mm、线径0.6±0.06mm、节距2.54mm。不能把这些尺寸当零厚SMD，更不能把引线随意截短/折弯当已通过装配。

BQ TS第一独立NTC与本图第二独立NTC均需实际包络、绝缘层、导线弯曲/应力释放、贴合材料和热滞后预算；若第一路也拟用同型号，则两只都按完整物理尺寸计，不共享节点。原厂涂层无规定绝缘等级、不适合灌封。**机械Ø12.2电池区域绝不是已证明能塞下两NTC的完成尺寸**。薄型NTC可后续另选，但不能暗换R/B、公差和耦合证明。
