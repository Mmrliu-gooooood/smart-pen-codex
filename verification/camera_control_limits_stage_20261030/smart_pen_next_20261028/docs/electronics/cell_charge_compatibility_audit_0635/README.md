**不可误判**：器件快充编程下限100mA不是“误差后实际电流必须≥100mA”；此R值合法，不能因91.12mA角点否决。也不能任意加大ISET电阻以给超小电芯降流而仍宣称规格覆盖。输入模式00/01/10分别USB100/USB500/电阻编程，11暂停；输入限流共享系统与充电，不是电池充电电流。DPPM/热调节会减小充电电流并影响计时，USB100还可能由电池补充系统功率。113.72mA只是上述静态快充上界，不能代替零伏、热插拔与故障瞬态资格。

电阻1%仅是图纸允许初值；当前未逐颗冻结MPN/温漂/寿命，总误差若超过1%必须重算。禁充漏电非零且依条件；本报告不把CE高或模拟开关OFF视为任何电池均可安全接入的证明。

## 3. 候选而非合格选型

### P1044C：细径候选，未批准
[原厂页](https://www.keeppower.com/product/keeppower-570mah-10440-protected-li-ion-rechargeable-battery-3-6v-p1044c/)当前仍列550mAh最小/570mAh标称、最大充电390mA、持续放电1A、充电0–45°C、放电−20–60°C；本体按Ø10.8×45mm最大值筛选。现113.72mA低于充电电流上限，但**原厂写4.2V最大，未给可接受4.23V的容差，故CV不合格闭环**。不能用经销商推测修补。PCM阈值/延迟/恢复、脉冲条件、双NTC及触点/绝缘/保持件包络仍缺。

沿用明确标为假设的系统筛选：3.3V×(MCU0.5A+camera0.25A)/(效率0.8×带载包电压2.8V)+0.02A=1.125A；若持续则超1A，若短脉冲也没有原厂时长/占空资格。没有宣称实际消耗一定为这些数值。550mAh/本轮电流仅算4.84–6.04h CC容量比，尚未CV/预充，不能保证一次充满。

### Jauch 245137：额定电流较宽，体积/CV/计时仍阻塞
[原厂Rev1.1](https://www.jauch.com/downloadfile/5c33794c57a460a44e91602fdb5dfbb33/850mah_-_li14500j_1s1p_2_wires_50mm.pdf)列850mAh、最大充电850mA、放电1.7A、充电+10–45°C、正常放电截止2.75V、两根线无NTC。PCM OV最低4.225V与充电器4.23V有5mV交叠，需确认正常CV允许值及误切/重启协调；不能直接称裸芯损坏。850mAh/本轮电流为7.47–9.33h，已大于6.732h最短计时；这是空到满可用性风险，不应取消安全计时来掩盖。现有资料径向尺寸仍无最大公差，另有15/16mm表述差异；线束/双NTC都未闭合。

**历史温窗结论需更新解释**：旧`battery_qualification_next.md`针对NEW-P1称0–45°C不兼容Jauch；当前RevB真实采用REF3425 + R109=10k、R110/R111=110k/100k、R112/R113=255k/100k，属于NEW-REF-P0的**10–45°C目标**。不能继续把旧温窗错误归给当前板。但目标温窗不是电芯实际温度验证。

## 4. 温度及机械不能用数值占位冒充通过

当前参考模型给10/45°C禁止、20–30°C条件许可；`reference_thermal_next.md`明确保留比较器偏流测试点、静态误差、快速棕断延时、漏电/污染、热滞后缺口。本轮未重复宣称独立验证其全部4096角点。两路NTC必须真实测到电芯，而非板上环境或充电芯片温度；贴合、绝缘、传感器脱落、开短路、充电热源耦合均待试验。硬件门控减少固件依赖，不意味着全部单故障安全已经成立。

[Vishay原厂](https://www.vishay.com/docs/29049/ntcle100.pdf)明确NTCLE100涂层没有规定绝缘性能、不用于灌封；约15s热时间常数是信息值，不是本装配检测上界。不能直接贴金属电池壳、灌胶或把PCB温度当电芯温度而省略材料和热响应评估。

没有发现已合格“20mm宽电池”。实际历史RevC机械是**预算圆柱**：18mm串排Ø12.2×49，19mm并排Ø11.4×49，20mm并排Ø12.2×49；P1044C本体能小于预算不证明双NTC完整包能装入。该文绑定旧95mm RevC板，不能套到当前101.5mm主板。当前ACCESS壳19/20mm仅研究对照，文档明示battery fastening/整包未合格；本轮不以总体积证明可装，也不擅自放宽用户15–18mm目标。

## 5. 最小安全下一步与采购规格门槛（不是采购指令）

1. **保持JP1开路**；继续无真实电芯的受控电源/电池模拟器方案制定，先完成电源/CE/NTC开短路及上电/棕断试验规程。未知相机仍禁接电。
2. 在既有架构内先保留约103mA设置，锁定唯一保护1S锂离子包订货号；签版要求至少覆盖113.73mA及完整误差/瞬态余量、4.23V调节上界和实际终止/预充/低压恢复。若无法允许4.23V，则当前充电器不能获批，不能把PCM当正常CV控制器。
3. 连续/脉冲放电规格由实际MCU+camera+LED测量与保护后最低带载电压导出；在现假设包络中1A候选受限，优先取得≥1.3A持续条件及温度/脉冲证明作为筛选输入，**1.3A不是最终合格额定或已测需求**。正常截止必须高于电芯工作下限并覆盖供电跌落；PCM欠压是后备，不能只靠“固件会睡”。
4. 取得OV/UV/OC/短路阈值、容差、延迟、恢复与禁止零伏充电规则；双独立NTC安装/曲线/绝缘/最大包络图，批次适用测试摘要、连接器极性、防反接及线束应力释放。两件报价需包含NTC/保持/装配，归入760元预算，不重复向用户追问既定偏好。
5. 依确切包和实测负载再定ISET/TMR与温窗；调整电阻不直接在冻结native上试改。新完整包装入**同一版**主板/壳模型后再做公差/热/换芯/跌落/握持审查。
