# 参数化联合验证合同：先可见光、后IR

本合同给出缺失证据和冻结规则，不选定纸型、点距、镜头、距离或数值精度门槛。无需现在重复询问用户；工程候选先依据已有资料提出，之后用对应实物数据判定。

## 1. 每个实验必须绑定一整套组合

记录版本与实际值：
- **纸/码**：编码器与页/section/模板身份，点阵方向位定义、局部唯一性要求；点距p、点径d、位移δ及δ/p；打印机/模式/材料/批次、实测横纵比例与局部形变。修改几何或编码即新paper_revision。
- **光机**：具体sensor/module、镜头/滤片/镜窗、对焦位置、物距的测量基准、光轴安装角、笔轴角与滚转、真实笔芯/鼻锥遮挡、装配容差；全帧可用纸面区域和实际软件ROI分开记录。
- **采集/算法**：分辨率、RAW或处理格式及完整处理链、裁剪/缩放/stride、曝光语义与实测时序、XCLK/PCLK/帧率、时间戳来源；实际decoder版本/搜索范围/输入门槛；不得跨版本借用通过结论。
- **条件**：距离/姿态/速度/加速度/照明/纸面起伏/笔迹覆盖；独立真值、测量不确定度、训练标定集与保留验证集划分；两支独立装配和换芯重装。

## 2. 几何与采样筛选：允许拒绝组合，不等于准确度通过

| 问题 | 必须做的比较 |
|---|---|
| 近尖能否看全码窗？ | 按实际点位置枚举decoder要求的窗口，将点的完整墨迹边界投影到实际有效ROI；扣掉笔芯/鼻锥、失焦边缘、畸变、姿态及打印/装配余量。当前要求完整6×6时不得凭补点/外推伪造36点。新码制若需其他窗口，必须另验证，不沿用6×6结论。 |
| 点会不会太密或位移太小？ | 联合检查p、d、δ与实际印刷扩散/缺点。对于等直径圆点、格点邻居沿同轴相向位移的特定几何，名义最小净隙p−2δ−d仅是筛选量；还要枚举实际所有近邻、误差和模糊，不能把正净隙当可识别保证。 |
| 是否有足够像素？ | 用局部纸面→像素映射的Jacobian J检查两格轴向采样、点像椭圆与位移可分辨程度，逐位置/姿态计算或测量；不能用全图单一mm/px，不能把640像素默认都给了ROI。软件零拷贝裁剪不改变像素尺度或帧率。 |
| 动态是否丢信息？ | 初筛像素模糊可按局部J·v·曝光时间估计；实际加入转动、离面、曝光/读出方式与照明同步影响。帧间位移v/f与有效窗口/跟踪条件一起评价。独立绝对解码不必假定帧间重叠，但仍必须证明每帧有码窗和可接受轨迹采样/漏记。 |

旧6mm/0.3mm与当前3.527778mm纸都只是可被上述检查淘汰或保留的实验点，不能从一个条件反推另一个为产品硬要求。

## 3. 不能把桌面模板配准当作板端解码支持

当前 active `firmware/vision/roi_opt.h` L30–35明确：ROI≤256（实现检查）、冷搜索像素点距8–32、角度−60…60、轴比0.6…1.4，是正交非均匀模型，不是一般透视模型。这是**该软件版本限制**，不是最终纸物理规格。`roi_opt.c` 检测需要至少36点/完整6×6，当前major位移归一化门0.10…0.30、minor≤0.065，并以1/6附近评分；还有限制连通域大小/形状/边界。当前样纸δ/p约0.30落在其上边界，不能从桌面fitter允许到0.42便说板端也通过。

归档V3仍是独立研究，未替换active应用；V4为NOT_ADOPTED。固定远距已知模板匹配不证明盲局部码/页身份正确，更不证明合成模型支持真实握笔透视。每个新(p,d,δ)组合先用真实打印裁片/实拍输入对应decoder；同时报告正确接受、错误接受、拒绝和原因，并验证无完整窗口、相似码、遮挡、污点、旧新笔迹及其他纸的负例。不得为了“通过”仅调松置信门或将答案注入搜索。

## 4. 真正的笔尖准确度验收

分层记录，不能互相替代：
1. 点检测/分割与模板匹配：像素残差、所有点覆盖、失败/合并点，不只成功子集。
2. 纸上局部坐标/页识别：使用未参与拟合的物理参考与真实印刷尺度；分开误码、错页与拒绝。
3. **落墨笔尖**：相机内参/畸变与近焦、相机—触发状态笔尖外参、姿态/纸面估计、笔芯偏摆/压缩、换芯和装配差异全部计入；静态多位置多姿态及动态轨迹都和独立真值比较。

在做最终通过判断前，对具体测试矩阵冻结精度统计口径和门限（偏差、重复性、RMS/95分位/最大值、错误接受率、漏点/首次落笔/恢复延迟等），注明真值不确定度和有效/拒绝样本分母。数值尚未确定时结论只能“未资格化”，不能把当前模板残差补作指标。0.2mm平面残差等旧工具默认值不是产品精度承诺。

## 5. 可见光首样 → IR材料与光路：分开闸门

**可见阶段**：复用已知正常OV5640资料分析点阵、检测与模板一致性；需要近尖组合时必须在相应安全、受审硬件上另行取证。纸几何可改，所有改版重检。远距图不能证明OV5640本身能装笔或近焦，不要求为了材料未知先购买相机。

**IR阶段**：即使采用相同几何，也必须重新验证选定波长下纸/点墨/正文/笔芯墨迹的对比度，镜头与滤片/窗口透过和焦移、传感器响应、照明一致性与曝光SNR；同时评价所谓“隐形”的可见外观，不能把黑色碳点或“无IR-cut”自动当隐形方案。实际材料/打印工艺可能改变点形、点径与可选间距，因此IR阶段允许反向修改几何并重跑可解码/笔尖准确度矩阵。光安全、电气限流、温升和实际功耗独立评审；本说明不授权开IR灯或指定安全电流。

**最终冻结单元是同一组：纸/材料版本 + 相机镜头光路 + 实际安装几何 + 采集模式 + decoder/标定版本。** 必须同时有近尖原始图像、完整码窗/采样证据、独立静动态笔尖误差和可采购/两支预算证据。局部通过不能单独冻结最终纸型或对外称消费级笔已满足精度。
