## 结论和下一步

优先原生化一个完整的小块：TPS22918 U301 的 VIN/C301 输入供电及 U301/C302/C303/R301 对应地回流。最终模型只有 **7个对象：6条线+1颗标准0.60/0.30mm地孔**，不删旧铜、不移动器件、不短接JP301。全组有限铜筛无冲突，假设有限铜核心连接从AON23→25/39、GND57→61/102、SENS保持12/12。具体逐对象坐标在gate3.json和check.json。

第二目标 U101.2/.3 VDD3P3/C103 未得到可接受的整体路径。初始局部逃线后扩大到0.508mm的候选被已布CHIP_EN/BOOT_N阻挡（first.json列精确UUID/层/区域）。**这是这一个候选被拒绝，不是板无路；没有删除控制网腾路，也没有用更细主供电硬塞。** 后续需协调这两个控制网的完整回接、或电容/供电入口局部布局，而非重复平行线试探。当前只推进前述U301完整局部回路，避免无界搜索。

## 3. 已完成的只读检查

- 所有新对象彼此与当前所有铜/实际pad层进行0.15mm异网铜距筛；新孔对包括同网的所有实际pad做环交叠排除，并核与现孔的0.25mm钻孔间距。
- 用实际Edge.Cuts做0.25mm铜边检查；按原生track/via rule area逐层核禁区。绑定原.pro/.dru，新增AON/GND采用0.15mm混合铜距；没有把FineSignal127的0.127mm用于电源放宽。
- 新孔BuildCourtyardCaches后对全板F/B courtyard筛无相交；这是名义2D安装预算，不是所有实物高度、阻焊偏差或夹持力资格。现有三个复用孔的既有工艺限制没有因此消失。
- 有限铜模型连接全部六个新增目标pad到对应核心；保所有旧物理pad分量、八项本地gate连接对及SENS全树。
- 五项删除反例分别移除整个两线AON分支、U301地孔、C302地线、C303地线、R301地线，均使目标失去核心。模型负例不是原生CLI删除试验。
- 平面按新异网孔的0.15mm间距进行**名义反焊盘排除模型**。最后仅有一个新GND孔且其名义反焊盘位于AON区域外（最靠近处仅约0.05mm几何余量，不代表层间注册/蚀刻公差资格），因此五个旧填铜区域减量均0，旧信号的参考投影新增损失0。以权威guard只对已知raw native fractured填充一次Unfracture后，0.25mm侵蚀均1片。
- 上述平面预测不是KiCad fresh-fill：不能覆盖thermal spoke、最小岛删除、真实布线后重新生成的填充、DC载流或瞬态回流评估。原生化时必须fresh-fill并全核心/全部pad分量重验。
- normal/-O check输出逐字一致；输入PCB/规则/源数据哈希不变。plan_view.png已实际查看。

## 4. 明确拒绝/取代的中间假设

first.json保留两个最初候选的实际冲突；alternatives.json是7个有界局部地孔备选的拒绝结果。第一次完整gate9对象方案（gate2.json）可通过铜距，但额外AON孔并非唯一接入：删除它后仍通过现有AON孔(10.9,64.875)连核心，故“唯一孔删除必须断开”的断言失败。没有隐去此结果；最终改为直接复用该已有孔并删掉不必要的新孔/长stub。

第一次中间courtyard检查未BuildCourtyardCaches，空cache结果不能作为安装证据；最终脚本明确先建缓存后检查。未把那个中间结果收为最终判据。

MCU源pin2/3的0.4mm节距不能直接在pad中心套用20mil线宽而侵犯相邻异网；初始模型显式用短0.25mm逃线后加宽0.508mm，但下游仍受EN/BOOT限制。宽度目标依据已有官方供电评估报告（Espressif通用S3指南），并非本计划新增的厂家认证要求，也不将SoC规则无条件等价为SiP封装每处允许例外。[官方供电布局指南](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s3/pcb-layout-design.html#power-supply)
