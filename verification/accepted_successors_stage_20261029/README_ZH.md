## 硬件状态

历史冻结独审的全量结果为 **17违规 / 21未连 / parity0**，DRC exit5。恢复环境对同一字节 PCB 的新 DRC 可能产生不同条数，必须看本批 `portable_check_result.json` 的实际 fresh 结果和差量；条数变化不代表铜线被修好。冻结 PCB 字节没有因为备份而改变。

五网闭合不等于DVP/采图功能完成。当前24Pin研究接口不是用户30Pin定制模组线序确认。JP301及充电 commissioning 开路，未知相机不得接电。IRQ极性、I²C实际电容/VOL、供电动态/回灌、短段维护、参考返回/EMI、DFM、温升、实际电池/保护/充电仍未合格。

实际原生 J103 仍在B52，ACCESS机械研究使用的B70.5长线接口未实施；J301仍y88.7，y92.3只是旧预检。机械笔芯简化扫掠无正体积交叠不能证明配合，slider/grip的零间隙和头部直走线碰前框的问题仍在。不存在电路与机械一致且实物装配合格的整笔版本。

## 相机 V2 软件边界

原 V1 reset 表越界失败原日志保留，V2修复采用表的实际编译期长度、写前完整终止符检查、边界循环与写失败传播。V2独立复核通过原八组主机测试和新增26,829次 CHECK执行（不是26,829个独立场景），两套真实 ESP-IDF 5.4 构建成功证据保留。

这只涉及固定合法 VGA / Gray8 的 SC031GS 软件包装器。实际购买的 **SC035HGS仍不受该候选支持**。默认OFF、空profile和不启动相机的编译入口保留。通用原始 `esp_camera_init` 并非已强化的不可信参数入口，不可从固定VGA的通过推论任意枚举/空指针/任意传感器都安全。

HAL软件时间戳不是曝光中点或已测首DMA时刻，压力同步未验。PSRAM运行配置、实际I/O电平/时钟、图像/FPS/准确率、射频、续航与整机安全均未测。SDK日志中的烧录提示不是本次操作指令，不能拿编译夹具直接接相机运行。

## 离线复验

快速hash核对仅需Python标准库：

```sh
python3 portable_check.py
```

可选隔离软件复验需要本机已安装gcc与ASan/UBSan；不下载、不连接设备。需保留各本地发布批相邻，或显式给发布目录/已装配仓库：

```sh
python3 portable_check.py --software --publication-root /path/to/pen_publication
python3 portable_check.py --native --repo-root /path/to/smart-pen-codex
```

`--native` 还需要已安装KiCad 9及系统Python的pcbnew。所有源按hash物化到临时目录，修改/输出只在临时副本。核对五个独审的关键几何检查normal/-O、两份强制勘误、最终板新DRC完整finding差量。它不重新运行每个历史负例、每次refill、每个原生生成器或机械CAD审查；原冻结报告与此次实际重跑范围明确分开。相机SDK两套编译由本次独审已重跑，本包装复验不再次重建SDK。
