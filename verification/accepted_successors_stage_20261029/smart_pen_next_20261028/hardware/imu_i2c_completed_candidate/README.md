权威板：`native/mainboard_revD.kicad_pcb`，SHA-256：
`6b44e149edf7e3b6c843375125a71247ece6c664eb531686dd3b451e1586ee71`。

- 有限铜图：仅两条 I²C 网合并；所有旧 pad 分量不退化；AON 六个填铜岛、GND 四个填铜岛全部连接原核心。JP301 保持 OPEN。

## 有界成组重排，而非单 via 救线

GPIO5/6 原位拥塞。新扇出沿 F 面原 CHIP_EN/CAM_D0 之间下行，在 `(1.725,15.75)` / `(1.725,15.10)` 使用 .45/.20 mm 通孔进入 In3。为打开完整通道，仅替换四条旧铜：

| 网络 | 旧局部长度 | 新局部长度 | 全网长度变化 |
|---|---:|---:|---:|
| CAM_D0 / F | 4.644975 mm | 4.644975 mm | 0 |
| CAM_D7 / B | 9.125000 mm | 9.477082 mm | +0.352082 mm |
| CAM_PWDN_UART_RX / In3 | 7.775000 mm | 8.562006 mm | +0.787006 mm |

D0 总长 24.830590 mm；D7 总长由 30.961449 到 31.313530 mm，因此两者总几何差增加 0.352082 mm。完整 D0–D7、PCLK/HREF/VSYNC/XCLK 统计见 `measurements.json`。不是制定任意硬等长门，也不是时序已合格。旧 DVP 全部端点/实体保留，修改段的参考投影未产生新缺口；D7 旧约 .89 mm 单段投影缺口仍存在，不能隐去。

最终相对基线删除 4 个旧 track，新增 **302 tracks + 7 vias**；无旧铜原位改网、无旧 via 减径。精确 UUID/网/层/宽/坐标见 `geometry_delta.json` 与 `serialized_delta.json`。

## 总线长度与维护门

| 网络 | 总 track 中心线长度 | tracks / vias | < .1 mm 短段 |
|---|---:|---:|---:|
| SCL | 88.336048 mm | 92 / 2 | 38 |
| SDA | 130.156340 mm | 197 / 5 | 98 |

长度是包含分支的全网 track 总和，不包含焊盘内路径或 via 电传播。先做保留端点、分支、pad/via 节点的有约束可视线段简化；原一次简化移除 731 段、替换为 232 段，后续另有顶部 via 移位和 MEMS 外逃修正。`bus_simplification.json` 是中间步骤证据，最终身份以 delta 为准。仍有 136 条新总线短段、最短 .025 mm；本阶段是完整静态接通候选，**不称已达到优雅量产布线**。

SDA 经过顶部 F 通道再回 In3，因此比 SCL 长且换层多。没有在 In1/In4 地层开长信号槽，没有用 .15 mm 细线修复相机电源。后续可在整体布线维护中改善，不以低速豁免边沿/EMI/工艺检查。

引用 `docs/electronics/imu_i2c_timing_budget` 的冻结合同：10.1 kΩ（仅 +1%）时，100 kHz / 1000 ns 对应理论总 C ≤116.85 pF；400 kHz / 300 ns 对应 ≤35.06 pF，未扣 TCR/老化，实际总 C 未测。首轮 100 kHz 只是待测配置，未改源电阻，**不保证 400 kHz 或上升时间合格**。

## 新反焊盘、返回地与 RF

- 连续同层中心线投影筛选最大缺口约 **.406774 mm**；采样 ≤.005 mm，边界不确定性按 .010 mm 报告。跨层/分支不硬拼成连续路径。`continuous_reference.json` 不是回流/EMI 仿真。
- 各信号 via 到现有 GND via 的真实距离见 `measurements.json`；最远约 4.19 mm，不能仅因地岛全连就称高频换层返回已资格。
- 全部未改旧 F/In3/B 铜的参考地投影 **新增丢失面积为 0**；另核 RF/时钟焊盘投影。新 In1/In4 反焊盘约损失各 3.083734 mm²，In2 AON 约损失 2.709544 mm²。面积小本身不是通过依据。
- 顶部 SDA via 原 `(5.95,1.35)` 的新 In1 空洞距 RF 铜/焊盘仅 .098537 mm，未采纳；向下 .45 mm 会撞 IRQ/STRAP/CAM_SDA，已拒绝。最终向左移至 **(5.20,1.35)**，最近空洞到 RF 铜/焊盘 **.376670 mm**，到时钟 **2.448602 mm**；均无投影相交，六层 RF 禁区无新增侵入。通过本轮 **.35 mm 项目敏感区筛选**（约 3×.1164 mm 参考介质厚度），不是厂商规定、不是 50 Ω/边缘场/天线实测保证。
- MCU SCL via 旁 In2 反焊盘到旧边界局部仅 .0745 mm；SDA 空洞局部与旧边界合并。反事实只将这两个孔周围 In2 填铜清空半径从 .375 扩到 .55 mm，删除额外 **.514514 mm²**，所有旧 AON pad 仍接原核心。证明该边缘狭条不是必要连通颈；不证明全板电流密度、温升或其它剩余路径截面已资格。真实候选没有加细线补救。

## MEMS 同侧实体审查

继承已独审分层规则，不恢复错误的全六层空白要求：F body 禁 pour/through-via，中央 F 禁穿越，内层可恢复参考面；外围旧链接和装配应力仍有人工门。

最终新总线 F 铜进入名义 body 的部分，仅在实际 pin1 / pin4 的外半焊盘及明确的**左向必要接近带**内；带外面积 0。这些项目带不是 ST 给出的精确例外尺寸。第一次 SDA 从 pin4 向下离开 body 的候选虽中央 DRC 未报警，但仍超出左向接近带，已改成先向左出 body、再在 body 下方返回。`mems_approach_screen.json` 逐对象公开交叠，不能用中央 rule 替代全 body 审查。

## 制造/安全边界

- 所有新 I²C 铜 .15 mm；新信号通孔 .45/.20 mm，理论环宽 .125 mm。保持 Default 规则，未暗改为 FineSignal127。
- 既有项目最小 via .45、drill .20、annulus .10、孔距 .25 mm；满足项目并不等于厂家已批准。叠层 JLC06081H-2116 候选 .83 mm，机械上界 .93 mm；钻孔、DFM、成本报价和装配仍未资格。
- 现有充电 commissioning / JP301 均 OPEN。未知 30 pin 相机不得直接供电。TPS22918 不是过流限流器；IO 回灌、真实负载、QOD 放电热资格未解决。
- IRQ 模式/极性/路由/锁存清除与睡前电平、I²C 上升时间/总线恢复、实测唤醒仍需固件和硬件联调。铜连接不等于已能拿起就写。
- 17 项旧违规、33 未连及其它机械/制造/测试门保持公开。整笔未完成。

## 重现与审计

冻结后**不要原地运行会写结果的脚本**；复制包到新的工作副本，或在隔离输出目录运行 `replay.py`。本包保留完整 native 源树、精确差量，不复制全部历史。

```sh
/usr/bin/python3 hardware/imu_i2c_completed_candidate/replay.py --output /tmp/NEW-EMPTY-DIR
/usr/bin/python3 hardware/imu_i2c_completed_candidate/verify.py
/usr/bin/python3 -O hardware/imu_i2c_completed_candidate/verify.py
```

重放从冻结 IRQ native 和本包精确序列化差量重新填铜，可复现最终 PCB SHA。全量命令/退出码在 `native_command_results.json`；标准参数为 `--all-track-errors --schematic-parity --severity-all --exit-code-violations`，不是默认节选 DRC。

正常/-O 审计一致；5 类负例共 10 次，按精确错误类别拒绝（旧 AON 改网、新总线改网、新线变细、新 via 钻孔变化、IMU 身份变化），不把任意异常当通过。参考面/机械几何筛选与最终实际铜图彼此独立，不能相互替代。

`comparisons/` 为明确拒绝/中间比较，原始栅格板压缩备份不准当成最终板；依赖版本在 `dependencies.json`。本候选仍待本次独立复核后，才能作为下一布局阶段基线。
