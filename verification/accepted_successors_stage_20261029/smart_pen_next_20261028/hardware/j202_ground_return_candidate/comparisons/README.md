# 拒绝或中间比较，不是最终 PCB

统一 y89.5 / y89.8 直引孔在 pin10/13/17 处碰撞既有数字铜/正面 J301。不得以已减少7项未连为由接受。

局部外侧候选扫描明确找到 pin10 错位孔、在选定有限区域未找到 pin13短折线；扫描脚本在 pin17 穷举未完成时主动终止（exit130），不宣称全局无解。最后 pin17 手工坐标由完整 native DRC 核实。

pin13 本体下孔版本电气 DRC 可达17/26/0，但原厂底面金属窗口未完整尺寸化，不能凭 body框说绝缘安全。最终取消该孔，改成 y91.2 的短共享地条接 pin10。最终 native不依赖本体下盖孔。
