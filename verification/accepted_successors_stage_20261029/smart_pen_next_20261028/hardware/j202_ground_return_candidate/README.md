## 实际完成范围

在已独审的 I²C 基线 `6b44e149…1586ee71` 上，只增加接地铜：**12 段 B.Cu 地线 + 6 个 .60/.30 mm 普通通孔**，旧 track/via、全部 102 封装、356 源端点、J202 的24脚定义、原理图/MPN/项目规则均保持原身份。

J202 地脚 **1 / 4 / 7 / 10 / 13 / 17 / 24** 已由实际有限铜图证明接入原 GND 核心与参考平面。未把固定孔或机械焊脚偷改接地，未改任何信号定义。

- 完整原生 DRC：**17 违规 / 26 未连 / 0 parity**，退出码 **5**。
- 与基线17/33/0相比，7项未连消除；原17项违规的完整多重集不变，不是整板DRC通过。
- ERC：0错误、1条原有 VBUS 全局边界警告，退出码5。
- 有限铜图只有 GND pad 分量合并；所有旧 pad 关系保持，AON 6个岛、GND 4个岛均连原核心。
- 正常/-O一致；6类负例共12次按精确原因拒绝；重放+fresh-fill复现相同 PCB SHA。

## 本体、孔和阻焊的真实边界

使用已冻结的 Molex [5034802400 官方系列图 SD-503480-001 J1](https://www.molex.com/content/dam/molex/molex-dot-com/products/automated/en-us/salesdrawingpdf/503/503480/5034802000_sd.pdf)，重新目视核对第1页底视图、剖面和推荐板图。其底面确有端子/窗口，但没有给出每处底部金属到 PCB 原点的完整间距，仍需原厂3D/实物底面和装配确认。

- 六个新增 via 的**原生 F/B tenting 均明确设为 TENTED**，并核实 `IsTented`；不是 README 假设。普通阻焊盖孔，不要求树脂塞孔、填孔或 via-in-pad。
- 所有新孔都不在 SMT pad 内。相对原生保守 body框 x=.05..13.95/y90..94，孔钻边名义上在框外，最小仅 .05 mm；这不是带公差的实物底部间隙保证。部分铜环可进入保守框边缘。
- pin13 深入本体下的孔已取消；其短地条在 B 面 y91.2。该水平段与 J202 阻焊开窗交叠为0，新 track 没有额外阻焊开窗。
- 当前原生全局 mask expansion=0、min width=0，不代表制造允许零间隙。J202 邻接信号 pad 的名义 mask web .20 mm，内侧短地条到信号 pad mask边名义 .225 mm；实际板厂公差、盖孔可靠性、回流焊吸锡与底面接触仍是制造/装配门。
- 未改变外壳、FPC端头、锁扣扫掠或线束高度；不能据这次铜变化沿用不存在的连接器装配批准。

## 电源与全部既有信号返回面

`plane_reference_audit.py` 对新旧填铜都扣除了**全部真实通孔钻孔**，避免把 GND via 中心孔误当成实心地铜。

- In1/In4 真实孔形校正后各减少约 .424073 mm²，来自6个新孔；In2 AON减少约3.054899 mm²。
- 对全部未改旧 F/In3/B 铜逐对象比较参考投影，DVP、I²C、IRQ、RF及其它信号的**新增缺口面积为0**；RF六层区域没有新铜侵入。
- 所有旧 AON/GND pad 分量和全部填铜岛仍与核心相连。面积小、网名相同或DRC无新增都不作为替代证据。
- 该屏查不是回流/电流密度、阻抗、EMI仿真或整板最小颈宽保证；原有动态/PI门不撤销。

## 后续信号扇出与安全门

这次只完成地，不代表24Pin信号已可布通：pin13内侧 B 短条和 pin10外侧错位引线占用了实际局部空间，后续 DVP成组扇出须重新检查。**冻结是版本审计，不是永远不得移动这些地铜**；新候选可重新安排地 via/短引，只要真实七个地端、返回面和全板检查不退化。

J202 是明确的新24Pin未来紧凑头接口，**不兼容也不授权接未知30Pin定制SC035HGS模组**。本次没有改VIO、供电、LED、控制线或18→24迁移合同。JP301及充电commissioning保持OPEN；相机默认隔离，不上电。剩余26未连、17旧违规及板厂DFM/报价/低功耗/固件/实际测试门继续存在，整笔未完成。
