# 619a MEMS 中央筛说明勘误（不改冻结几何）

适用：`hardware/mems_layered_rule_study` manifest `57699dacb2002f2af06b04af305912e596e73f720168d1f4e4dc538b37e73b3b`，PCB `619a1307b7eb18c27d34f323e511726d95b373cca4e4dd2c11e284f03501eaf0`。

独立审查按真实旋转后的焊盘投影发现：

- 中央筛的x=3.425/4.575确为侧排pad内缘。
- 端排pad的实际y内缘为81.425/82.575；候选中央筛采用81.4125/82.5875，各向端排pad延伸0.0125mm。
- 原说明“由实际焊盘内缘界定”应限定为“项目中央筛，含12.5µm端排pad重叠”，不能称精确匹配所有pad内缘。原因是初始计算未将端排pad的90°旋转计入外形投影。

冻结规则已显式允许pad，现有实际F走线没有侵入中央筛；独审复现的完整DRC/连通结果不因这处文字精度勘误变化。既不改旧板，也不将重叠偷称为厂家尺寸公差或厂家许可。未来若调整筛边界，须另存候选并重新跑实际铜/规则负例。

ST TN0018 p14图15/16是同侧留空/背侧可布的指导，不给出此项目中央筛坐标。其§3.11 p15的向外逃线建议亦需一起核查；旧底排两段GND边缘连接仍是人工符合性/应力审查门，不因本规则通过就宣称整个MEMS已符合全部厂规。
