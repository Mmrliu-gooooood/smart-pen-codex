# 高 B 值真实 NTC 原生 TS 补查（2026-10-28）

**研究结论：BQ25170 + TDK B57371V2103H060 值得进入独立候选架构研究；不是现板替换批准，不是充电/制造放行。BQ24074 尚未找到合格的真实高 B 10k NTC。现有冻结板、安全门、JP1 开路状态全部不变。**

## 1. 真正修正了什么

“给固定 NTC 加正值串/并电阻不能收窄温窗”不能推出“换另一条 R–T 曲线也不行”。本次实际换曲线，而非给旧 Vishay 曲线换一个典型 B 数字。原 NTCLE100E3103GB0 + BQ25170 最坏热停 45.182°C 的失败结论仍有效；不靠四舍五入消除失败。

下列计算采用官方逐 1°C 的 **Rmin/Rmax 完整表**；它已包含初始 R25/B 容差，不能再重复乘初始容差。每项阈值遍历 2 偏流 × 2 阈值 × 2 阻值包络 = 8 角点。`results.json` 保存全部角点。单调表只能严格给出相邻整数温度括界；小数温度是线性插值估计，不是厂家承诺。

|---|---|---|---|---|---|---|
| B57371V2103H060 | 0603，10k ±3% | 8507，B25/100=4480±3% | 2.559–8.090 | 36.733–43.671 | +160.089mV | +9.721mV |
| B57471V2103J062 | 0805，10k ±5% | 同曲线 | 2.149–8.436 | 36.284–44.107 | +133.151mV | +6.581mV |

优先 H0603：严格冷停包络 **[2,9]°C**，热停 **[36,44]°C**；冷热恢复分别 **[5,12]°C、[33,40]°C**，可保守把 **12–33°C** 视作静态全角点恢复后的充电温区。代价是部分个体约37°C已停止充电，不能宣传完整0–45°C均可充。其 Rmin(0)=34249Ω，Rmax(45)=4209.6Ω。两型号均**不满足最低10°C才准充的电池**，不能套用到 Jauch 10–45°C 候选。

## 2. 官方电气界限与可复算公式

BQ24074：I=72…78µA；冷停2…2.2V；热停.270….330V。BQ25170：I=36.5…39.5µA；冷停.99…1.09V、冷恢复.83….93V；热停.176….200V、热恢复.208….232V。引用的 BQ24074 电气表保证范围为结温0…125°C，BQ25170 对应表为−40…125°C，并须满足各自供电/测试条件；不能外推 BQ24074 到结温零下的保证。BQ24074 恢复迟滞仅典型值，未伪造其保证恢复界限。[TI BQ24074 Rev N §8.5](https://www.ti.com/lit/ds/symlink/bq24074.pdf)，[TI BQ25170 Rev A §6.5](https://www.ti.com/lit/ds/symlink/bq25170.pdf)。

- 冷边安全余量：`Imin * Rmin(Tcold) − Vcold_max`。
- 热边安全余量：`Vhot_min − Imax * Rmax(Thot)`。
- BQ24074 必须 Rmin(0)≥30555.556Ω，Rmax(45)≤3461.538Ω。对于标称10k曲线，未计任何容差已需有效 B25/45≥5031.526K。B25/100=4480 不是 B25/45，更不能仅凭产品系列“最高4500K”宣称该10k型号合格。
- H0603 与 BQ24074 热停估计40.562–49.670°C，45°C裕量−58.349mV；J0805更差。**二者明确失败。**
- 保证端点要求最坏 R0/R45 比≥8.827160；H实际仅8.135927，J仅7.813061。普通同一正值串联电阻使比值向1压缩，并联也如此；组合正值串并联不能增大此比值。因此不能靠这种无源整形救这两条固定曲线。此证明不涵盖有源电流/参考改造，也不宣称所有世界上的10k NTC都不可能。
- BQ25170 要求 Rmin(0)≥29863.014Ω，Rmax(45)≤4455.696Ω；H通过。另加固定分压参考属于新电路，不能默认不增加失效模式。

## 3. 裕量还没有变成产品安全保证

H0603 在45°C有246.096Ω额外串阻等效余量（只单项变化）。`check.py` 另列**假设性**额外误差：±0.5µA外围漏流、50Ω串联线阻、±1mV地差，再叠加±0/1/2%装配后漂移。H的热边剩余4.616/2.932/1.248mV；J对应1.436/−.280/−1.995mV。以上不是实物保证预算：尤其TDK可靠性表中的漂移是典型数据，不是可直接拿来做全寿命最坏值的保证。

无额外误差时H最坏热停插值43.671°C，距45°C约1.329°C；只凭整数表可保守用1°C。这个差额必须覆盖传感器与电芯温差、动态滞后、去抖/检测延迟和全部装配后误差，不可同时重复占用。加完上述误差后不能仍声称有1.329°C。TS功耗约几十µW也会产生自热；板载耗散常数不能当胶粘到电芯后的测温保证。必须取得/验证：真实电芯表面/内部允许温度定义、最坏升温速率、传感器牢固绝缘贴合、胶老化和跌落、热源串扰、冷启动、自热、线阻漏电与漂移界限。没有这些，静态端点过关≠单故障安全过关。

## 4. 新候选不能丢掉的功能与失效检查

这里只允许提出另线研究，不移除现板27封装增量。原生TS对NTC开路/短路可形成停充，但**传感器脱离电芯仍电连续、阻值卡在室温、充电IC内部TS故障、控制接线错误**可能不被检测；保护电池的电压/过流保护不是电芯温度保护。一个TS不等价于双测温独立链的冗余。反之，现双链共享地/充电IC及机械环境也不是任意单故障均安全的证明。

BQ25170没有独立SYS电源路径。若进入新原理图，必须保留并证明：
1. 插电充电时硬件停止书写/隔离大负载，MCU复位、死机、GPIO高阻不能破坏默认安全；不能只靠软件让系统睡眠。
2. TS拉低停充控制的默认态、开漏元件短/开路、上电/掉电与漏流对温窗的影响逐项验证；不能用固定“常温电阻”旁路真实NTC。
3. 终止电流必须量到电池而非持续系统负载；包括外围待机漏电、异常开机和定时器行为。不能因换芯片就宣称保留原PowerPath行为。
4. 电池→USB反灌，以及USB数据/调试线/旁路路径的反向电流、插拔瞬态，必须按新拓扑检查，不能仅凭充电IC休眠漏电宣传值跳过。
5. 保护电池/独立保护器仍负责异常过压、过放与短路；核对充电CV最坏值、设置电阻误差、最大充电电流、保护阈值/延时和MOS故障。原生TS不能取代这些。
6. 共同失效与物理热耦合测试仍是放行门槛；如果风险分析要求一个充电IC内部故障后仍具独立热切断，单TS候选不适用，须保留独立通道或改变安全架构。

用户明确要求安全、准确、体积、≤380元全包，未明确要求双NTC/六新增IC或任意单点失效认证。是否接受较简架构必须由主任务结合风险评估与用户确认决定，不能由本计算自动批准。

## 5. 真实面积、采购与边界

H0603是1.6×0.8mm本体，J0805为2×1.25mm；不是直接将0603贴在主板就能测电芯，仍需合格的贴电芯载体/引线/应力保护。BQ25170 2×2mm本体对BQ24074 3×3mm本体少5mm²，但**不等于整板少5mm²**；新增负载隔离/接口/热路径尚无已布线BOM，不能声称从50封装立即降到23，更不能以此报出380元已达标。前一研究实测现板630mm²/50封装，旧core420mm²/23封装，只是基准，不是此候选实现。
