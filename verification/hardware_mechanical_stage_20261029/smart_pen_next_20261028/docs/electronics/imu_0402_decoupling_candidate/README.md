# C501 / C502 0402 局部回路候选

只用于两颗 IMU 100 nF 候选，不降低其他电容尺寸或冒称装配工艺已资格。

精确候选 KEMET **C0402C104K4RACTU**，别名 C0402C104K4RAC7867。原厂当前生成规格：[官方 PDF](https://yageogroup.com/component-documentation/download/specsheet/C0402C104K4RACTU?lang=en)。0.1 µF ±10%，16 V，X7R，0402；L 1±.05、W .5±.05、T .5±.05 mm。上界实体 1.05×.55×.55 mm，另留 .15 mm 焊料/安装高度，共 .70 mm。这是候选，不能把标准 EIA 名字当实际pad相容性验证；须检查原厂端接 B=.3±.1，间隙 S≥.3 与实际 footprint。

实际下载原厂 PDF 第 2 页有 DC bias 典型模拟图。视觉粗读 3.3–3.6 V 约损失 4–6%，即名义值典型约 94–96 nF；未叠加初始公差、温漂与老化，非保证最小值。第4页明确典型模拟不是规格。相对原0603方案的目的不是盲缩体积，而是让两去耦紧靠 VDD/VDDIO 并各自短支路接地，减少共享阻抗及绕行。

暂无整板装配报价或实际焊接/电源噪声测试。原生源/布局最终绑定另行完成，本文不修改冻结源。若采用该精确MPN，应在新source合同只更改 C501/C502，保持100n数值与所有net不变；不得将旧 Murata 候选的采购/曲线自动归给它。
