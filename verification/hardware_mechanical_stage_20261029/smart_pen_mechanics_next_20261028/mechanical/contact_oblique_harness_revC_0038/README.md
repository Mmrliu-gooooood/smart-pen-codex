# CONTACT 真实斜直线线束 RevC（局部 NOFAB 候选）

## 结论与范围

本目录独立于已冻 RevB。它不再强迫导线从载板背面向 +Z 绕电源，而是用**载板 F 面 SMD land → 主板 B52 的 +Y、−Z 斜直线**。实际原生小板有两网、五 pad、已画铜连接；基本 DRC 0/0。这是一条可按下述次序尝试装配的完整静态两线几何候选，**不是抗拉、抗振、热疲劳或工艺放行**。毫米级短线没有服务余量，不能宣称可带线拆换。

本次联合上下文绑定实际主板 `hardware/imu_compact_0402_placement/mainboard_revD.kicad_pcb`，SHA `dd55c7b2a342bea2ea900a6daac70f7dff88274d1ad05132aa6ce3ef6b93d9a5`。从 4059 实际板对比，仅 C501/502/503/R501 实体变更，其余所有 footprint 的位置/角度/面/值/焊盘坐标及网名均相等。C501/502 精确 KEMET C0402C104K4RACTU 本体 1.05×.55×.55 max + .15 装配= .70 高；C503 C0805C106K8RACTU 本体 2.2×1.45×1.45 max + .15 =1.60 高。几何取实际原生 pad/fab 与本体最大框之并集，不给其它被动件降高。R501 保留 1.45 未知装配预算。未据此宣称整机、全线束、成本或外径最终通过。

## 实际铜与身份

小板 F 面朝笔头 −Z，X=PCB_x−3.75，Y=−PCB_y−.4，名义 F 铜 Z78.4。

- J1.1 CONTACT：PCB(1.45,1.2)，笔坐标(−2.3,−1.6,78.4)，仅 F 面 1.4×1.2 手焊 land，接 SW1.3。
- J1.2 GND：PCB(6.05,1.2)，笔坐标(+2.3,−1.6,78.4)，接 SW1.1/2。三个 SPVE 端子全部按此前原厂 No1 土地图使用，没有新增 NC 悬空金属。
- SW1.1/2 GND 的 PCB 中心(5.875,4.15)/(5.875,2.65)；SW1.3 CONTACT(1.625,3.4)。原厂 land 1.2×.7、内缘间隔3.05、双端节距1.5 不变。实际短铜路/网已在 native 中，不以“机械线”代替电气连接。
- 主板 J103.1 CONTACT PCB(3,52) → 笔(−4,2.2647931763,75)；J103.2 GND PCB(5.4,52) → 笔(−1.6,2.2647931763,75)。原生铜 pad 旋转后 X1.8×Z1.4，焊线装配预算并非铜尺寸。CONTACT 保持先 R504 再 NIB，不把它接到电源或旧六芯 pickup host。

## 导线与可复算实体

依据 Alpha 官方 2840/7 规范：32AWG(7/40) 镀银铜，导体 nominal Ø.009in=.2286mm；PTFE 外径 .022±.002in → 最大 .6096mm；最小弯曲半径 10×外径，即保守6.096mm。规范最大拉力 .53lbf 只是线材数据，**不是板上焊点/夹持合格负载**。

芯中心名义起点 Z78.2857（铜平面下 .1143）、终点主板 Y2.1504931763（铜平面内侧 .1143）。导体模型半径 .1143、绝缘段半径 .3048。每端剥线 **.8mm 是自定工艺试验目标，不是厂商许可**；没有热缩套管（未加选/未有空间或加工验证，不能假定已绝缘）。裸端分别加半径 .25、长度约 .75 的自定焊锡预算并裁到铜朝向半空间，保留 .15 的裸铜到绝缘过程余量。实际焊锡浸润、爬锡长度、皮损、股线散开仍须显微检查；裸铜 nominal 不是最大公差合同。

名义两根直线端点间真实模型长度：CONTACT 5.268019mm / GND 6.330247mm（不是下料图已批准尺寸）。载板校准 Z−.2/0/+.2 的三组长度分别 5.145653/5.268019/5.395026 与6.228783/6.330247/6.436327mm。**这是三次独立按件裁线，不是一根线自动伸缩。** 同一装配的任意强迫位移都不得由本几何结果视作允许。两线曲率为0，没有硬折或为保持短线把 R6.096 改小。最小两线实体距离1.858862mm。

## 壳、紧固与工装可达性改动

- 外尺寸仍沿用条件研究，不升级为用户批准的 19mm；此前 Ø7.6 局部壳和轴线(0,−3.8) 保留。
- 两壳半部开半径 .5048 的斜通道，覆盖三校准范围（工程间隙约 .2）。未开槽 RevB 的实际线束反例保留在 verify 输出。
- 后横螺钉/孔 Z78→78.5，Y+.6 不变；头/杆尺寸仍此前已记录的 M1.6×8 参考，螺纹/材料/扭矩/螺纹承载未放行。原 Z78 时 +.2 校准的线距仅 .037136mm，因此不保留旧位。
- 前垫片改为**有底部连接边的单件 U 形绝缘垫片**，保留两侧及底边、上沿退到 Y−2.15，给侧焊访问让位。它不是两片松散薄片，CAD 重开单实体。校准时厚度须按 RevB 实测程序重新制作，不能靠 PCB 弯曲。
- 两侧壳窗口分别 X[−4.45,−1.45]/[1.45,4.45]，Y[−2.15,−1.05]，Z[77.4,78.9]。它们使壳闭合后可从 ±X 方向接触 F 面焊线 land，避免“闭壳后焊不到”的虚假流程。
- 校准 −.2/0/+.2 三姿态、两侧共6次实际直径 .6mm 圆柱工具预算通路检查。工具尚未选型；**要求实测实际热端/锡丝进给能通过此预算**，热辐射/熔壳风险不由无碰撞保证。此窗口只能在外笔壳未装时使用。

## 安装、维护及应力释放门

1. 在不接相机/电池条件下，先完成 RevB 的真实开关 ON/OFF、回差和硬止挡校准，锁定垫片。复检无载断开、回程释放、过载由硬止挡承担。不采用软件屏蔽常闭。
2. 独立装配夹具按实际 mainB 基准、笔芯轴线和载板测得 Z 值固定主板及 cassette；**整笔内的正向固定/外壳承载点尚未设计验证，不能让焊线承担定位或拉力**。
3. 测量实际端点，制作/检验直线试片，按件裁线和剥线；禁止通过拉长短线、加急弯或焊点受力来补偿尺寸误差。两根分别标 CONTACT/GND。误差无法以轻微调整无载就位消除时换新线，不弯成小于原厂半径的 S 形。
4. 自由线预穿小支撑衬套/斜通道，壳合拢后由侧窗在载板 land 上先定位、润湿焊接，保持每端 .8 裸端目标。再将主板放入**同一刚性装配夹具**，确认自由另一端自然落在对应 J103 land 才焊主板端。所有此操作均在外笔壳未装、断电状态完成。不得扯线把主板拉到位置。
5. CAD 中 `StrainBushing_*_TRIAL` 是安装态外径1.0096/内径.6096/长1.2 的**自定义支撑衬套候选**，位于线参数 s=1.0..2.2mm。它实际不和线过盈（CAD接触），多姿态扩大通道也未提供确定夹持量。因此目前只算直线支撑空间，**不算已经闭合的应力释放**。拟用可拆软衬套须先选实际材料/自由尺寸、确认槽口容纳和轴向保持，做剪切/拉脱、回弹、蠕变及绝缘压伤试片。不能假定 PTFE 可由胶粘可靠锚固，不给未知衬套零成本或无限寿命。
6. 在工艺通过前，仅可作为夹具固定的机械/电气实验候选，不是可自由使用样机；测试施加载荷必须经责任人选定且不超过具体焊点/器件/线材最弱上界。线材 .53lbf 不能直接当成焊点抽检载荷。检查放大镜/显微下散股、焊桥、爬锡、绝缘退缩、端子错接；断电测通断和对邻近铜短路，再用批准的微电流测试前端做动态触发。
7. 每次换载板、换笔芯导致校准更改、重新分离主板或 cassette：先两端脱焊并换新线，再校准重裁。没有带线翻开或服务环，不承诺无损重复脱焊次数。SMD land 承力/剥离、极短自由段的热疲劳和焊锡爬入后刚化必须试验；这条路径不靠“零曲率”解决这些问题。

## 仍然禁止放行的边界

SPVE 50µA@3V 最低负载、50k 次目录寿命、未知保证回差和接触稳定性均继承 RevB；原100k前端仍不足，47k仅在实际 AON≥3V 全工况证明后才可采用。没有把二值 contact 当提按轨迹/光学笔尖标定。弹簧、外壳材料/强度、软握持、加工公差、两支器件可得性/工时/焊接返修/实际成本仍待验证。

线材实际仅用约12mm/支并不意味着可按此长度采购；官方标准包装100ft/1000ft，可能需要可靠小量分切来源。两支四根下料、试片损耗、新 PCB、衬套、开槽/侧窗口、薄片校准、放大焊接及夹具都必须新增到成本表，目前没有报价。**≤380CNY/支没有证明。** 全其他线束并未随本局部路径通过。

## 可复算验证
`probe.py` 为未开槽初始反例探针，不作为最终通过判据。`build_carrier.py` / `extract_context.py` / `build_route.py` / `verify.py` 为本候选流程；normal 与 −O 结果相同。实际 FCStd 重开全部有效，修改壳/垫片/PCB 均单实体，STEP 重开有效20实体。最终旧壳反例重叠 .671054514 mm³。新四实体与实际上下文无交叠；新实体最大径向值 R501=7.294843mm，未突破本次条件7.9mm预算，不改变整板 C203 最窄裕量。预览为突出线束隐藏了两壳半部、后垫片及主板上下文，真实 CAD 未隐藏它们作为碰撞逃避。
