# 主板—cassette 共基准台架 RevD（不是 19mm 成品外壳）

## 完成的小目标

已给两个原本自由浮动的固定体一个共同实体基座、可拆夹持/定位件、轴向止挡、抗转界面和实际可检查的装配次序。主板不靠 CONTACT 焊线定位，cassette 轴向反力不传给电池。**这是一套待选材料、待修整、待实测的台架几何候选，不是可自由书写样机/量产夹具，也不将未知刚度/夹紧力当成已经合格。**

既有 `whole_pen_revC` 的 B19/C19 文档明确单体壳、没有分型/螺钉/卡扣；不能继承一个不存在的“已完成19mm可拆壳”。本台架底板宽50mm、Z20..138，总长118mm，底面Y−16；圆抱箍外径10mm。它明显超出19mm笔壳，不可冒充最终外形或在尺寸栏填19mm通过。后续仍需独立可拆笔壳、紧凑支架及完整装配设计，旧单体 CAD 未改。

## 定位与承力合同（均为本项目候选尺寸）

1. **共基座**：同一底板连接四 PCB 外侧柱、头/尾止挡、cassette 下抱箍及两个叉座的键。装配测量以基座外部平整底面作为工装基准，不把焊点或电池当工装。
2. **PCB 3-2-1 定位**：Z45 左/右、Z95 左三个 B 面承点定义平面；Z95 右备用下托退低 .1，避免四点强迫板弯曲。接触仅X[−7,−6.75]及[6.75,7]的 .25mm 边带，Z各±1。两左边配垫定义X位置，两右边配垫保持，不把实际PCB宽度假定永远恰为14.000。
3. **四个可拆上 keeper**：安装后的硬止挡 spacer 把螺钉压紧反力旁路到外侧柱。模型 spacer .93mm 仅对应最厚参考板；实际按当地板厚、平整度和表面状态逐件配垫，不允许拧螺钉把板压平。所有接触件必须电绝缘、无尖毛刺；材料未锁。绝缘不等于夹紧力已合格。
4. **主板轴向限位**：头边Z32为基准；尾部止挡接触非天线一侧X[−7,−5]，名义Z133.5，独立长圆孔允许±.5mm调整。按实测板边/铜基准设定，不能靠止挡压缩 PCB。绘图板边相对铜的位置误差仍须实测，边缘定位不等于J103铜位置天然精确。
5. **cassette 径向保持**：Z69..72、内R4/外R5的可拆上下抱箍，中心(0,−3.8)。实际housing外R3.8时名义径向垫厚.2。上下耳的相接面是夹紧硬止挡，配垫错误不得用扭矩压薄 housing。真实内导向轴与外圆同轴性、抱紧后滑块不夹滞/ON-OFF不漂移须实测。
6. **cassette 轴向/抗转**：前矩形凸台Z64.4..67.6、X±3.5由两个可拆侧叉座捕获。轴向两端各.1名义配垫；两侧抗转薄垫位于X±3.5，Y−2.25..−1.0，主要接触凸台底侧Y−1.2..−1.0。每侧实际抗转接触约 .2×2=.4mm²，不隐瞒小接触面积，允许力/扭矩尚未知。每个轴向垫接触约 .6×.8=.48mm²，两侧合计.96；这只是面积，不是材料强度批准。
7. **可拆叉座键**：基座3×3×1mm方键进入叉座沿X敞开的槽，前后.1配垫消名义Z间隙，使轴向反力经叉座—键—底板，不靠短线；叉座侧向保持与紧固后的抗滑仍需实测。不能把螺钉松动时的孔间隙视作合格固定。
8. **原cassette前螺钉避让**：右叉座保留真实M1.6头的R1.6贯通侧通道，不能把头埋在基座里。已有本体头R1.5，因此名义仅.1径向间隙；该处须实测修整，不能由“普通打印±.2”自动放行。

本版9个新增紧固件沿用已有M1.6×8头Ø3/H1.6参考包络。模型中的内螺纹是名义大径简化，不是可直接打印的切削底孔：实际工艺须明确 M1.6×.35、切削底孔参考1.25mm、有效啮合/底孔深度/材料及试片；不可把Ø1.8通孔说成能攻M1.6。Gühring的 [M1.6切削手用丝锥目录](https://webshop.guhring-benelux.com/en/000009008610016000)列螺距.350及底孔1.25，**没有因此批准未知打印材料螺纹**。不得套用成形丝锥的不同底孔。

## 装配次序（不是仅检查最后一个姿态）

初始“一体叉座先装好，再向下放cassette”在途中碰撞，已明确拒绝。最终改为独立叉座，不能按旧失败顺序装。

1. 断电、无相机/电池，先以无电假件/量规检查基座、螺纹、配垫及边带接触；材料和紧固方式验证前不夹昂贵板件。不把实验室工时/量具视作免费已具备。
2. 移除上抱箍、两个侧叉座与其配垫、PCB上keeper。把已按RevC闭合的cassette沿−Y放入下抱箍，保留原两颗机构螺钉。
3. 侧叉座及其轴向/抗转/键槽配垫作为一组，从各自±X外侧水平滑入，经过沿X敞开键槽落到基座。检查各薄垫没有折皱或遗失；必要的夹持镊子/辅助夹片尚需选型，不能靠导线牵住。上紧两颗叉座螺钉前确认垫片和头避让；禁止任意强拧。
4. 安装上抱箍及其径向配垫，在耳硬止挡处闭合。实测轴线、轴向/抗转自由间隙、导向顺畅、无载断开。完全固定后再校准 ON/OFF/止挡；不得沿用夹紧前数据。
5. 上keeper和PCB侧垫移除状态下，主板从+Y降到三个B面承点。确认部件/底侧焊盘无压到定位台。装入左右定位配垫，调尾止挡，最后用按实际局部板厚配出的硬止挡spacer安装keeper。不让板边或焊膜承受未定义的夹紧力。
6. 在所有固定件完成、量测稳定后，才按RevC逐件定长、剥线、从侧窗焊载板和B52。不可先焊短线再靠螺钉拉到位置。两侧Ø.6mm工具预算仍可达，不等于真实热端/握柄已选或热损伤已通过。
7. 任何拆主板、换垫片、换cassette或重校准：先脱焊并换新短线，再按以上顺序重装。基座可拆不意味着短线有服务余量。

验证对cassette垂直放入、两侧叉座横向装入、PCB垂直放入分别取0/.1/.5/1/2/5/10mm离位姿态；均是**有限采样几何验证，不是实际手工装配或连续运动证明**。最终真实CAD重开、每个新增件单实体；STEP亦回读。尚无力矩/疲劳/跌落试验。

## 打印、量测、公差与位移：不可把目标写成已知能力

未选择打印机、材料、工艺或提供者，没有厂商打印精度合同。±.2mm仅为偏差压力情景，不是本台架保证值：两个独立特征的相对误差可达±.4；14mm跨距会产生约atan(.4/14)=1.64°、50mm跨距约.458°的差高倾斜。原样打印绝不能直接称主板B面/笔轴已对齐。

关键面/孔必须实际测量并修整或配垫：三B承点、板边定位、可调尾挡、cassette内导向轴及外圆、凸台叉座、抱箍、键槽与螺钉头通道。小孔和螺纹使用同材料试片先验证；底孔/丝锥/刀具及小薄垫制备不是任意用户必然具备的工艺。若现有资源达不到，不下令强装，先改结构/扩大配垫和止挡窗口。

**.01mm/轴仅是早期未加载相对位移测量目标，不是必要采购精度，不是线材允许变形，更不是已经合格的制造公差。** 方法输入应包括仪器型号/真实误差、校准、量程、夹具和探针方向、重复性及温度。显示分辨率不能替代不确定度。可用相对比较仪/图像法/已标定量规等实际可用方案，但本文件未选择或报价任何仪器，也未承诺这些方案达到目标。若测量U太大，记录“不足以判断”，而非填0。

测量至少包括：
- 以同一基座参考，在J103附近主板非导电基准与cassette凸台各设可识别标记，测装配前/紧固后/重复加载卸载后的相对X/Y/Z，不在通电焊盘上压表针；
- 用实测直线度/直径的试棒或其它可追溯轴线方法检查实际内导向轴，不能只把外圆CAD同心当制造同轴；
- 断电先记录力—位移和回零，逐步选定安全的验证负载，不把未经确认的“1N”或线材最大拉力直接变成机构试验载荷；
- 夹紧前后检查PCB局部弯曲、边缘/阻焊压痕、丝印/焊点/元件有无接触，cassette无载断开/ON/OFF/回差/止挡都重新记录。

短线的位移灵敏度由真实中心线算出。CONTACT/GND名义长度5.268/6.330mm，单独Z相对位移.01mm的一阶轴向应变约.1184%/.0820%；若三轴相对误差各.01，最坏一阶长度变化约.01658/.01728mm。**这些不是允许值**，没有线材/焊点微动疲劳和安装应力数据，无法从“最大拉力”推出合格位移。`qualified_allowable_joint_motion_mm=null`是有意保留的门，不拿架子看起来结实作假证明。

更正见已冻 `docs/mechanical/metrology_target_erratum_0139`：5µm是原自定窄ON窗的目标，非原厂/非必买；扩大可测窗口与可替换止挡仍待实验，.25/.35都不能默认精度无损。装配后逐件记录ON/OFF/回差，不保证所有开关公差件必收。

## 铜、射频与电池边界

- ae805原文件有5个非规则内层zone（In1×2/In2×1/In4×2）且已有缓存填铜；F/B无zone。先前只遍历外层后说“没有已填zone”过宽，本文件明确纠正。四接触条带现有track/pad/via包围框无侵入。
- **独立副本fresh fill**，等basename pro/dru/sch和所有实际库环境，完整 `--all-track-errors --severity-all --schematic-parity --exit-code-violations --format json`。原与fresh均135/54/0；135违规规范化一致，未连6条代表项有枚举端点差异。3784段线、228via、12序列化zone块（不等于12个全局铜zone对象）、6filled_polygon和net号→名称逐块规范化完全相同，102FP/焊盘身份相等。未观察到铜/网输入变化，不声称修掉未连。保留原始/等环境报告，不拿缺库额外102告警或默认123口径混比标准135。
- fresh内层铜X范围最左.30、最右13.70；边带末端.25/13.75只有.05 nominal横向空隙。最终PCB边缘/覆铜/阻焊公差及机械应力未知，所以绝缘、夹力/板弯曲/边缘损伤试验门全部保留。
- 原生RF规则PCB x5.5..12,y−6.5..0 → 笔X−1.5..5,Z127..133.5。本台架用贯穿Y[−20,20]的更宽项目保留体检查，所有新增件零侵入；这不是原厂3D射频合格边界，外侧塑料和金属仍可能改变射频。
- PCB柱退到外X±7.5，最小对既有power预算间距.5mm；旧柱贴X±7会零间隙，已作为拒绝反例。所有台架件Z≤138，距现有Z141起的电池区域预算3mm；没有螺钉伸进电池。实际完整电池包/安全/NTC仍未因此合格。

## 成本和停止门

38个CAD新增件中9个为M1.6×8参考紧固件，剩余含底座/keeper/抱箍/叉座及大量可替换薄垫/间隔件。它是一件可报价/可做量测试片的实验工装，不是优化过的首样生产BOM。打印、修整、薄片、攻丝、小量硬件、夹持工时、焊接、量测与返工均未报价；不默认免费实验室或两支可分摊为零。≤380CNY/支依然没有证明，不能把外置台架换算成19mm合格成品壳。

材料/小螺纹/紧固保持/实际位移/夹持损伤和线材疲劳未验证之前，只能开展断电夹具/量规测试，不发布制造、不接未知相机、不采购或上传。下一步先取得可用测量/加工资源和实际夹持试片结果，再决定是否值得miniaturize；不是先承诺纸面.01mm。
