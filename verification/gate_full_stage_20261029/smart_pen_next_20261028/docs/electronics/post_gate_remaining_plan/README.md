# 完整门控后剩余工作：只读分类

绑定 `hardware/gate_control_output_candidate` 的 508e71cb…6c5b35 板。完整原生口径为 **28 违规 / 41 未连 / parity 0**，不是可制作板。分类 JSON 保留原始报告条目、UUID、坐标和报告 SHA；报告代表端点不是唯一走线要求。

## 当前先后顺序

1. **先处理可维护性，不先加新走线。** 独审确认六个门控网及六个 AON 填充岛真正接入核心，但新铜有 669 段短于 0.1 mm。后继先只合并同网、同层、同宽、连续共线且无中间分支/过孔/焊盘接触的段；非共线阶梯另行分类。重验实际铜、全部电源岛、全量 DRC 和 JP301 OPEN。不能把同网标签当物理连通。
2. 然后修复 J103/J107 与既有铜的真实冲突，再分别完成物理接口；不得删所需功能降低计数。
3. IMU 中断/I²C 为独立完整信号块。相机接口大量未连要先完成真实头部版本/供电域合同，再进行时序和参考回流约束下的整组路由。

## 两处真实冲突区域

**J107：** F 面 pin 1 USB_EN1=(8.2,81.5)、pin 2 USB_EN2=(8.2,83.9)、pin 3 GND=(8.2,86.3)。既有 GND 两条短铜段和 via (8.6,82.4) 与前两焊盘冲突，产生 5 项短接、1 项孔间距、5 项阻焊报告。两个短铜 UUID `3ac5bb80-3c7d-4b2f-a6da-470db2406f74` 与 `e4f8df0a-430c-47de-81ff-a856e125fcf0` 虽打印位置/长度相同，仍是不同原生 item；不得把报告数字直接称为独立物理短路点数。修铜前应证明其接地用途和替代回路，不能假定悬空旧铜。保留 EN1/EN2 独立模式，不为了布线绑死；使用最新 Rev B 电源板三针合同，拒绝旧四针身份混用。

**J103：** B 面 CONTACT=(3,52)、GND=(5.4,52)。GND via (2.3,51.15)、CAM_IO_EN via (5.45,52.95)、SENS_HREF via (3.9,52.85) 及 HREF B 面路径与焊盘冲突，共 4 短接、3 孔间距、4 阻焊、1 间距报告。真实 Rev C 机构和短线已依赖该端口位置，优先重排铜而非移动端口。HREF 是 DVP 时序网，不能按低速控制信号随意绕行；实际参考地/时序要复核。CONTACT 必须经 R504 到 NIB_CONTACT_N，不绕过偏置/去抖。

其余 5 项是悬尾报告。必须按真实铜图判断分支，不能整段盲删；前轮这种操作曾切断内部连接。

## 功能边界与安全

- J202 当前为已有 24 针原生定义，绝不代表用户未知 30 针定制相机可直插。拟议的新头口受控 3.3 V/独立补光方案还不是本板既定源，不可悄改 GND 针用途。
- 独立 UART 取消/连续采集默认属于尚未应用的 v5 功能方案；当前 J104 不因未连而删除。
- J105 需要已有隔离/分压系统块，BATTERY_ADC 不得接原始电池。
- 压力 R503 仍为 100k，SPVE 最小触点负载问题尚未解决；47k 仅条件研究。焊盘连通不等于首笔/寿命/唤醒已实测。
- JP301 和充电 commissioning 保持 OPEN。负载开关不是过流保护，未知相机电容、QOD 脉冲、断电 IO 回灌、CT 回流和启动动态仍开放。
