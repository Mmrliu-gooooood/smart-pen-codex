# 门控测试可达性：仅定义节点，尚未批准测试

绑定冻结 508e 板。脚本实际读原生 pad 网与中心（不是 footprint 原点），普通/优化 Python 输出一致。

- **使能命令**：TP301.1 与 R302.1 均是 CAM_PWR_EN。TP301 实际 pad 中心为 (4.325,74.5)，不能拿元件原点代替。R302.2 已是串联电阻后的 CAM_ON，不可等同命令端测量。
- **开关输出、隔离桥之前**：C302.1 和 JP301.1 是 CAM_3V3_PRELINK；C302.2 是 GND。可以比较装配前测试线/夹具，但尚无实际工具、绝缘、应力释放及完整装配空间证明。
- **隔离桥之后**：J301.1 和 JP301.2 是 CAM_3V3_SW。JP301 OPEN 时此节点不能替代 PRELINK；更不能为了测量临时闭桥或连接未知相机。

机械联合审查已证明 Ø0.5 平头斜探针侵入 PCB，理想数学尖头不是合格工具。禁止将此方案解释成带电手持探针操作许可。

原型可比较“断电状态先接临时测试线、固定并绝缘后受控测量”的方案，但必须先完成：实际线材/焊点/应力释放与装配空间审查；测试设备输入范围/阻抗、供电限流和共地方案；JP OPEN 与相机断开检查；记录线号、端点、测试配置；结束后的断电拆线及焊点/短路复查。当前没有选定工具或线束，因此这些均为开放门，不能实际开始上电。

测量 CAM_PWR_EN、CAM_ON 和 PRELINK 的动态目的不同；不能仅凭一个输出电压判定默认下拉、上电误开、CT、QOD 或 IO 回灌已经合格。负载开关不是电池/短路保护。
