## 为什么改变布局而不是重复固定位置搜索

C103当前F(1.2,7.025),90°，100n/0603；其AON pad实际最右约x1.675，与U101电源pad左缘x2.25之间仅0.575mm，不足放下0.60mm孔环。背面R503 B(2.5,7.5),0°，100k，上拉连接3V3_AON与NIB_CONTACT_N，两个pad在父板均未连入其他铜。仅移动R503不能消除正面C103和U101之间的孔环限制。

本研究最多两个局部摆放方向：C103均向左0.4mm，R503分别向下4mm或5.5mm。`study.json`保存两初始布置/宽合流的真实失败；下方入口进一步撞CHIP_EN，明确拒绝。上方位置保留，只将过早扩宽的合流末端缩回短必要逃线，再补第二标准孔，并非无界平行线扫描。

## 最终单一提案（two_vias.json）

- C103 → **F(0.8,7.025),90°**。实际铜pad距板边最小0.325mm；这是名义铜几何，不是外壳/焊接公差保证。
- R503 → **B(2.5,11.5),0°**。source/net/value/角度/面不变，两个原本孤立pad仍孤立，不能说压力前端已完成。
- 不动MCU、RF匹配、EN、BOOT、J103、J106或任何旧铜。
- 新增内存对象共9个：六条AON线、两颗标准0.60/0.30mm贯穿孔、一条0.3mm GND加强尾线。全部精确端点见JSON。
- 两电源pad至宽合流的0.25mm短段分别约**0.775mm、0.975mm**；0.635mm宽部分合计约2.171mm。两孔为(1.8,8.0)与(0.6,8.75)。没有缩小孔或使用0.15mm供电线。
- C103地尾(0.8,6.25)→(1.2,6.25)为可选加强。移动后原地线末段仍与新pad相交；首次误以为此尾线是唯一回流，负例失败已保存并更正，不能把它说成必要连接。

[Espressif通用PCB指南](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s3/pcb-layout-design.html#power-supply)建议25mil主干、pins2/3 20mil及多个供电过孔。本提案达0.635mm合流和两标准孔，但**0.25mm必要短逃线低于0.508mm建议，不能宣称全面遵循指南或载流合格**。SiP适用范围与实际域电流/铜厚下限/瞬态未知，详见依赖的mcu_supply_path_assessment_2338报告及[PICO规格书](https://documentation.espressif.com/esp32-s3-pico-1_datasheet_en.pdf)。

1. 对父板780铜对象、366真实pad的全部实际铜层做0.15mm异网铜距、包括同网的孔环-pad重叠、孔距、真实0.25mm板边和原生禁区筛，最终模型零冲突。移动后的两个FP与所有旧铜/其它pad也无新冲突。没有忽略同网孔干涉。
2. 有限铜图保全部旧pad组件；U101.2/.3、C103.1、J106.2同组件；C103.2到J106.3保持。假设AON核心25→28/39，GND61/102不变。R503未接两脚不被虚报完成。
3. 两FP同面courtyard互相及与其它FP零相交；但**新via孔环与U101/C103名义courtyard存在小交叠**：首孔与U101 0.0287694mm²、与C103 0.00403508mm²，第二孔与C103 0.0112595mm²。实际pad不重叠不等于封装底部/阻焊/回流工艺已通过。该门必须在原生化前评估，不能删除courtyard或缩小安装预算以宣称通过。
4. 按原填铜、guarded raw-once Unfracture及新孔名义反焊盘作**只读**参考分析：主GND每面约减少1.202731mm²，AON扣自身钻孔约0.133616mm²；0.25mm侵蚀每层一片。父板F/B/In3信号对指定邻层的投影无新增损失，包括RF。不是候选fresh-fill、真实载流或EMI证明。
5. 四个已有CAD上下文（RevC、RevD台架、ACCESS19/20）使用**原完整安装包络**平移这两个器件，无正体积碰撞。C103沿用0.95×1.45×2.45mm，R503沿用2.45×1.45×0.95mm；高度并非厂家最大值资格。该比较只限两个移位件，不能把过往不同接口的壳研究当成当前整机装配。未设零高度、未缩预算。
