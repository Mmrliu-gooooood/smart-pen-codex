# 当前 J107 → Rev B 电源板：版本与网身份合同（NOFAB）

本合同只核逻辑/原生身份，**不是实物线束放行**。新主板 J107 三端路由候选绑定 8aa2581b…05ab5，电源板仅允许 `power14_single_feed_revB` 的 94ced2bd…dcdbc；不可拿旧 016d 主板或原 14×45 电源板的同名接口代替。

| 线标记 | 主板 J107 | 电源 J5 | 精确源网络身份 |
|---|---|---|---|
| EN1 / 1 | 1 | 1 | USB_EN1 ↔ /core/USB_EN1 |
| EN2 / 2 | 2 | 2 | USB_EN2 ↔ /core/USB_EN2 |
| GND / 3 | 3 | 3 | GND ↔ GND |

当前这两个版本的 **3 针 1:1 映射正确**。验证器从全部原生源锁定 fresh XML，同时打开两端实际 PCB 检查 pad 网身份，不只按数字配线。每根线两端需要信号名和针号标记；不得按翻面照片猜左右。旧四针 J5 的 pin3 是 `/CE_PERMISSION_EXTERNAL`，pin4 才是 `/GND`，不能套此 1:1 映射。

9 个 normal/-O 案例输出等价：正确映射通过；旧四针目标、原三针但错误板版本、地误接、重复线、源哈希变更、注入 CE、缺地、旧 016d 主板均拒绝。精确板身份不仅靠调用方 target 参数，还由验证器固定 PCB SHA 门约束。

保留电源板既有 R4/R5 100k 默认下拉，独立 EN1/EN2 模式不绑死；三线不携带 CE 许可，不闭合充电 commissioning，不授权电池/未知相机上电。真实线材、线径/电流、应力释放、防错实物、插装姿态、上电/棕断电默认和 RF 避让仍需联合设计验证。当前不是完整实物装配图，也未把旧线束几何证明继承过来。

此版本保留旧合同为历史依赖，不覆盖其 016d 源身份。主板路由已冻结，manifest `49250127029a2e9ab5c8399eb0ada354b18050e716fcc94a3bfe79e35cd73c64`，完整 DRC 17/38/0，限定独审尚待完成。本合同不替代路由独审。
