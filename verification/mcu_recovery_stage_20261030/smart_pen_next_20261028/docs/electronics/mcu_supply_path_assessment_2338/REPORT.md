# MCU供电局部分支评估（恢复完成，2026-10-30 00:42 UTC）

**结论：只接受原几何作为研究输入，不批准原0.15mm供电支线作为最终生产布局。优先在新候选中把RTC、CPU IO、VDDA及其局部去耦支线加宽至0.254mm，并一起恢复U101地端、去耦回路和主供电。当前板仍NOFAB，不得上电。** 这不是认定所有0.15mm短线必然过热，也不是仅凭小直流压降放行。

## 2. 官方资料与适用范围

Espressif通用ESP32-S3四层布局建议主供电至少25mil（0.635mm）、pins2/3至少20mil（0.508mm），其余电源推荐10mil（0.254mm）；还要求短去耦回流和主电源跨层至少两个孔。它是SoC参考布局指导，不能无条件把所有外部电容/地孔形态照搬到集成SiP封装，也不能用本六层板的0DRC替代这些目标的评估。[官方PCB指南](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s3/pcb-layout-design.html#power-supply)

当前官方PICO规格书实际为v1.2，表2-1确认pin46是CPU IO输入供电；表3-2的单路电源≥500mA供给能力不等于每个pad承受500mA。RTC还涉及内部VDD_SPI供电压降条件，不能仅看此0.775mm PCB段。[PICO规格书v1.2](https://documentation.espressif.com/esp32-s3-pico-1_datasheet_en.pdf)

因此加宽局部分支是本项目的保守工程选择，不声称厂家对这个SiP的每毫米都规定不可例外。源/负载、回流和瞬态证据齐备前不得宣布合格。主板已有0.5mm桥也低于通用0.635mm主干目标；本报告不对该桥负载能力或全主干作最终判定，应在完整主供电复核中独立处理。

## 3. 铜厚与计算限定

实际原生stack已逐层核对绑定JLC06081H-2116研究合同：F/B名义35µm，内层15.2µm；介质0.1164/0.1300/0.2028/0.1300/0.1164mm，Cu+介质合计0.8264mm。合同状态明确**非厂家下单确认**，没有铜厚/蚀刻/孔镀铜保证下限，也不能把名字相近的0.2104mm中心介质版本混用。

脚本采用假设铜ρ20=1.724×10^-5 Ω·mm，温度系数0.00393/°C，R=ρL/(wt)。65°C是计算温度，不是实测铜温，也不是因环境上限65°C就保证铜不更热。上表仅局部走线，不含via、pad电流扩散、plane、连接器、稳压器、回流、封装和瞬态L·di/dt；不构成完整压降/温升预算。

额外25µm铜厚、宽度减30µm的假想敏感性在65°C给出RTC/CPU/VDDA约5.241/12.004/6.594mΩ；这些不是工厂认证最差值。F→In2中心距离0.2867mm；假设0.3mm孔、15/20/25µm孔壁镀铜，圆筒近似R20约0.350/0.262/0.210mΩ，仅说明未知镀铜会影响估计，不是孔额定电流。

## 4. 下一步决定与硬门

- 组0/5/6共10条局部track加宽至0.254mm的内存有限铜距筛无冲突（保持0.15mm异网规则）。这只含当前对象与拟恢复8组的异网筛，不是已保存原生板、全DRC或完整供电/返回资格。需新候选、fresh fill、全部孔/同网/board/keepout规则复核，不能直接标成可制板。
- 原8组可作为受控复用输入；**优先恢复为加宽的MCU供电分支候选，不把0.15mm原样版默认为最终版。** 不建议仅为机械保留旧线宽；若原生加宽出现不可避让局部颈，应明确其长度、周围pad/工艺、公差与电源条件，再决定改变布局。
- 当前U101.57有9个物理pad，全部未接J106地核心；这是一项真正的连接缺口。C207地也未接。必须恢复完整地路径、去耦电容两端回路及足够宽的主供电，同时确认AON/SENS_VIO域不误接。不能先只接VDD上电试验。
- 需检查实际供电容量/最低端电压、负载跃变、RF/PSRAM活动、去耦直流偏压有效值、回流路径、温升和电池低压工况。内部集成去耦不等于任意外部走线可接受。
