## 有界扇出研究与停止原因

`source_trial`在本布局、其余旧铜全部缺失的有利条件下，研究12条head侧信号到同一右侧总线的入口。必须与真实板的完整恢复区别。

1. 同一晚入口y60、随后同一早入口的预留方式形成了人为同层屏障，被明确拒绝，不能当物理无路证据。
2. 改为错列入口之后，最多得到6条独立源端模型路径，未全通12条。
3. 全组预放8颗.45/.20源端孔、保留真实孔环占位，仍在D6止步；将错列改为.65mm后在D2止步。没有把这些部分结果导入正式主板，也没有声称新布局优于9a03的完整电气实现。
4. 已停止同一路由器增轮。下一是人工pin-order/左右分路/两端层交换规划，而非继续盲搜或增加蛇形。

这些路线仍缺少完整有限几何/原生DRC的接收审查，因此没有把临时 `source_only_NOT_COMPLETE.kicad_pcb` 纳入发布清单。部分源端成功不等于12条DVP、偏置支路或MCU侧完整连接。
