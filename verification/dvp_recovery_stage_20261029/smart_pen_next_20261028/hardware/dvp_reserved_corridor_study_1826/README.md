## 被拒固定源端模型

`source_trial`保留两种次序的模型失败，不导入正式PCB。模型暂去掉3条USB旧外绕后，在y60统一入口做三层搜索。未预留全部入口的初稿让前线遮住后口；补入口后，时钟优先到VSYNC耗尽1,337,323展开，数据优先到D1耗尽1,472,444展开。只是这个固定入口/旧铜模型的失败，不是数学不可布证明。

后续发现同层多口强制相同纵向起点本身会产生拓扑屏障。因此不应拿上述失败直接判整个源区无路；后续不同旋转布局研究明确保留这一模型限制。此策略不再继续加轮。临时局部PCB、二进制搜索输入/输出和编译产物不作为可制板文件。
