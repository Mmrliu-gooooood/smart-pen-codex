# 12条局部 DVP 链原生候选独立审查

**限定结果：12条 translator→J202 局部链静态证据通过；整板不可制板、不可上电，NOFAB。** 本研究不是9a03接受基线的电气后继。为了研究扇出，旧信号/电源/地线及平面填铜已全部移除；0条几何违规与262项未连同时存在，不是成品接近完成。

## 输入与独立方法

- 原候选 hardware/dvp_joint_native_candidate_1950，69项manifest SHA256：98c8617fcd3c5341bd82cbde4db9012ad2cfa70e58377e33443249a8f628845e。
- PCB SHA256：184dce12e82219e5d4bb3e1f20f84cf2bc6e06c1494f5b23862f5e1978024f81。
- 原件逐项大小/哈希及6个明确依赖哈希全部核同。审查在独立副本进行，不改变候选、7d197未选布局或9a03正式基线。
- 重跑作者 normal/-O、12个端点图断段负例；另写 independent_native.py，以原生pad/track/via的**有限铜多边形交叠图**计算连通，并逐链删除一条必要线段做12个独立负例，不只相信中心线端点相同。

## 实际结果

1. 独立真实有限铜图证实12条局部链全部连通：SENS_D0..D7、PCLK、VSYNC、HREF、EXTCLK。每条链只有相应 translator pin 与 J202 pin连在同一pad分组。对应R224..R235的100k偏置端仍各自孤立，不能把局部链成功说成整个同名网完整。
2. 两种模式的独立有限铜12个断段负例均拒绝连通；作者额外12个端点图负例亦复现。76个原生铜对象与解析模型逐项相同：60段0.15mm线、16颗0.45/0.20mm贯穿孔。
3. Fresh KiCad9.0.2完整CLI使用 --all-track-errors --severity-all --schematic-parity --exit-code-violations，结果 **0违规 / 262未连 / 0 parity**。退出码5来自未连错误，不应当写成全DRC通过。
4. 同basename project/dru与9a03字节一致，无新增排除（drc_exclusions为空）。既有5类ignore保持原样，详见independent_results.json；因此“完整CLI”不是任何可能的工艺检查都启用。继承规则含FineSignal127特例，实际新线宽均0.15mm；不能把项目文件中的全局min_clearance=0孤立理解为没检查间距，实际由netclass和.dru生效。
5. 独立原生DRC两项故障注入均触发预期错误：D0长线向D1偏移0.01mm造成clearance错误；一颗孔扩为0.40mm、环外径保持0.45mm造成annular_width错误。故障只在临时副本，不改变设计，也不替代制造公差资格。
6. 102个实体的ref/value/footprint/pad-net保持。相对7d197输入新增6个位姿变更；相对9a03累计29个，不是27+6简单相加。J103/J106保持原位。原生源、库、project/rules保持逐字节一致。
7. 规范化记录的实际UUID后精确原生重放，重新加载保存得到相同PCB SHA。候选原始日志中旧SWIG字符串记录错误只在历史元数据；重放采用纠正后的materialization.json，未将该旧字符串当真实UUID。
8. 已查看native_layers.png：三层长链布局与原生读取一致，图中灰pad是bounding box，不作为实际铜间距判据；实际判据为原生形状与DRC。

## 长度与返回路径的限制

新增链的平面线长（不含真实孔桶传播长度）：D0..D7分别60.7625、61.3125、62.3625、62.9125、66.3625、66.9125、67.9625、68.5125mm；PCLK56.0625、VSYNC56.6125、HREF57.1625、EXTCLK46.2625mm。D4..D7各2孔，其余各1孔。

这些值只描述此半段链。MCU侧、translator传播延迟、偏置stub及真实相机输出/ESP32采样窗口尚未纳入，不能凭总长或与PCLK的差值宣称时序通过。

**当前0填铜参考多边形、0地via、0电源走线。** 因而无法验证16孔的电源反焊盘、返回颈、层间返回/地缝、RF/PI/EMI。不得把无平面时的0冲突继承到未来铺铜板。补电源、地、去耦、偏置和MCU侧布线后必须重新全验，不能先称“仅剩262根线补齐”而假定拓扑可行。

## 机械与产品边界

本轮未重跑FreeCAD、未取得器件/焊点实际高度；保留已有机械审查报告的条件碰撞，不给机械通过结论：R206 B(9,47)的1.45mm预算与现夹持壳相交0.181032mm³；J107.2 B(1.5,83.9)的2mm焊线预算与ACCESS壳相交0.019815mm³，RevD台架R222亦有碰撞。低矮器件能否解决尚无保证。

真实未知30针摄像头仍不得接电。此原生局部研究不证明SC035驱动、光学、压力同步、充电安全、功耗/热或整笔可制造。
