## 复现与额外验证

1. 新进程运行 `/usr/bin/kicad-cli pcb drc --all-track-errors --severity-all --schematic-parity --format json --exit-code-violations`，同 basename 原生 project/rules/schematic 与 PCB 同目录，原件来源与哈希不变。
2. 基线与候选均为 **17 违规 / 21 未连 / 0 parity**。17 条违规完整对象 multiset 一致。DRC 返回 5 是已有违规的正确失败码，不是规则通过。
3. **未连条目有 5 对代表对象替换**，其完整差量保存在 independent_results.json。数量未变，有限铜旧 pad 分组不变，不能将代表对象替换说成修复，也不能说全部三类 finding 完整 multiset 都相同。
4. 原绑定 preflight 通过配置锁检查并调用相同完整 DRC，返回 5；post configuration unchanged 为真。先前省略 --all-track-errors 的 16 条报告不能用作完整检查，更不是工具版本差异或已修短路。
5. 作者有限铜检查 normal/-O 均通过：102 封装原生块、原生源、规则和填铜配置未变；所有旧 pad 连通分组相同，AON/GND 序列化填铜块均连至各自核心；新铜无异网正面积交叠。
6. 铜变化仅 USB_EN1 和 SENS_TRIG_IN：19 旧段删除、2 USB 段裁短、120 新线段+4 过孔；其他网络铜未改。两项安全相关变异（J301 位移、AON 线宽减小）在 normal/-O 四例均被拒绝。
7. 精确序列化 delta 重放并 fresh fill，得到相同候选 PCB SHA。作者回归运行的输出写入副本，不改变冻结输入。

## 返回面与实际空间的边界

- 新增 USB_EN1 路径长 21.6487067 mm，两孔；TRIG 新路径 18.1154329 mm，两孔。这里是新增路径长度，非完整端到端网络长度。
- 独立提取四孔均为 0.45/0.20 mm。USB_EN1 孔 (8.325,70.275) 距最近 GND 孔中心 3.794898 mm；另一孔约 0.756637 mm。TRIG 两孔最近 GND 孔中心均约 0.682367 mm。该指标不等于实际返回环路阻抗。
- 扣除实际贯穿钻孔后，新走线有限宽度在指定最近参考平面之外的投影并集：USB_EN1 约 **0.217748384 mm²**，TRIG 约 **0.180983582 mm²**。这包含换层附近反焊盘等缺口，不是零参考缺口，更不能证明动态 PI/EMI 合格。
- 重跑旧线参考屏：In1/In4 各少约 1.733976 mm²，In2 少约 5.024189 mm²；旧 AON 投影新增缺口约 0.00005037 mm²。其他旧 DVP/RF/IRQ/AON I²C 没有超过该屏记录阈值的新增损失，不是无限精度无变化或实际电气资格。
- TRIG 孔 (13.425,89.7) 铜环至粗 y90 连接器 body 边界名义间距 **0.075 mm**。未知真实底面、焊料/阻焊、孔环与装配公差仍为未关闭的机械/工艺门；不能把原生 DRC 通过这一局部几何测试等同可制造。
- 实际 J103 仍 B 面 (3,52)/(5.4,52)，J301 pads 仍 (5.8,88.7)/(8.2,88.7)。没有应用虚拟 B70.5 触点接口或 J301 前移。
