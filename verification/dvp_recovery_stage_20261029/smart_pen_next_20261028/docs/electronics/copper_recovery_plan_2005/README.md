# 9a03 → f92c 只读铜恢复计划，NOFAB

**未把任何旧铜加回新板，未生成新原生候选，未填铜。** 两个输入逐字节保持：正式9a03（17/21/0）和两实体避让研究f92c（0/262/0）。后者只含12条translator↔J202链，仍不能制作。

## 结论

原9a03共有5317条track/via对象；与f92c的新76对象、29改位实体的实际新pad以及新旧孔距比较：
- 557旧对象出现新增有限铜/改位pad/钻孔冲突。
- 9旧track/via涉及源报告原有违规（与557有4对象重合）。没有把已有短路/悬端当无风险铜。
- 剩4755对象仅是本轮几何筛候选，分为238个不依赖旧平面的原生track/pad子图。**4755不是可直接恢复的整网对象数。** 悬空片段、旧移动引脚尾巴仍必须重接或删除。
- 19个网全部当前端点未改、原track图一个连通分量、所有端点都在该分量且没有本轮冲突/原违规网风险，可以作为后续整网恢复候选：BOOT_N、CAM_3V3_PRELINK、CAM_CT、CAM_ON、CAM_QOD、CHIP_EN、ILLUM_STROBE、ISO_GATE、RF_ANT、RF_SIP、SCCB_ENABLE_LINK、SCCB_EN_SAFE、STRAP_GPIO3、STRAP_GPIO45、STRAP_GPIO46、USB_DM、USB_DM_MCU、USB_DP、USB_DP_MCU。
- 上述19网仍需实际复制到另存候选后完整DRC、返回参考、源与制造检查。RF和USB几何没变不等于阻抗/返回继承成立。

`recovery_plan.json`逐对象提供UUID、net、宽度、层、两端坐标、明确冲突对象与原违规、旧pad接触；按net列全端点、已移动端点、候选完整网、连通子图索引。`net_summary.csv`适合人工查看。

## 反焊盘明确纳入，而非继承旧平面

对新16个贯穿信号孔，以实际0.45mm铜环加各zone≥0.15mm间距，在旧填铜的有限多边形上计算排除区域：
- 旧In2 AON zone新增排除并集约**4.216142053mm²**（14孔与旧填铜有正面积交叠）。
- 旧In1/In4各两个GND zone分别约**6.197345597mm²**及**0.871929045mm²**。这些是各zone的并集，不应无条件相加成整层净损失。
- 每孔UUID/坐标/所在zone交叠面积全部记录。此处只是历史填铜会被新孔侵入的证据，**没有重填、没有证明仍同核心、没有证明最窄地颈/阻抗/返回间距通过**。
- 后续恢复必须从原始zone边界和规则重新填铜，检查原全部AON/GND pad与实际J106核心连通、孤岛、细颈、过孔/铜桥载流以及DVP/USB/RF换层返回。不以面积小作为电源完整性通过理由。

## 建议下一轮有界恢复顺序

1. **建立主供电/地骨架的新候选，不先恢复所有信号。** 先选完整保留的U301局部控制/预连接网与实际固定pad子图；例如AON 55对象片段连接R203.2↔U301.1，GND 184对象片段连接U301.2/C302.2/C303.2/R301.2。它们尚未证明接J106核心，不能单独上电。
2. 对上述12 AON/2 CAM_SW/85 GND冲突给出明确替代完整路径。保原0.5mm主干及电源角色；不得靠削细电源、删地孔或把压力/模式口改功能来让路。当前12链不是不可移动的永久约束，如果完整电源返回无法成立，应联合小范围改DVP入口/头端，重新对12链全验。
3. 先做新原生候选fresh fill与全部核心连通、有限铜/负例/完整DRC。仍保持JP301 OPEN，确认VIO是外部头参考输入，不冒出主板1.8V电源。
4. 骨架可接受后，再恢复19个整网候选与其他包含≥2固定pad的明确子图；逐网测试所有当前端点。对于包含U201–203或移动偏置/去耦端点的网，只恢复有意义的固定端片段，按新引脚位置重布stub/电源端，不能把旧尾巴原样加入。
5. 在最后全板完整DRC、源/parity、机械及实际波形/功耗/热/印刷/光学验证前，仍NOFAB。此计划不缩小262未连的当前事实。

## 方法和可复现边界

- 原生铜形状按共享层计算0.15mm异网距离；用真实新pad、旧新via钻孔边距0.25mm及同网钻孔-pad重叠筛，不忽略同网via-in-pad风险。旧旧相互关系沿源完整DRC列风险；此任务没有新完整DRC候选。
- 连通子图来自内存中的旧板，移除所有zone后重建KiCad连接；只使用未冲突/无原违规铜以及**未移动的实际pad UUID**作连接桥。不同物理pad即便同编号不会被人为短接。移动pad只作为“必须改接的旧端点”列出。
- 同网旧铜碰到新12链仅列为候选接触，不自动提升全网恢复结论。
- normal/-O输出一致；独立账目/组件分区/整网端点验证与4个故意错误负例通过。负例不代替后续真正KiCad/电气验证。
- 图片`power_recovery_map.png`只是只读规划叠图：绿为局部几何候选、红为冲突/原风险、蓝为当前12链；不绘旧plane fill，不是已恢复铜截图。图片已实际查看。
- 输入原生文件hash前后不变。本任务无原生写入、上传、制板、上电或采购。
