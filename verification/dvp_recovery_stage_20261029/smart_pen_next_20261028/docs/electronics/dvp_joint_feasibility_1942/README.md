### 已做的几何筛选

最终12网60条线+16贯穿孔，同时：
- 对102实体所有pad、六铜层，0.15mm异网铜边距无冲突；六改位实体对其余pad同样无冲突。
- 76对象彼此异网共享层铜边距无冲突；独立纯Python精确轴平行中心线/宽度距离计算一致。
- 所有同面原生courtyard均无正面积相交；102实体都具有courtyard。
- 原生4个规则区按tracks/vias及层属性检查，没有禁入冲突。
- 从实际Edge.Cuts生成板多边形，逐对象增加0.25mm铜到板边区域，无超界。独立矩形X筛最小0.425mm只是交叉检查，非替代真实轮廓检查。
- 16孔之间独立drill-to-drill最小边缘距离0.620061mm（0.20mm孔；比较门0.25mm），不是将铜间距冒充孔距。输入没有其他原生pad钻孔，旧via已在输入布局删除，因此此项**不覆盖未来全板新增/恢复孔**。
- 所有16钻孔对全部pad的实体交叠为零，**包含同网pad**；同网via铜环与pad实体交叠也为零，未通过跳过同网掩盖via-in-pad。
- 正常与-O检查输出相同。独立距离检测4个重合异网负例均拒绝。

最小异网铜距数学目标仍恰0.15mm，无额外制造裕量。这里只判断局部名义二维几何；没有运行完整原生整板ERC/DRC，不能写成“DRC 0”或“274连接已经关闭”。

## 未测和必须联合审查的事项

1. **贯穿孔反焊盘/返回**：仅16孔铜环对其他模型铜、pad/规则区已筛；输入无已填电源地平面。In1/In2/In4平面反焊盘、AON核心、地颈/岛、换层地via、回流路径、RF影响均未资格，不能将零铜碰撞推广成PI/EMI成立。
2. **偏置支路未连接**：R225/226/227翻B后D1/D2/D3的100k stub与GND、R206 UNUSED_B_INPUT的10k下拉均还没布线。其它MCU侧、供电、去耦、接口全部旧铜也未恢复。
3. **机械高度未知，不填0**：四R为`R_0603_1608Metric`，native仅引用泛用KiCad STEP，字段无可绑定的厂家最大高度/焊接高度，不能据此保证B面间隙。J105/J107为定制焊线pad footprint，没有3D实体模型；实际线径、锡包、线束弯曲及应力释放高度未给，不能认为“零高度”。
4. **机械审核请求**：先评估B面新增四R在x4.5..10.5、y43.3..47与电源板/电池/支撑的实体包络；J105移到B77.5、J107翻至B左列x1.5/y81.5..86.3能否焊接及走线。若B面布局不允许，本候选即拒绝；不继而擅自搬J103/J106。
5. J202前方最近新孔D0中心y89.35，0.45铜环最远89.575。仅粗body起点y90可算0.425名义间隙，真实壳体/FPC/公差与制造盖孔需要另验。不能套此前0.075mm孔的结论。
6. 90°模型转角、阻抗、全路径+AXC延迟、相对PCLK时序、实际相机峰值频率均待设计与实测。此方案不改变用户旧30针相机未知电平/线序门禁。

## 可交给下一步的具体结果

在**保持J103/J106固定**的条件下，已找到一个全部12网端点和102实体二维名义几何同时无上述冲突的解析模型，六项位移明确可复现。值得进入独立几何/机械审查；审查通过后才考虑另存原生候选，不能以“路由模型可放”跳过剩余电源、支路、连通、机械和实物验收。
