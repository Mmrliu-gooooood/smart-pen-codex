## 先读真实pin顺序

U201相机侧数据D0..D7分别为21..14，J202是2、3、5、6、8、9、11、12。U202的PCLK/VSYNC/HREF为13/12/11，对J202的14/15/16。U203 EXTCLK为13，对J202的18。**11条相机→MCU，EXTCLK反向MCU→相机**；“translator endpoint”不是统一方向的电气源。

正式9a03中3个转换器F面0°，相机侧主要沿右边纵向排列。未选旋转版本为−90°：相机侧朝下，D7→D0的X递增3.075→7.625，顺序与J202数据组X递增7.25→12.25一致。因此整体扇出不应先将端点人为交换，再靠7–10次换层或长绕路救回。旋转并不消除MCU端新扇出，也不减少芯片到纸端的总距离。

## 只作为人工比较的左右/层分工

| 组 | 待比较的长通道 | 必须先解决的交换与占位 |

| D4–D7 | In3.Cu左侧，X=1.4/1.1/.8/.5 | 这是**有障碍**的备选，不是新空槽。当前9a03实际35个唯一旧铜对象阻挡4条左槽，含AON/GND及CAM/控制信号。必须按实际连通用途分组重排、验证完整恢复，绝不直接删除或用细线替主电源。源F→In3、目标In3→B至少两处层转换。 |

## 必须画出来的三个局部图，再允许布整段

1. **源端完整组图**：12个实际pad、8数据相关100k偏置、去耦、所有预置via圆环与钻孔。先放全组必要的via，不让先布网永久堵住后网；via直径/孔距与.15线间距是不同门。
2. **中间分层截面**：明确F参考In1 GND、In3/B参考In4 GND；记录每个through-via穿过In2 AON的真实反焊盘，不能只看3个信号层。选左路必须保护已有AON/GND核心与各旧pad分量，不能直接套右槽结论。
3. **J202整体扇出**：24个pad、7个GND返回、真实FPC壳体/出口包络、全部数据和时钟共同规划。可在新版本重排刚加的地返回，但必须全组验证。后侧双排孔只是未取得全公差机械资格的研究；`.075mm`名义body间隙不是制造合格。不给某个pad先放“永久孔”再逼全部邻网绕远。

## 不能用旧研究结论替代的门

- 左右跨层不要求任意蛇形“等长”。应测J202→AXC→MCU每段、100k偏置stub、换层与相对PCLK路径；按实际相机输出时序、AXC延迟、S3采样窗口和PVT建立预算。
- ESP32-S3公开PCLK上限40MHz不能批准旧SC035HGS配置的条件72MHz推算。当前相机尚无受控实测，不用降低帧率冒充降低峰值PCLK。
- 新层分配必须重算返回地缺口与最近地via，复填铜、全DRC（含`--all-track-errors`）、同basename源/规则绑定、全旧pad分量、电源/地岛连核心、JP301真实OPEN。
- 任何翻面器件都重新检查壳体/电池/电源板间隙、支架和装配。两支760元预算及15–18mm目标没有因本规划自动满足。
- 所有搜索失败是指定边界/顺序/入口合同的失败。现在不再给同一路由器追加轮数；需要人工KiCad规划或一个先证明全组端点交换的不同方法。
