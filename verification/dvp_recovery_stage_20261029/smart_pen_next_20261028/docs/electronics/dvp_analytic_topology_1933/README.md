# 12网解析有序阶梯拓扑：可作下一轮联合布局的约束，不是布通板

状态 **NOFAB / 规划未选**。正式主板仍9a03（17/21/0），本目录没有修改或产生可制造native板。输入绑定未选27实体旋转布局 `hardware/dvp_rotated_group_placement_1835/native/mainboard_revD.kicad_pcb`，SHA `7d197c4db87e936bd26fc9bb6052036aaf42c3a0e3e92032eac445e4909a6ff1`。该输入主动删除全部旧铜/填铜，名义0/274/0；本研究不恢复这些274处连接。

## 新方法与实际结果

不再使用A*/history轮次，也不把入口锁在y60。一次性定义全部12网的源端阶梯、3层各4条右侧纵线、头端退线次序和16个贯穿孔。`result.json`包含全部76对象的坐标、层、线宽和身份，可用其他方法复查。

- D0–D3用F；D4–D7用In3；PCLK/VSYNC/HREF/EXTCLK用B。
- 每层右纵线X=13.5/13.2/12.9/12.6mm；0.15mm线宽、0.15mm间距。
- 数据源阶梯从y38.0起，每组按D0→D3或D4→D7递增0.65mm。
- 头端先让时钟组在y81.45–83.40退到x4.25–6.25，随后数据按D7→D0在y84.05–88.60依次退到x7.25–12.25并进入B层。这样在B面不把时钟横线画穿数据末端纵线。
- 首稿0.30mm阶梯虽然线距够，却使贯穿孔与相邻线路不够净距，已拒绝保留`rejected_dense_stair.*`。最终0.65mm不是继续搜索所得，是显式给孔环留位。

最终60条线+16孔的所有异网同层铜相互间距冲突为0，**包含源端和头端，不仅12条直槽**。原生KiCad有限多边形(外逼近误差50nm)与独立纯Python轴平行线段距离复核一致。最小铜距浮点0.14999999999999894mm，数学目标0.15mm，**没有额外工艺裕量**。互相钻孔边距最小0.620061mm（按0.20孔及本轮0.25筛选）；左右矩形板边筛0.425mm。以上不是原生完整DRC、整板孔距、返回面或制造公差保证。

## 真实器件约束：29处冲突，8个ref

新12网相互不冲突不等于可放进板里。把所有102实体真实pad保留后，29条“路线对象–pad”冲突记录如下；数目包括同一pad被多段命中，不是29个独立缺陷。完整逐对象信息在result.json。

| ref | 命中次数 | 分类与必须保留的约束 |
|---|---:|---|
| R225 | 5 | D1的100k偏置，源端可考虑局部移位/翻面，但需要全支路、stub与GND恢复及两面装配复核 |
| R226 | 4 | D2偏置，同上 |
| R227 | 4 | D3偏置，同上 |
| R206 | 4 | UNUSED_B_INPUT的10k下拉，**不是VSYNC偏置**；保持输入有确定状态，不能删掉 |
| J103 | 2 | 现B52干接点焊线端，HREF源孔/横线与GND相冲；需压力线束/RC联合决定，**不自动迁到虚拟B70.5** |
| J105 | 2 | 安全ADC前端接口，HREF/EXTCLK的末端B纵线撞GND pad；不是裸电池口，不能以未用名义删掉 |
| J106 | 4 | **电源核心接口**，数据D2/D3末孔碰GND；搬位影响VBUS/AON/GND实际供电及线束，不可只重排一个地pad或用细线救电源 |
| J107 | 4 | 充电模式接口，D4–D7末孔碰GND/EN2；保持模式控制和地返回及实际焊接空间 |

因此“最小联合移动集合”只是**如果完整保留当前76对象坐标，至少需要处理这8个ref**，不是证明全局最少搬8颗，也不是批准把8个接口任意平移。可局部改路径绕开pad，必须重算全组/孔/返回；或者另建源一致的联合布局。四个R的修改主要为电气/装配局部约束，四个J涉及实际线束和功能，不得当普通小阻容随意搬。

## 可以据此开始的下一轮，及停止门

1. 先固定本解析图为整组空间预留，列出R225/226/227/206可落位和J103/105/106/107的真实机电允许区域。只有得到不侵占16孔及两端阶梯的落位才改新布局。输入27实体布局仍未选。
2. 若J106/J107供电/模式端接不能避让头端阶梯，应调整**整组**头端交换布局，不继续在孤立一条DVP上盲绕。任何方案必须保全部102ref/pad-net、同24针、原轮廓/叠层。
3. 新原生候选必须全源parity、完整DRC(--all-track-errors)、全孔/板边/填铜/电源岛连通，以及机械真实线束和两侧高度复查。再恢复MCU侧/偏置/所有其它连接，不继承旧9a03连通性。
4. In2 AON的16孔反焊盘、地返回/地孔和去耦路径当前**没有**资格；未画回流和供电铜不能声称PI或EMI。90°模型转角亦需实际布线转角细化后复验。
5. 没有实际相机时序/AXC/S3 PVT预算，不能任意等长或称40MHz已通过。不能用于直接上未知30针SC035模组。

**停止结论：**本次已证明一个12网两端互不交叉且线/孔互距满足名义规则的几何模型，并准确定位它与实际8个ref的冲突。尚未找到保全部器件与功能的可路整板；不声称现板数学无解，不重复旧路由器加轮。
