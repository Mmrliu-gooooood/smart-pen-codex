# 头区12信号与电源入口联合解析规划，NOFAB

本包只在内存中建立拓扑，没有保存新PCB、没有填铜、没有上传或上电。输入4d7bd85ae460928a48967c00adae133c05df5ef259a6789470c04e986b856f8a保持不变，其0/233/0状态未被本规划改写。正式接受板仍9a03。

## 结果与范围

统一考虑全部12条translator→J202链、固定J106/J301入口及旧19整网392铜对象，得到一个**有限几何无冲突**的联合模型：141个模型对象，包括原SW上游47个精确对象、其余94个信号/电源/地模型对象。实际366 pad、0.15mm异网间距、0.25mm孔距与真实板边、原生禁布区、同网孔环-pad也一并筛选。

独立有限铜图确认12链、JP301.2→J301.1完整CAM_SW链，以及J106.3→J301.2局部地链；14个逐链删段负例均断开。normal/-O生成和有限铜验证结果一致。当前模型与392既有铜无异网冲突，既有铜本身未改变。

**没有确认39个AON端点全部到核心，也没有确认完整GND返回能力不低于旧板。** AON核心入口与中段桥是分离局部片段，必须靠后续完整电源布线/平面接通。本包因此不是“完整电源骨架通过”，更不是“全板DRC为零”。没有运行新板原生DRC、没有恢复旧平面。信号时序、参考连续性、供电温升及制造资格仍未取得。

## 单一联合拓扑的具体变化

1. 保留源端全组及右侧三层走廊。头端D4–D7四条In3横线和四条同步/时钟B横线整体提前3mm，而非让电源孔强塞原横线间隙。EXTCLK横线最终y78.6，躲开SCCB_ENABLE_LINK旧贯穿孔(9.55,78.0)。
2. D7头孔从目标pad同列改至(8.0,81.05)，B面先到x7.25，再到y84.0、错列到x7.4/y84.2，下行到89.8后回实际J202.12的(7.25,90.5)。源/目标实际引脚未改。此处不移动D6，而是避开其贯穿环及C501.2。
3. 固定J106.2(10.6,83.9)用0.5mm F铜到AON孔(11.9,83.9)，孔0.60/0.30。孔在原pad外，未以via-in-pad偷取空间。
4. J301.2(8.2,88.7)用0.5mm F铜沿(8.2,86.3)接固定J106.3(10.6,86.3)，再到GND孔(11.9,86.3)，孔0.60/0.30。这里只保证这两个地端点互连，不代替全部地回流。
5. J301.1用0.5mm F铜到SW孔(6.825,87.6)，孔0.60/0.30。原PCLK x6.25与D7 x7.25只相隔1mm：0.6孔环对两条0.15线满足0.15间距需要中心通道宽1.05mm；所以单调孔位无解于这个固定局部截面。D7局部移到x7.4后产生1.15mm通道。
6. CAM_SW保留旧JP301.2侧47个对象；旧局部7对象弯折受前移D6/D7孔影响而移除，改0.5mm In2线路(6.825,87.6)→(6.85,82.05)→(6.85,79.0)→(10.15,79.0)→(10.15,78.5)，接回旧链。不是把旧54个对象直接恢复，也不是把SW接PRELINK。**JP301保持OPEN。**
7. AON中段只规划一条0.5mm In2桥(11.2,55.75)→(11.2,64)→(11.3,64.8)。旧端点和其余AON仍未恢复；它与J106入口目前不相连。

全部封装位姿保持输入不变；J103、J106、J301都没有移动。没有缩小器件/安装包络，也没有改源、连接器针序或跳线状态。局部图仅显示模型铜与pad显示AABB，未绘不存在的平面。图已实际查看。

## 有界拒绝记录，而非无界搜索

- initial_rejected_result：最初整体提前4mm，会碰J105及旧SCCB_ENABLE_LINK；D7错列开始太早，碰D6孔。
- second_rejected_result：整体提前3mm后，D7孔碰C501.2、EXTCLK横线靠旧SCCB孔太近；电源孔仍与同网接线pad重叠。按具体实体边界修正，不以同网忽略安装风险。
- old_sw_component_rejected：直接恢复旧54对象上游SW链后出现6条冲突，集中旧7对象弯折与新D6/D7孔。
- direct_sw_rejected：另起长直SW线跨越现有SCCB/预连接网，31条冲突，明确拒绝。最终保留旧源端47对象、只重排受影响7对象，不继续猜全新供电路线。
- joint_before_sw_restore仅局部入口clear，不证明完整SW；最终result.json才包含闭合SW的联合模型。

## 返回与平面占位仍是实质阻断项

未在In1/In4走长线或切地槽；但贯穿孔及反焊盘仍改变旧平面。verify输出使用旧填铜对全部模型异网铜的排除占位并集：
- In2 AON旧fill交叠约7.628949mm²；
- In1/In4每层两个旧GND zone分别约6.357475及1.508148mm²。
这些数包含模型中沿用的SW孔/线，**不是相对上一版本的净新增差量**，不能跨zone盲加，也不证明剩余平面完整。模型只有一个新增核心GND孔，不能据此宣称所有16个信号换层的地返回距离/电感等同旧板。

下一步若采纳这个拓扑，必须另存原生候选并先做完整DRC/源/实际14链重验；再按原zone边界fresh-fill，逐层/跨孔查AON39 pad与所有GND实际pad到J106核心、实际电源路径最窄颈、源端去耦正地回路、头端七地及全部换层返回。需要新增GND stitching时必须整组检查与上述电源孔/IMU应力区/机械底面，不能盲恢复旧85冲突地对象。若不能满足这些门，重新联合该头区而非削细0.5mm主干。

## PAD层字段勘误：限定影响范围

原生PAD.GetLayer()在本环境对实际B层焊盘仍返回F.Cu，不能用于pad层判定。pad_layer_erratum.json给366个实际pad的GetLayer原值、IsOnLayer得到的copper_layers和FP面；其中2022/2124电源合同42条side错误。确切受影响文件/字段：
- power_backbone_plan_2022/plan.json的pad_contract.side；
- power_backbone_recovery_2124/plan.json及plan_normal.json同字段；
- power_backbone_recovery_2124/power_pad_contract.csv的side。

数量、UUID、ref/pin、net、XY、size没有改变。经定向追溯，2022/2124实际铜距和孔-pad检查用IsOnLayer；2005铜恢复检查用IsOnLayer及原生GetConnectedPads；2014源合同用GetLayerSet、原生连接图；2020和1955有限铜独审用IsOnLayer；1950源/目标端层判断也用IsOnLayer。未发现这几批数值几何判据受side导出错误影响。不宣称审计了所有历史脚本。原生CLI仍依据真实layer set。
