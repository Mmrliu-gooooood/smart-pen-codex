# 双介质交接有限协议模型

研究代码，未接入固件，未采用新存储器或MCU。运行 `python test_model.py` 和 `python -O test_model.py`。

10项测试，穷举两个预先持久记录的463个状态、2493条转换：未提交复制不能擦原件；本地迁移不是BLE ACK；ACK需对应当前精确记录；旧副本仍在时不能提前丢ACK墓碑；重复记录内容冲突必须停止恢复。

commit为抽象持久化契约，不证明现实写入/sync/命令状态已经抗断电。没有字节撕裂、坏块/ECC、缓存、电压跌落、并发、容量耗尽和有界ACK日志实现。此模型不证明24小时容量或实物断电安全，不替换既有store.c。
